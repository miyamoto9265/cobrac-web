# ステップ5: 機能関連項目の定義

TLFとすべてのGNについて、以下の4項目を定義します：Requirement, Requirement realization by interface, Capability, Mechanism

## TLF: R.Perceptual-Speed

### Requirement
[R.Perceptual-Speed]は、広範な視野内で視覚刺激（文字、数字、パターンなど）の類似点や相違点を素早く流暢に探索・比較する能力として機能する必要がある。入力として、[U.V1]（網膜位置対応的な視覚特徴マップ；方位、空間周波数、色、輝度コントラスト）、[U.V2]（輪郭、テクスチャ、立体視差などのより複雑な視覚特徴）、[U.V3]（大域的運動パターンと動的形態の表現）、[U.V4]（色恒常性と形態の統合表現）、[U.MT]（視覚運動の方向と速度の選択的表現）、[U.IT]（物体カテゴリと形態の高次表現、文字・数字・複雑パターンの同一性表現）、[U.Pulvinar]（上丘を経由した視覚情報の高速リレー）、[U.FEF]（注意制御信号）、[U.DLPFC]（探索目標テンプレート、タスクルール、意思決定基準）を受け取る。これらの入力から、視野内のターゲット刺激を検出し、その検出判断と確信度を計算し、[U.SC]（サッカード目標）、[U.PMC]（運動準備信号）、[U.FEF]（注意優先マップ）、[U.DLPFC]（判断結果）、[U.V1]-[U.MT]（注意変調信号）として出力する。この変換により、視覚探索の全過程（特徴統合→照合選択→判断）が実現され、知覚速度という認知能力が発現する。

### Requirement realization by interface
[R.Perceptual-Speed]のInterfaceは、([U.SC], [U.PMC], [U.FEF], [U.DLPFC], [U.V1], [U.V2], [U.V3], [U.V4], [U.MT]) = R.Perceptual-Speed([U.V1], [U.V2], [U.V3], [U.V4], [U.MT], [U.IT], [U.Pulvinar], [U.FEF], [U.DLPFC])と定義されている。Requirementで記述された機能は、このInterfaceによって完全に実現される。視覚野からのbottom-up情報、ITからの物体情報、Pulvinarからの高速視覚情報が入力され、FEFとDLPFCからのtop-down制御が統合される。出力として、運動系（SC, PMC）への指令、認知制御系（FEF, DLPFC）へのフィードバック、視覚系（V1-MT）への変調が含まれ、知覚速度の全機能が包含される。このInterfaceは、子GN（R.Visual-Integration, R.Goal-Matching-Selection, R.Comparison-Judgment）とそれらが内包するUC（U.pIPS, U.mIPS, U.aIPS）を通じて、階層的な情報処理として実装される。

### Capability
視覚情報の階層的処理により、視野内のターゲット刺激を検出し判断する能力。この能力は、(1)視覚特徴の空間的統合と優先度計算、(2)探索目標との照合と選択的注意、(3)証拠の蓄積と判断・確信度評価という3つの段階的処理を含む。各段階は並列処理と逐次処理を組み合わせ、bottom-up情報とtop-down制御を統合する。この処理は、Priority Map理論（Bisley & Goldberg, 2010）、Guided Search 6.0（Wolfe, 2021）、Drift Diffusion Model（Ratcliff & McKoon, 2008）などの計算論的枠組みに基づく。知覚速度は、単一の処理ではなく、複数の部分機能が統合された創発的な認知能力である。神経科学的には、頭頂間溝（IPS）における後部→中部→前部という階層的情報処理として実装される（Orban & Caruana, 2014）。

### Mechanism
知覚速度は、以下の3段階の階層的メカニズムによって実現される。第1段階（視覚統合）では、複数の視覚野からの並列入力が後部IPS（pIPS）に収束し、bottom-up saliency mapとtop-down relevance mapが統合されてpriority mapが形成される。Priority mapは、各空間位置の行動的優先度を表現し、注意とサッカードの目標位置を決定する。第2段階（目標照合選択）では、priority mapに基づいて注意スポットライトが配置され、中部IPS（mIPS）で探索目標テンプレート（DLPFCから）と視覚情報のtemplate matchingが実行される。一致度が高い候補は選択され、低い候補（distractor）は抑制される。Winner-take-all機構により競合が解決される。第3段階（判断）では、前部IPS（aIPS）で証拠がDrift Diffusion Modelに従って時間積分され、判断閾値（DLPFCから）に達した時点で判断が確定する。確信度は証拠強度と判断時間から計算される。各段階はフィードバックループで接続され、探索の動的調整が可能となる。

## 第1層GN

### R.Visual-Integration

#### Requirement
[R.Visual-Integration]は、広範な視野全体から視覚情報を統合し、探索可能な表現を構築する必要がある。入力として、[U.V1]（網膜位置対応的な視覚特徴マップ）、[U.V2]（輪郭、テクスチャ）、[U.V3]（大域的運動パターン）、[U.V4]（色と形態の統合表現）、[U.MT]（視覚運動の方向と速度）、[U.IT]（物体カテゴリと形態の高次表現）、[U.Pulvinar]（視覚情報の高速リレー）、[U.FEF]（注意制御信号）、[U.DLPFC]（探索目標テンプレート）を受け取る。これらを統合し、視野全体の空間的優先度マップを構築し、[U.mIPS]（次段階の選択処理への入力）、[U.V1]-[U.MT]（注意による感度変調）、[U.FEF]（注意シフト候補位置）として出力する。この変換により、視覚探索の最初の段階として、視野のどの領域を優先的に処理すべきかが決定される。

#### Requirement realization by interface
[R.Visual-Integration]のInterfaceは、([U.mIPS], [U.V1], [U.V2], [U.V3], [U.V4], [U.MT], [U.FEF]) = R.Visual-Integration([U.V1], [U.V2], [U.V3], [U.V4], [U.MT], [U.IT], [U.Pulvinar], [U.FEF], [U.DLPFC])と定義されている。Requirementで記述された視覚統合機能は、このInterfaceによって完全に実現される。視覚野からの並列入力が[U.pIPS]に収束し、ITとPulvinarからの追加情報が統合される。FEFとDLPFCからのtop-down制御により、探索目標に関連する特徴が強調される。[U.pIPS]内でbottom-up saliencyとtop-down relevanceが統合され、priority mapが形成される。このmapは[U.mIPS]に送られ、視覚野へのフィードバックにより注意変調が実現され、[U.FEF]へのフィードバックにより注意シフトが制御される。

#### Capability
複数の視覚特徴チャネルからの情報を空間的に統合し、行動的優先度マップを構築する能力。この能力は、各視覚特徴（方位、色、形態、運動）の局所的顕著性を計算し（center-surround差分フィルタ）、それらを正規化して統合する処理を含む。Bottom-up saliency mapの構築は、Itti & Koch (2001)のSaliency map modelに基づく。並行して、探索目標テンプレートと視覚特徴の類似度を計算し、top-down relevance mapを形成する。両mapは加算的または乗算的に統合され、最終的なpriority mapを生成する。Priority mapは、Bisley & Goldberg (2010)のPriority map理論で定式化され、LIPニューロンが視覚信号、サッカード信号、認知信号を加算的に統合することが実証されている（Thomas & Paré, 2007）。

#### Mechanism
視覚統合は、以下のメカニズムで実現される。まず、各視覚野（V1-MT）から[U.pIPS]への並列投射により、視覚特徴が網膜位置対応的に表現される。[U.pIPS]内で、各特徴チャネルの局所コントラストがcenter-surround差分により計算され、正規化後に統合されてbottom-up saliency mapが形成される。並行して、[U.DLPFC]からの探索目標テンプレートと[U.pIPS]内の視覚表現の類似度が計算され、top-down relevance mapが形成される。両mapは統合され（P = α·S_bu + β·S_td）、surround suppressionにより空間的に鋭敏化される。このpriority mapは動的に更新され、inhibition of returnにより既訪問位置の優先度が低下する。Priority mapのピーク位置が次の注意目標として[U.mIPS]と[U.FEF]に送られる。同時に、[U.pIPS]から視覚野へのフィードバック投射により、priority mapで高活動の位置に対応する視覚野ニューロンの入力ゲインが増強される。

### R.Goal-Matching-Selection

#### Requirement
[R.Goal-Matching-Selection]は、探索目標と視覚情報を照合し、候補を選択する必要がある。入力として、[U.V1]-[U.MT]（視覚特徴）、[U.IT]（物体表現）、[U.Pulvinar]（視覚情報リレー）、[U.pIPS]（優先度マップ）、[U.FEF]（注意配分制御）、[U.DLPFC]（探索目標テンプレート、ワーキングメモリ）を受け取る。[U.pIPS]で構築された優先度マップに基づき、[U.mIPS]で探索目標との詳細な照合を実行し、ターゲット候補を選択し、distractorを抑制する。選択結果を[U.aIPS]（判断段階への入力）、[U.FEF]（注意優先マップのフィードバック）、[U.V1]-[U.MT]（選択的注意による変調）として出力する。この変換により、視野内の多数の刺激の中から、探索目標に一致する可能性が高い候補が絞り込まれる。

#### Requirement realization by interface
[R.Goal-Matching-Selection]のInterfaceは、([U.aIPS], [U.FEF], [U.V1], [U.V2], [U.V3], [U.V4], [U.MT]) = R.Goal-Matching-Selection([U.V1], [U.V2], [U.V3], [U.V4], [U.MT], [U.IT], [U.Pulvinar], [U.pIPS], [U.FEF], [U.DLPFC])と定義されている。Requirementで記述された照合選択機能は、[U.pIPS]と[U.mIPS]の協調によって実現される。[U.pIPS]が優先度マップを提供し、[U.mIPS]がそのマップに基づいて注意スポットライトを配置する。[U.DLPFC]からの探索目標テンプレートと[U.pIPS]からの視覚情報が[U.mIPS]で照合される。Template matchingにより一致度が計算され、高一致度の候補が選択され、低一致度のdistractorが抑制される。選択結果は[U.aIPS]に送られ、[U.FEF]へのフィードバックにより注意配分が継続的に調整される。視覚野への出力により、選択された候補の処理が強調される。

#### Capability
探索目標テンプレートと視覚情報を照合し、選択的注意により候補を絞り込む能力。この能力は、template matching（視覚特徴ベクトルと目標テンプレートの類似度計算）と、競合的選択（Winner-take-all機構による候補の選択）を含む。Guided Search 6.0モデル（Wolfe, 2021）では、priority mapの高活動位置から順次、注意スポットライトが配置され、各項目が拡散ベースの認識プロセス（>150ms/item）で処理される。選択的注意は、ターゲット集合サイズとdistractor集合サイズに応じて適応的に配分される（Gillebert et al., 2012）。Distractor抑制は、V4で観察されるpop-inメカニズム（初期増強後の持続的抑制）により実現される。Feature attentionは、探索速度と正確性のバランスを最適化するメカニズムとして機能する（Vater et al., 2023）。

#### Mechanism
目標照合選択は、[U.pIPS]と[U.mIPS]の2段階で実現される。第1段階（[U.pIPS]）では、priority mapのピーク位置が特定され、次の注意目標として[U.mIPS]に送られる。第2段階（[U.mIPS]）では、[U.pIPS]からのpriority mapに基づき、注意スポットライトが順次配置される（A(x,y,t) = Θ(P(x,y,t) - θ_att)）。各スポットライト内で、視覚特徴（[U.pIPS]経由）と探索目標テンプレート（[U.DLPFC]から）の類似度が計算される（M_i = sim(V_i, T)）。一致度が閾値を超える項目はターゲット候補として選択され、その活動が増強される。Distractorに対しては、初期増強後に持続的抑制が適用される（D_i(t) = max(0, I_i(t) - k·(I_i(t-Δt) + Σ_j w_ij·S_j))）。複数候補間では競合的相互抑制が働き（S_i = M_i·A_i - Σ_{j≠i} w_ij·S_j）、最も強い候補が勝者となる。Feature attentionの強度は、速度コストとエラーコストを最小化するように調整される（F = arg min(C_time·RT + C_error·ER)）。選択された候補の情報は[U.aIPS]に送られ、注意配分状態は[U.FEF]にフィードバックされる。

### R.Comparison-Judgment

#### Requirement
[R.Comparison-Judgment]は、選択された候補が目標と一致するかを判断する必要がある。入力として、[U.pIPS]（優先度マップ）、[U.mIPS]（選択されたターゲット候補の表現）、[U.FEF]（探索終了制御）、[U.DLPFC]（意思決定基準、判断閾値）を受け取る。[U.mIPS]からの候補情報を[U.aIPS]で時間的に蓄積し、判断閾値と比較して、ターゲット検出の有無を決定する。同時に、判断の確信度を計算する。判断結果を[U.pIPS]と[U.mIPS]（探索継続か終了かのフィードバック）、[U.FEF]と[U.DLPFC]（判断結果の報告）、[U.SC]と[U.PMC]（運動応答の開始）として出力する。この変換により、視覚探索の最終段階として、「ターゲットが見つかった」という判断が確定し、適切な行動が開始される。

#### Requirement realization by interface
[R.Comparison-Judgment]のInterfaceは、([U.pIPS], [U.FEF], [U.DLPFC], [U.SC], [U.PMC]) = R.Comparison-Judgment([U.pIPS], [U.mIPS], [U.FEF], [U.DLPFC])と定義されている。Requirementで記述された判断機能は、[U.mIPS]と[U.aIPS]の協調によって実現される。[U.mIPS]が候補の選択情報を提供し、[U.aIPS]がその情報を証拠として蓄積する。[U.DLPFC]からの判断閾値により、判断のタイミングが制御される。証拠が閾値に達すると判断が確定し、[U.SC]と[U.PMC]への出力により運動応答が開始される。同時に、確信度が計算され、[U.FEF]と[U.DLPFC]に報告される。確信度が低い場合、[U.pIPS]と[U.mIPS]へのフィードバックにより探索が継続される。このInterfaceは、判断の速度-正確性トレードオフを調整する柔軟な機構を提供する。

#### Capability
感覚証拠を時間的に蓄積し、二値判断（ターゲット有/無）とその確信度を計算する能力。この能力は、Drift Diffusion Model（DDM; Ratcliff & McKoon, 2008）に基づく証拠蓄積プロセスを含む。証拠は、ターゲット仮説とno-target仮説を表す2つの独立した積分器で並行して蓄積される（dE/dt = μ·S + σ·η(t)）。いずれかが判断閾値に達した時点で判断が確定する。確信度は、証拠の強度と判断時間から計算される（Conf ∝ (E_winner - E_loser)/RT）。ベイズ的確信度モデル（Sanders et al., 2016）では、確信度は判断が正しい事後確率として定義される。神経科学的には、頭頂皮質ニューロンが確信度を集団コードとして表現することが実証されている（Kiani & Shadlen, 2009）。確信度信号は刺激提示後約300msから出現し、運動応答まで持続する（Gherman & Philiastides, 2015）。

#### Mechanism
判断は、[U.mIPS]と[U.aIPS]の2段階で実現される。第1段階（[U.mIPS]）では、選択された候補の一致度が計算され、その信号が[U.aIPS]に送られる。第2段階（[U.aIPS]）では、[U.mIPS]からの証拠が時間積分される。2つの独立した積分器（ターゲット有り仮説用とターゲット無し仮説用）が並行して動作し、各時刻で証拠のドリフト率に比例した増分とガウスノイズが加えられる（dE_target/dt = μ_target·S + σ·η(t), dE_notarget/dt = μ_notarget·(1-S) + σ·η(t)）。いずれかの積分器が[U.DLPFC]から設定された判断閾値（θ_decision）に達した時点で、判断が確定する（Choice = arg max(E_target, E_notarget) if max(...) > θ_decision）。判断時間はRT = t（閾値到達時刻）として記録される。確信度は、勝者積分器と敗者積分器の差を判断時間で割った値として計算される（Conf = (E_winner - E_loser)/RT）。あるいは、ベイズ的には Conf = P(correct | E, Choice, RT) として計算される。判断後も証拠蓄積は継続し（post-decisional accumulation）、確信度が更新される。確信度が高い場合、判断結果が[U.SC]と[U.PMC]に送られ、運動応答が開始される。確信度が低い場合、[U.pIPS]と[U.mIPS]へのフィードバックにより、探索が継続される。

## 第2-3層GNの機能詳細

### R.Feature-Extraction

#### Requirement
[R.Feature-Extraction]は、基本的な視覚特徴を抽出・表現する必要がある。入力として、[U.V1]（方位、空間周波数、色、輝度コントラスト）、[U.V2]（輪郭、テクスチャ）、[U.V3]（大域的運動）、[U.V4]（色と形態の統合）、[U.MT]（視覚運動）、[U.IT]（物体表現）、[U.Pulvinar]（高速視覚リレー）を受け取る。これらを[U.pIPS]で統合し、網膜位置対応的な視覚特徴マップを構築し、[U.mIPS]、視覚野、[U.FEF]に出力する。

#### Requirement realization by interface
Interface ([U.mIPS], [U.V1], [U.V2], [U.V3], [U.V4], [U.MT], [U.FEF]) = R.Feature-Extraction([U.V1], [U.V2], [U.V3], [U.V4], [U.MT], [U.IT], [U.Pulvinar]) により、視覚野からの並列入力が[U.pIPS]に収束し、統合される。[U.pIPS]は、各視覚特徴を空間マップとして保持し、下流の処理に提供する。

#### Capability
複数の視覚野からの特徴情報を統合し、共通の空間座標系で表現する能力。背側視覚経路（V1→V2→V3→MT→IPS）における階層的特徴処理に基づく（Konen & Kastner, 2008）。

#### Mechanism
視覚野（V1-MT, IT）から[U.pIPS]への並列投射により、視覚特徴が網膜位置対応的に表現される。各特徴は独立したチャネルとして処理され、[U.pIPS]内で空間的に整列される。

---

### R.Spatial-Priority-Formation

#### Requirement
[R.Spatial-Priority-Formation]は、視野全体の空間的優先度マップを形成する必要がある。視覚特徴から計算されるbottom-up saliencyと、探索目標に基づくtop-down priorityを統合し、最終的な優先度マップを生成する。

#### Requirement realization by interface
Interface ([U.mIPS], [U.FEF]) = R.Spatial-Priority-Formation([U.V1], [U.V2], [U.V3], [U.V4], [U.MT], [U.IT], [U.Pulvinar], [U.FEF], [U.DLPFC]) により、子GN（R.Bottom-Up-Saliency, R.Goal-Directed-Priority, R.Priority-Integration）を通じて優先度マップが形成される。

#### Capability
Bottom-upとtop-down情報を統合してpriority mapを構築する能力。Priority map理論（Bisley & Goldberg, 2010）に基づく。

#### Mechanism
子GNが並列に処理を実行し、[U.pIPS]内でsaliency mapとrelevance mapが統合される（P = α·S_bu + β·S_td）。

---

### R.Bottom-Up-Saliency

#### Requirement
視覚的顕著性に基づくボトムアップ優先度を計算する。視覚野からの特徴情報を受け取り、局所コントラストを計算し、顕著性マップを生成する。

#### Requirement realization by interface
Interface ([U.mIPS]) = R.Bottom-Up-Saliency([U.V1], [U.V2], [U.V3], [U.V4], [U.MT], [U.IT], [U.Pulvinar]) により、[U.pIPS]でbottom-up saliency mapが計算される。

#### Capability
Center-surround差分フィルタによる局所コントラスト検出。Itti & Koch (2001)のSaliency map modelに基づく。

#### Mechanism
各視覚特徴チャネルでcenter-surround差分が計算され（F_i(x,y)）、正規化後に統合される（S_bu = Σ_i w_i·N(F_i)）。

### R.Goal-Directed-Priority

#### Requirement
探索目標に基づくトップダウン優先度を計算する。前頭皮質からの目標テンプレートと視覚情報を照合し、目標に関連する位置の優先度を上げる。

#### Requirement realization by interface
Interface ([U.mIPS]) = R.Goal-Directed-Priority([U.FEF], [U.DLPFC], [U.pIPS]) により、[U.pIPS]と[U.mIPS]で段階的に目標関連性が評価される。

#### Capability
目標テンプレートと視覚特徴の類似度計算。Guided Search 6.0のtop-down guidanceに基づく。

#### Mechanism
[U.pIPS]で初期的な類似度が計算され（S_td = sim(V, T)）、[U.mIPS]でより詳細な照合が実行される。

---

### R.Priority-Integration

#### Requirement
ボトムアップとトップダウン優先度を統合して最終優先度マップを生成する。

#### Requirement realization by interface
Interface ([U.mIPS], [U.FEF]) = R.Priority-Integration([R.Bottom-Up-Saliency], [R.Goal-Directed-Priority]) により、[U.pIPS]で両優先度が統合される。

#### Capability
加算的または乗算的な優先度統合。LIPニューロンの加算的統合に基づく（Thomas & Paré, 2007）。

#### Mechanism
P = α·S_bu + β·S_td + γ·Aによる統合。Surround suppressionで鋭敏化。

### R.Template-Matching

#### Requirement
視覚情報と探索目標の類似度を計算する。[U.pIPS]からの視覚情報と[U.DLPFC]からのテンプレートを[U.mIPS]で照合する。

#### Requirement realization by interface
Interface ([U.aIPS]) = R.Template-Matching([U.pIPS], [U.DLPFC]) により、[U.mIPS]でtemplate matchingが実行される。

#### Capability
視覚特徴ベクトル間の類似度計算。特徴空間での距離計算に基づく。

#### Mechanism
M_i = sim(V_i, T)による類似度計算。内積や正規化相関などの類似度関数。

### R.Attentional-Selection

#### Requirement
目標に関連する候補に注意を配分し、非関連刺激を抑制する。

#### Requirement realization by interface
Interface ([U.aIPS], [U.FEF]) = R.Attentional-Selection([U.pIPS], [U.FEF], [U.DLPFC]) により、子GN（R.Target-Candidate-Selection, R.Distractor-Suppression）を通じて選択が実現される。

#### Capability
選択的注意の配分。Guided Search 6.0の選択メカニズムに基づく。

#### Mechanism
注意スポットライトの配置と、候補選択・distractor抑制の並行実行。

---

### R.Target-Candidate-Selection

#### Requirement
一致度が高い候補を選択し、競合を解決する。

#### Requirement realization by interface
Interface ([U.aIPS]) = R.Target-Candidate-Selection([U.pIPS], [U.DLPFC]) により、[U.mIPS]で候補が選択される。

#### Capability
Winner-take-all機構による競合的選択。

#### Mechanism
S_i = M_i·A_i - Σ_{j≠i} w_ij·S_j による競合的相互抑制。

---

### R.Distractor-Suppression

#### Requirement
一致度が低い刺激を抑制する。

#### Requirement realization by interface
Interface ([U.aIPS]) = R.Distractor-Suppression([U.pIPS], [U.FEF]) により、[U.mIPS]でdistractorが抑制される。

#### Capability
Pop-inメカニズムによる持続的抑制。V4での観察に基づく。

#### Mechanism
D_i(t) = max(0, I_i(t) - k·(...)) による抑制。

### R.Evidence-Accumulation

#### Requirement
「目標が見つかった」という証拠を時間的に統合する。

#### Requirement realization by interface
Interface ([U.SC], [U.PMC]) = R.Evidence-Accumulation([U.mIPS]) により、[U.aIPS]で証拠が蓄積される。

#### Capability
Drift Diffusion Modelによる証拠蓄積。

#### Mechanism
dE/dt = μ·S + σ·η(t)による時間積分。

### R.Criterion-Comparison

#### Requirement
蓄積された証拠が判断に十分かを評価する。

#### Requirement realization by interface
Interface ([U.pIPS], [U.mIPS]) = R.Criterion-Comparison([U.mIPS], [U.DLPFC]) により、[U.aIPS]で閾値比較が実行される。

#### Capability
証拠と閾値の比較による判断確定。

#### Mechanism
Choice = arg max(E) if max(E) > θ_decision。

---

### R.Confidence-Evaluation

#### Requirement
判断の信頼性を評価する。

#### Requirement realization by interface
Interface ([U.FEF], [U.DLPFC]) = R.Confidence-Evaluation([U.mIPS], [U.FEF], [U.DLPFC]) により、[U.aIPS]で確信度が計算される。

#### Capability
証拠強度と判断時間から確信度を計算。ベイズ的確信度モデルに基づく（Sanders et al., 2016）。

#### Mechanism
Conf = (E_winner - E_loser)/RT または Conf = P(correct | E, Choice, RT)。
