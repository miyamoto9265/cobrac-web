# ステップ3: Uniform Circuit（UC）の定義

## 目的
BIFに基づいて、情報処理の基本単位となるUniform Circuit（UC）を定義する。

## UC採用基準
1. **ROI内に位置する**（最重要）
2. ROI内で必要な情報処理を担当している
3. 同質的な情報をコードしている神経組織である
4. メゾスコピックレベルとして適切な粒度（大きすぎず、小さすぎない）

---

## UC定義（完全版：Interface、Output Semantics、機能関連項目含む）

### `BLA` (Basolateral Amygdala)

| 項目 | 内容 |
| ---- | ---- |
| **Names** | Basolateral Amygdala (基底外側扁桃体) |
| **Comment** | CS-US連合学習の中心的役割を担う。条件刺激（CS）と無条件刺激（US）の時間的関連を学習し、恐怖記憶を形成・保持する。消去学習時には下辺縁皮質からの入力により消去記憶も保持する。外側扁桃体核（LA）を含む基底外側扁桃体複合体として統合的に扱う。 |
| **Interface** | [`CEA`, `ITC`, `PL`, `IL`] = `BLA`(`Thalamus_CS`, `Thalamus_US`, `vHPC`, `PL`, `IL`) |
| **Output Semantics** | [BLA]CS-US連合強度、恐怖記憶価、消去記憶価、文脈依存的恐怖評価値; |
| **A1. Requirement** | 恐怖条件づけ・消去・再発において、条件刺激（CS）と無条件刺激（US）の時間的連合を学習し、恐怖記憶を形成する。消去学習時には、CSに対する恐怖反応を抑制する消去記憶を形成・保持する。文脈情報とトップダウン制御信号を統合し、文脈依存的な恐怖評価値を出力する。恐怖条件づけフェーズではCS-US連合強度を高め、消去フェーズでは消去記憶価を高め、再発フェーズでは文脈に応じて恐怖記憶を再活性化する。 |
| **A2. Requirement realization by interface** | 入力として、条件刺激（Thalamus_CS）、無条件刺激（Thalamus_US）、文脈情報（vHPC）、トップダウン恐怖促進信号（PL）、トップダウン消去促進信号（IL）を受け取る。条件づけフェーズでは、Thalamus_CSとThalamus_USの時間的一致を検出してCS-US連合を強化し、CEAへ恐怖駆動信号を出力する。消去フェーズでは、ILからの消去促進信号とvHPCからの文脈情報を統合し、消去記憶を形成してITCを活性化し、CEA出力を抑制する。再発フェーズでは、PLからの恐怖促進信号とvHPCからの新文脈情報により恐怖記憶を再活性化し、再びCEAへ恐怖駆動信号を送る。同時に、PLとILへボトムアップの恐怖情報をフィードバックする。 |
| **B1. Capability** | 複数の入力信号（感覚刺激、文脈情報、トップダウン制御）を統合し、それらの時間的・文脈的関連性を学習する。学習により、特定の入力パターンに対する出力を可塑的に変化させる。異なる記憶痕跡（恐怖記憶と消去記憶）を並行して保持し、文脈とトップダウン信号に応じて適切な記憶痕跡を活性化する。 |
| **B2. Mechanism** | 連合学習はヘブ型シナプス可塑性により実現される。CS入力とUS入力が時間的に近接すると、CS→BLAシナプスが長期増強（LTP）され、CS単独でBLAが活性化されるようになる。消去学習では、CS入力とUS欠如の組み合わせ、およびILからの消去促進信号により、消去記憶を担う別のニューロン集団が活性化される。文脈情報とトップダウン信号は、恐怖記憶ニューロン集団と消去記憶ニューロン集団の競合的活性化を調節し、どちらの記憶が優位になるかを決定する。 |
| **B3. Implementation** | CS入力を x_CS、US入力を x_US、文脈入力を x_ctx、PL入力を x_PL、IL入力を x_IL とする。恐怖記憶ニューロンの活性を y_fear、消去記憶ニューロンの活性を y_ext とすると、y_fear = σ(w_CS_fear × x_CS + w_ctx_fear × x_ctx + w_PL × x_PL - w_IL_fear × x_IL)、y_ext = σ(w_CS_ext × x_CS + w_ctx_ext × x_ctx + w_IL × x_IL - w_PL_ext × x_PL)。ここで、σは活性化関数（シグモイドなど）。学習則として、恐怖条件づけ時には Δw_CS_fear = η × x_CS × x_US、消去学習時には Δw_CS_ext = η × x_CS × (1 - x_US) × x_IL。最終出力は y_BLA = y_fear - y_ext で競合的に決定される。 |

### `CEA` (Central Amygdala)

| 項目 | 内容 |
| ---- | ---- |
| **Names** | Central Amygdala (中心核) |
| **Comment** | 恐怖反応の出力中枢。BLAやITCからの情報を統合し、視床下部・中脳水道周囲灰白質・脳幹へ投射して、すくみ反応、自律神経反応、内分泌反応などの恐怖反応を実行する。 |
| **Interface** | [`Output_Fear`] = `CEA`(`BLA`, `ITC`) |
| **Output Semantics** | [CEA]恐怖反応実行強度、最終恐怖出力信号; |
| **A1. Requirement** | 恐怖条件づけ・消去・再発において、BLAからの恐怖駆動信号とITCからの抑制信号を統合し、最終的な恐怖反応実行強度を決定する。恐怖条件づけフェーズと再発フェーズでは強い恐怖出力を生成し、消去フェーズでは出力を抑制する。この出力信号を視床下部・PAG・脳幹へ送り、すくみ反応、自律神経反応、内分泌反応を実行する。 |
| **A2. Requirement realization by interface** | 入力として、BLAからの恐怖駆動信号（興奮性）とITCからの抑制信号（GABAergic）を受け取る。恐怖条件づけフェーズと再発フェーズでは、BLAからの強い興奮性入力によりCEAが活性化され、Output_Fearへ強い恐怖反応信号を出力する。消去フェーズでは、ITCからの強いGABAergic抑制によりCEA活性が低下し、Output_Fearへの出力が抑制される。これにより、行動レベルでの恐怖反応の発現/抑制が制御される。 |
| **B1. Capability** | 興奮性入力と抑制性入力を統合し、最終的な出力強度を決定する。興奮性入力が抑制性入力を上回る場合に出力を生成し、抑制性入力が優位な場合に出力を抑制する。出力は下流の実行系へ伝達され、多様な生理的・行動的反応を引き起こす。 |
| **B2. Mechanism** | CEAニューロンはBLAからの興奮性（グルタミン酸作動性）入力とITCからの抑制性（GABA作動性）入力の両方を受ける。これらの入力が時空間的に統合され、CEAニューロンの膜電位が決定される。膜電位が閾値を超えると活動電位が発火し、下流の視床下部・PAG・脳幹へ出力される。ITCからの抑制が強い場合、BLAからの興奮性入力があってもCEAニューロンは閾値に達せず、恐怖反応が抑制される。 |
| **B3. Implementation** | BLA入力を x_BLA、ITC抑制を x_ITC とする。CEA出力を y_CEA とすると、y_CEA = max(0, x_BLA - α × x_ITC - θ)。ここで、αは抑制ゲイン、θは発火閾値。x_ITC が大きい場合、y_CEA は0に近づき恐怖反応が抑制される。x_ITC が小さく x_BLA が大きい場合、y_CEA は大きな値となり強い恐怖反応が実行される。 |

### `ITC` (Intercalated Cells)

| 項目 | 内容 |
| ---- | ---- |
| **Names** | Intercalated Cells (介在細胞群) |
| **Comment** | 扁桃体の「オフスイッチ」として機能するGABAergic抑制性ニューロン群。BLAとCEAの間に位置し、消去学習時にILからの入力により活性化され、CEA出力を抑制して恐怖反応を抑制する。消去記憶の発現基盤。 |
| **Interface** | [`CEA`] = `ITC`(`BLA`, `IL`) |
| **Output Semantics** | [ITC]CEA抑制度、消去信号強度; |
| **A1. Requirement** | 恐怖条件づけ・消去・再発において、消去学習時にILからの消去促進信号を受け取り、CEAへの抑制を強化する。BLAからの入力とILからの入力を統合し、消去フェーズでCEA出力を抑制して恐怖反応を抑制する。恐怖条件づけフェーズと再発フェーズでは抑制を弱め、消去フェーズで抑制を強化する。 |
| **A2. Requirement realization by interface** | 入力として、BLAからの興奮性入力とILからの消去促進信号を受け取る。消去学習フェーズでは、ILからの強い入力によりITCが活性化され、CEAへ強いGABAergic抑制を送る。これによりCEA出力が抑制され、恐怖反応が抑制される。恐怖条件づけフェーズや再発フェーズでは、IL入力が弱いためITCの活性は低く、CEAへの抑制は弱い。BLAからの入力はITCの基礎活性を調節する。 |
| **B1. Capability** | 複数の興奮性入力を受け取り、それらを統合して抑制性出力の強度を決定する。特定の入力源（IL）からの信号により、出力強度を可塑的に増強する。出力はGABAergic抑制として下流ニューロンの活性を減少させる。 |
| **B2. Mechanism** | ITCはGABAergic抑制性ニューロンであり、BLAとILから興奮性（グルタミン酸作動性）入力を受ける。これらの入力が統合されてITCが活性化すると、CEAへGABAを放出し、CEAニューロンの膜電位を過分極させて発火を抑制する。消去学習により、IL→ITCシナプスが増強され、IL入力に対するITCの応答性が高まる。これにより、消去文脈においてILが活性化されると、ITCが強く活性化してCEAを効果的に抑制できるようになる。 |
| **B3. Implementation** | BLA入力を x_BLA、IL入力を x_IL とする。ITC活性を y_ITC とすると、y_ITC = σ(w_BLA × x_BLA + w_IL × x_IL)。ここで、w_IL は消去学習により増強されるシナプス重み。CEAへの抑制出力は y_ITC_out = β × y_ITC。ここで、βはGABAergic抑制ゲイン。消去学習則として、Δw_IL = η × x_IL × (x_CS_present × (1 - x_US))。消去学習により w_IL が増加し、IL入力に対するITC応答が増強される。 |

### `PL` (Prelimbic Cortex)

| 項目 | 内容 |
| ---- | ---- |
| **Names** | Prelimbic Cortex (前辺縁皮質) |
| **Comment** | 内側前頭前野の一部。恐怖の発現と恐怖再発を促進する。BLAへ興奮性投射を送り、文脈依存的な恐怖反応の発現を制御する。腹側海馬から文脈情報を受け取り、BLAへトップダウン制御を行う。 |
| **Interface** | [`BLA`, `IL`] = `PL`(`vHPC`, `BLA`, `IL`) |
| **Output Semantics** | [PL]文脈依存的恐怖促進信号、トップダウン恐怖バイアス; |
| **A1. Requirement** | 恐怖条件づけ・消去・再発において、腹側海馬からの文脈情報とBLAからのボトムアップ恐怖情報を統合し、文脈依存的な恐怖促進信号を生成する。恐怖条件づけフェーズと再発フェーズでは、BLAへ恐怖促進のトップダウンバイアスを送り、恐怖反応を増強する。消去フェーズでは活動を抑制し、恐怖促進を減弱させる。ILとの相互作用により、PLとILの競合的バランスを調節する。 |
| **A2. Requirement realization by interface** | 入力として、文脈情報（vHPC）、ボトムアップ恐怖情報（BLA）、IL相互作用信号（IL）を受け取る。恐怖条件づけフェーズと再発フェーズでは、vHPCからの特定文脈情報とBLAからの恐怖情報によりPLが活性化され、BLAへ恐怖促進信号を出力する。これによりBLAの恐怖記憶ニューロンが増強され、恐怖反応が促進される。消去フェーズでは、ILからの抑制的相互作用によりPL活動が低下し、恐怖促進が減弱する。PLはILへも投射し、PL-IL間の競合的バランスを形成する。 |
| **B1. Capability** | 文脈情報、ボトムアップ情報、局所相互作用信号を統合し、文脈依存的なトップダウン制御信号を生成する。特定の文脈において下流領域の活性を増強し、行動選択にバイアスをかける。他の前頭前野領域との相互作用により、複数のトップダウン信号のバランスを調節する。 |
| **B2. Mechanism** | PLは腹側海馬から文脈情報を受け取り、文脈表現を形成する。BLAからのボトムアップ恐怖情報がPLに到達すると、現在の文脈が恐怖条件づけ文脈や再発文脈と一致する場合、PLニューロンが活性化される。活性化されたPLニューロンは、BLAへ興奮性投射を送り、BLAの恐怖記憶ニューロンの興奮性を高める。これにより、恐怖反応が増強される。PLはILと相互抑制的な関係にあり、PLが優位な場合は恐怖が促進され、ILが優位な場合は消去が促進される。 |
| **B3. Implementation** | 文脈入力を x_ctx、BLA入力を x_BLA、IL入力を x_IL とする。PL活性を y_PL とすると、y_PL = σ(w_ctx × x_ctx + w_BLA × x_BLA - w_IL_PL × x_IL)。ここで、w_ctx は文脈依存的な重みで、恐怖条件づけ文脈や再発文脈で高い値を持つ。PLからBLAへの出力は y_PL_out = γ_PL × y_PL。この出力はBLAの恐怖記憶ニューロンを増強する。w_ctx の学習則として、恐怖条件づけ時や再発時に Δw_ctx = η × x_ctx × x_BLA。 |

### `IL` (Infralimbic Cortex)

| 項目 | 内容 |
| ---- | ---- |
| **Names** | Infralimbic Cortex (下辺縁皮質) |
| **Comment** | 内側前頭前野の一部。消去学習の獲得・保持・想起に必須。BLAとITCへ興奮性投射を送り、消去記憶を形成・維持する。消去訓練後にIL→BLA投射ニューロンの興奮性が増加し、恐怖反応の抑制を媒介する。 |
| **Interface** | [`BLA`, `ITC`, `PL`] = `IL`(`vHPC`, `BLA`, `PL`) |
| **Output Semantics** | [IL]文脈依存的消去促進信号、トップダウン恐怖抑制バイアス; |
| **A1. Requirement** | 恐怖条件づけ・消去・再発において、腹側海馬からの文脈情報とBLAからのボトムアップ恐怖情報を統合し、文脈依存的な消去促進信号を生成する。消去学習フェーズでは、BLAとITCへ消去促進のトップダウンバイアスを送り、消去記憶の形成と恐怖反応の抑制を促進する。恐怖条件づけフェーズと再発フェーズでは活動を抑制し、消去促進を減弱させる。PLとの相互作用により、IL-PL間の競合的バランスを調節する。 |
| **A2. Requirement realization by interface** | 入力として、文脈情報（vHPC）、ボトムアップ恐怖情報（BLA）、PL相互作用信号（PL）を受け取る。消去学習フェーズでは、vHPCからの消去文脈情報とBLAからの恐怖情報によりILが活性化され、BLAへ消去促進信号、ITCへ活性化信号を出力する。これによりBLAに消去記憶が形成され、ITCがCEAを抑制して恐怖反応が抑制される。恐怖条件づけフェーズと再発フェーズでは、PLからの抑制的相互作用によりIL活動が低下し、消去促進が減弱する。ILはPLへも投射し、IL-PL間の競合的バランスを形成する。 |
| **B1. Capability** | 文脈情報、ボトムアップ情報、局所相互作用信号を統合し、文脈依存的なトップダウン抑制制御信号を生成する。特定の文脈において下流領域の抑制的処理を増強し、行動抑制にバイアスをかける。他の前頭前野領域との相互作用により、複数のトップダウン信号のバランスを調節する。 |
| **B2. Mechanism** | ILは腹側海馬から文脈情報を受け取り、文脈表現を形成する。BLAからのボトムアップ恐怖情報がILに到達すると、現在の文脈が消去文脈と一致する場合、ILニューロンが活性化される。活性化されたILニューロンは、BLAへ興奮性投射を送り、BLAの消去記憶ニューロンの興奮性を高める。同時に、ITCへも興奮性投射を送り、ITCを活性化してCEAを抑制する。これにより、恐怖反応が抑制される。ILはPLと相互抑制的な関係にあり、ILが優位な場合は消去が促進され、PLが優位な場合は恐怖が促進される。 |
| **B3. Implementation** | 文脈入力を x_ctx、BLA入力を x_BLA、PL入力を x_PL とする。IL活性を y_IL とすると、y_IL = σ(w_ctx_ext × x_ctx + w_BLA_IL × x_BLA - w_PL_IL × x_PL)。ここで、w_ctx_ext は消去文脈で高い値を持つ重み。ILからBLAへの出力は y_IL_BLA = γ_IL_BLA × y_IL、ILからITCへの出力は y_IL_ITC = γ_IL_ITC × y_IL。これらの出力はBLAの消去記憶ニューロンとITCを増強する。w_ctx_ext の学習則として、消去学習時に Δw_ctx_ext = η × x_ctx × (x_CS × (1 - x_US))。 |

## UC選定の根拠

### ROI内UCの選定理由

#### `BLA` (Basolateral Amygdala)
- **ROI内**: 扁桃体の主要核
- **機能**: 恐怖条件づけの中心。CS（条件刺激）とUS（無条件刺激）の連合学習を担当
- **情報コーディング**: CS-US連合強度、恐怖記憶価、消去記憶
- **粒度**: 外側扁桃体核（LA）と基底核を含む複合体だが、恐怖条件づけ・消去・再発の文脈では統合的に扱うことが妥当

#### `CEA` (Central Amygdala)
- **ROI内**: 扁桃体の出力核
- **機能**: 恐怖反応の実行制御
- **情報コーディング**: 恐怖反応強度、実行信号
- **粒度**: CEA自体も細分化されるが（CeL, CeM等）、本TLFにおいては統合的な出力ノードとして扱うことが適切

#### `ITC` (Intercalated Cells)
- **ROI内**: 扁桃体のBLAとCEAの間に位置
- **機能**: 消去学習における恐怖反応の抑制
- **情報コーディング**: 消去信号、CEA出力抑制度
- **粒度**: 複数のITCクラスターが存在するが、消去学習における主要機能は共通しており、統合的に扱うことが妥当

#### `PL` (Prelimbic Cortex)
- **ROI内**: 前頭前野の内側部
- **機能**: 恐怖の発現促進、恐怖再発の制御
- **情報コーディング**: 文脈依存的な恐怖発現信号、トップダウン制御信号
- **粒度**: mPFCのサブリージョンとして機能的に独立

#### `IL` (Infralimbic Cortex)
- **ROI内**: 前頭前野の内側部
- **機能**: 消去学習の獲得・想起
- **情報コーディング**: 消去文脈信号、恐怖抑制信号
- **粒度**: mPFCのサブリージョンとして機能的に独立、PLと対照的な機能

## ROI外の主要入出力

### ROI外入力源
- **視床（Thalamus）**: 聴覚視床（MGm, PIN, Sg）、視覚視床（LG, LP）、後部視床（PIT）、外側視床（Calr+）
  - 役割: CS情報（聴覚・視覚）とUS情報（侵害刺激）をBLAへ伝達
- **腹側海馬（vHPC）**: 
  - 役割: 文脈情報をPL、IL、BLAへ伝達。文脈依存的な恐怖調節と消去学習を支援

### ROI外出力先
- **視床下部（Hypothalamus）**: CEAから投射
