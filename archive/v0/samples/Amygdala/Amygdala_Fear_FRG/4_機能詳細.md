# ステップ4: 機能関連項目の定義（TLFとGN）

## 目的
TLFおよび各GNが実行する機能を詳細に定義する。

---

## 機能詳細表

### TLF: 恐怖条件づけ・消去・再発

| 項目 | 内容 |
| ---- | ---- |
| **A1. Requirement** | 中性刺激（条件刺激: CS）と嫌悪刺激（無条件刺激: US）を時間的に連合させることで、CSが恐怖反応を引き起こすようになる学習プロセスを実現する。その後、CSを繰り返し提示してもUSが続かない場合、CSに対する恐怖反応を減弱させる消去学習を実現する。さらに、文脈が変化した場合に恐怖反応を再発させるプロセスを実現する。これら3つの連続的なプロセスにより、環境の変化に応じて柔軟に恐怖反応を調節する機能を提供する。 |
| **A2. Requirement realization by children** | 3つの子ノード（恐怖条件づけ、消去学習、恐怖再発）により実現される。恐怖条件づけでCS-US連合により恐怖記憶を形成し恐怖反応を獲得する。消去学習でCS-US非連合により消去記憶を形成し恐怖反応を抑制する。恐怖再発で文脈変化により消去を解除し恐怖記憶を再活性化して恐怖反応を再発させる。これら3つのプロセスが連続的に実行されることで、TLF全体が実現される。 |
| **B1. Capability** | 複数の入力信号（条件刺激、無条件刺激、文脈情報）を統合し、それらの時間的・文脈的関連性を学習する。学習により、特定の入力パターンに対する出力（恐怖反応）を可塑的に変化させる。異なる記憶痕跡（恐怖記憶と消去記憶）を並行して保持し、文脈に応じて適切な記憶痕跡を選択的に活性化する。これにより、環境の変化に適応的に反応する能力を提供する。 |
| **B2. Mechanism** | 連合学習は、条件刺激と無条件刺激の同時提示により、両刺激をコードする神経回路間にシナプス結合を形成することで実現される。この結合により、条件刺激単独で恐怖反応が誘発されるようになる。消去学習では、条件刺激のみの繰り返し提示により、新たな消去記憶回路が形成され、元の恐怖記憶回路を抑制する。文脈情報は、どちらの記憶回路を活性化するかを決定するゲート信号として機能し、文脈変化により恐怖記憶回路が再び優位になる。 |
| **B3. Implementation** | CS入力をx_CS、US入力をx_US、文脈入力をx_ctxとする。恐怖記憶の強度をw_fear、消去記憶の強度をw_extとする。恐怖条件づけ時: Δw_fear = η × x_CS × x_US。消去学習時: Δw_ext = η × x_CS × (1 - x_US)。出力（恐怖反応）をyとすると、y = σ(w_fear × x_CS × (1 - x_ctx_ext) + w_ext × x_CS × x_ctx_ext × (-1))。ここで、x_ctx_extは消去文脈を示す変数、σは活性化関数。文脈変化により x_ctx_ext が減少すると、恐怖記憶が優位となり恐怖反応が再発する。 |

### GN (第2階層): 恐怖条件づけ

| 項目 | 内容 |
| ---- | ---- |
| **A1. Requirement** | 条件刺激（CS）と無条件刺激（US）の時間的連合を学習し、CS-US連合に基づいて恐怖記憶を形成・保持する。形成された恐怖記憶をCS入力により想起し、恐怖駆動信号を生成する。この信号に基づいて、すくみ反応、自律神経反応、内分泌反応などの行動的・生理的な恐怖反応を実行する。これにより、中性刺激が嫌悪刺激と連合されることで恐怖反応を引き起こすようになる学習プロセスを実現する。 |
| **A2. Requirement realization by children** | 2つの子ノード（恐怖記憶システム、恐怖反応実行）により実現される。恐怖記憶システムがCS-US連合を学習し、恐怖記憶を形成・保持・想起して恐怖駆動信号を生成する。恐怖反応実行がこの信号を受け取り、行動的・生理的な恐怖反応を実行する。これら2つの子ノードの組み合わせにより、恐怖条件づけが実現される。 |
| **B1. Capability** | 複数の入力信号（条件刺激、無条件刺激）の時間的関連性を検出し、連合学習により記憶を形成する。形成された記憶を条件刺激により想起し、出力信号を生成する。出力信号は下流の実行系に伝達され、多様な行動的・生理的反応を引き起こす。 |
| **B2. Mechanism** | 条件刺激と無条件刺激が時間的に近接して提示されると、両刺激をコードする神経回路間にヘブ型シナプス可塑性により結合が形成される（長期増強: LTP）。この結合により、条件刺激単独で恐怖記憶回路が活性化され、恐怖駆動信号が生成される。この信号は出力回路に伝達され、恐怖反応を実行する。 |
| **B3. Implementation** | CS入力をx_CS、US入力をx_USとする。CS-US連合強度（シナプス重み）をw_CS_USとすると、学習則は Δw_CS_US = η × x_CS × x_US。恐怖駆動信号y_fearは y_fear = σ(w_CS_US × x_CS)。ここでσは活性化関数。恐怖反応出力y_responseは y_response = f(y_fear)、fは出力実行関数。 |

### GN (第2階層): 消去学習

| 項目 | 内容 |
| ---- | ---- |
| **A1. Requirement** | 条件刺激（CS）を繰り返し提示しても無条件刺激（US）が続かない場合、CS-US非連合を検出し、消去記憶を形成・保持する。消去記憶に基づいて恐怖反応の出力を抑制する制御信号を生成し、恐怖反応の出力経路をゲーティングして遮断する。これにより、条件刺激に対する恐怖反応を減弱させる学習プロセスを実現する。 |
| **A2. Requirement realization by children** | 2つの子ノード（消去記憶システム、恐怖出力ゲーティング）により実現される。消去記憶システムがCS-US非連合を検出し、消去記憶を形成・保持・想起して恐怖抑制信号を生成する。恐怖出力ゲーティングがこの抑制信号に基づいて恐怖反応の出力経路を遮断する。これら2つの子ノードの組み合わせにより、消去学習が実現される。 |
| **B1. Capability** | 条件刺激のみの繰り返し提示（無条件刺激の欠如）を検出し、新たな記憶痕跡を形成する。この記憶に基づいて抑制制御信号を生成し、出力経路をゲーティングして特定の反応を抑制する。 |
| **B2. Mechanism** | 条件刺激が提示されても無条件刺激が続かない場合、条件刺激と無条件刺激欠如の組み合わせが新たな記憶痕跡（消去記憶）を形成する。この消去記憶は、恐怖記憶とは別の神経回路に保持される。消去記憶が想起されると、抑制性の制御信号が生成され、恐怖反応の出力経路に位置するゲート回路を活性化する。ゲート回路は抑制性ニューロンから構成され、恐怖出力回路を抑制して恐怖反応を遮断する。 |
| **B3. Implementation** | CS入力をx_CS、US入力をx_USとする。消去記憶強度をw_extとすると、学習則は Δw_ext = η × x_CS × (1 - x_US)。消去信号y_extは y_ext = σ(w_ext × x_CS)。ゲーティング信号y_gateは y_gate = β × y_ext、βは抑制ゲイン。最終恐怖出力y_outputは y_output = max(0, y_fear - α × y_gate)、αは抑制効果係数。 |

### GN (第2階層): 恐怖再発

| 項目 | 内容 |
| ---- | ---- |
| **A1. Requirement** | 消去学習後、文脈が変化した場合に、文脈変化を検出し、恐怖記憶の再活性化を促進するバイアス信号を生成する。このバイアスにより、消去記憶の影響を抑制し、恐怖記憶を再活性化して恐怖駆動信号を生成する。この信号に基づいて恐怖反応を実行し、恐怖反応を再発させる。これにより、環境文脈の変化により消去された恐怖反応が再び出現するプロセスを実現する。 |
| **A2. Requirement realization by children** | 3つの子ノード（文脈依存的恐怖促進、恐怖記憶システム、恐怖反応実行）により実現される。文脈依存的恐怖促進が文脈変化を検出し、恐怖促進バイアス信号を生成して消去の影響を抑制する。恐怖記憶システムがこのバイアスにより恐怖記憶を再活性化し、恐怖駆動信号を生成する。恐怖反応実行がこの信号に基づいて恐怖反応を実行する。これら3つの子ノードの組み合わせにより、恐怖再発が実現される。 |
| **B1. Capability** | 文脈情報の変化を検出し、それに応じてバイアス信号を生成する。バイアス信号により、複数の並行する記憶痕跡（恐怖記憶と消去記憶）の競合的活性化を制御し、特定の記憶（恐怖記憶）を優位にする。優位になった記憶により生成される出力信号を実行系に伝達し、反応を再発させる。 |
| **B2. Mechanism** | 文脈情報をコードする神経回路（海馬）が、現在の文脈と消去文脈との差異を検出する。文脈が変化すると、トップダウン制御回路（前頭前野）が恐怖促進バイアス信号を生成し、記憶回路（扁桃体）に投射する。このバイアス信号により、恐怖記憶ニューロン集団の興奮性が高まり、消去記憶ニューロン集団の影響が相対的に減弱する。結果として、恐怖記憶が再活性化され、恐怖駆動信号が再び生成される。この信号は出力回路に伝達され、恐怖反応が再発する。 |
| **B3. Implementation** | 文脈入力をx_ctx、消去文脈をx_ctx_extとする。文脈変化検出信号をd_ctx = \|x_ctx - x_ctx_ext\|とする。恐怖促進バイアスy_biasは y_bias = γ × d_ctx、γはバイアスゲイン。恐怖記憶活性y_fearは y_fear = σ(w_fear × x_CS + y_bias)。消去記憶活性y_extは y_ext = σ(w_ext × x_CS - y_bias)。最終出力は y_output = max(0, y_fear - y_ext)。文脈変化によりy_biasが増加し、恐怖記憶が優位となる。 |

### GN (第3階層): 恐怖記憶システム

| 項目 | 内容 |
| ---- | ---- |
| **A1. Requirement** | 条件刺激（CS）と無条件刺激（US）の時間的連合を学習し、CS-US連合に基づいて恐怖記憶を形成・保持する。CS入力により恐怖記憶を想起し、恐怖駆動信号を生成する。恐怖再発時には、文脈依存的な恐怖促進バイアスを受け取り、恐怖記憶を再活性化する。これにより、恐怖条件づけと恐怖再発の両方において、恐怖記憶の形成・保持・想起・再活性化を実現する。 |
| **A2. Requirement realization by children** | 2つのUC（BLA, PL）により実現される。BLAがCS-US連合を学習し、恐怖記憶を形成・保持・想起する中心的役割を担う。PLが文脈情報を受け取り、文脈依存的な恐怖促進バイアス信号をBLAへ送ることで、恐怖記憶の再活性化を促進する。BLAとPLの協調により、恐怖記憶システムが実現される。 |
| **B1. Capability** | 複数の入力信号（条件刺激、無条件刺激、文脈情報、トップダウンバイアス）を統合し、時間的連合を学習して記憶を形成する。記憶を長期保持し、条件刺激やバイアス信号により選択的に想起する。トップダウンバイアスにより、記憶の活性化強度を動的に調節する。 |
| **B2. Mechanism** | 条件刺激と無条件刺激の同時提示により、両刺激をコードするシナプス間にヘブ型可塑性（LTP）が生じ、記憶痕跡が形成される。この記憶は特定のニューロン集団の結合パターンとして保持される。条件刺激により記憶が想起され、恐怖駆動信号が生成される。トップダウンバイアス信号（前頭前野から）は、記憶ニューロン集団の興奮性を増強し、想起を促進する。文脈情報は、どの程度のバイアスを適用するかを調節する。 |
| **B3. Implementation** | CS入力をx_CS、US入力をx_US、トップダウンバイアスをx_biasとする。恐怖記憶のシナプス重みをw_fearとすると、学習則は Δw_fear = η × x_CS × x_US。恐怖記憶活性y_fearは y_fear = σ(w_fear × x_CS + x_bias)。ここでx_biasはPLから提供される文脈依存的バイアス。σは活性化関数。バイアスが大きいほど、恐怖記憶の活性が増強される。 |

### GN (第3階層): 恐怖反応実行

| 項目 | 内容 |
| ---- | ---- |
| **A1. Requirement** | 恐怖記憶システムから生成される恐怖駆動信号を受け取り、その信号に基づいて最終的な恐怖反応実行強度を決定する。決定された強度に応じて、すくみ反応、自律神経反応（心拍増加、血圧上昇、発汗）、内分泌反応（ストレスホルモン分泌）などの多様な行動的・生理的恐怖反応を実行する。恐怖条件づけと恐怖再発の両方において、恐怖反応の実行を担う。 |
| **A2. Requirement realization by children** | 2つのUC（BLA, CEA）により実現される。BLAが恐怖記憶を想起して恐怖駆動信号を生成する。CEAがこの信号を受け取り、視床下部・中脳水道周囲灰白質・脳幹へ投射して、最終的な恐怖反応を実行する。BLAとCEAの連携により、恐怖反応実行が実現される。 |
| **B1. Capability** | 上流からの駆動信号を受け取り、その強度に応じて下流の実行系へ出力を送る。出力は複数の経路に分散され、各経路が異なる種類の反応（行動、自律神経、内分泌）を制御する。信号強度が閾値を超えた場合にのみ出力を生成し、閾値以下では出力を抑制する。 |
| **B2. Mechanism** | 恐怖駆動信号が出力ニューロン（CEA）に到達すると、ニューロンの膜電位が上昇する。膜電位が発火閾値を超えると活動電位が発生し、下流の実行系（視床下部、PAG、脳幹）へ出力される。各下流領域は特定の恐怖反応成分を制御する。視床下部は自律神経反応、PAGは行動反応、脳幹は内分泌反応などを担当する。駆動信号の強度が大きいほど、発火頻度が高まり、恐怖反応が強くなる。 |
| **B3. Implementation** | BLAからの恐怖駆動信号をx_BLAとする。CEA出力をy_CEAとすると、y_CEA = max(0, x_BLA - θ)。ここでθは発火閾値。y_CEAが各実行系へ分配される: y_autonomic = k_auto × y_CEA（自律神経反応）、y_behavioral = k_behav × y_CEA（行動反応）、y_endocrine = k_endo × y_CEA（内分泌反応）。k_auto、k_behav、k_endoは各経路の結合重み。 |

### GN (第3階層): 消去記憶システム

| 項目 | 内容 |
| ---- | ---- |
| **A1. Requirement** | 条件刺激（CS）を繰り返し提示しても無条件刺激（US）が続かない場合、CS-US非連合を検出し、消去記憶を形成・保持する。消去記憶をCS入力により想起し、恐怖抑制信号を生成する。このシステムは、下辺縁皮質からの消去促進のトップダウン支援を受けることで、消去記憶の形成と保持を強化する。これにより、消去学習において恐怖反応を抑制する基盤を提供する。 |
| **A2. Requirement realization by children** | 2つのUC（BLA, IL）により実現される。BLAがCS-US非連合（US欠如）を検出し、消去記憶を形成・保持・想起する。ILが文脈情報を受け取り、消去促進のトップダウン信号をBLAへ送ることで、消去記憶の形成を支援する。BLAとILの協調により、消去記憶システムが実現される。 |
| **B1. Capability** | 条件刺激のみの繰り返し提示（無条件刺激の欠如）を検出し、新たな記憶痕跡を形成する。この記憶を長期保持し、条件刺激により選択的に想起する。トップダウン支援信号により、記憶形成と想起を促進する。 |
| **B2. Mechanism** | 条件刺激が提示されても無条件刺激が続かない場合、条件刺激とUS欠如の組み合わせ、およびトップダウン消去促進信号（下辺縁皮質から）により、消去記憶を担うニューロン集団が活性化される。このニューロン集団は恐怖記憶ニューロン集団とは別個に存在し、消去記憶痕跡を保持する。消去記憶が想起されると、恐怖抑制信号が生成され、下流のゲート回路を活性化する。トップダウン信号は消去記憶ニューロンの興奮性を増強し、消去記憶の形成と想起を促進する。 |
| **B3. Implementation** | CS入力をx_CS、US入力をx_US、ILからのトップダウン信号をx_ILとする。消去記憶のシナプス重みをw_extとすると、学習則は Δw_ext = η × x_CS × (1 - x_US) × x_IL。消去記憶活性y_extは y_ext = σ(w_ext × x_CS + x_IL)。ここでx_ILは消去記憶の想起も促進する。恐怖抑制信号はy_suppression = β × y_ext、βは抑制ゲイン。 |

### GN (第3階層): 恐怖出力ゲーティング

| 項目 | 内容 |
| ---- | ---- |
| **A1. Requirement** | 消去記憶システムから生成される恐怖抑制信号を受け取り、その信号に基づいて恐怖反応の出力経路を遮断する。下辺縁皮質からITC活性化信号を受け取り、ITCを活性化する。活性化されたITCがCEAへGABAergic抑制を送り、CEA出力を抑制して恐怖反応を遮断する。これにより、消去学習において恐怖反応の実行を抑制するゲーティング機能を実現する。 |
| **A2. Requirement realization by children** | 2つのUC（IL, ITC）により実現される。ILが消去記憶に基づいてITC活性化信号を生成する。ITCがこの信号を受け取り、CEAへGABAergic抑制を送ってCEA出力を抑制する。ILとITCの連携により、恐怖出力ゲーティングが実現される。 |
| **B1. Capability** | 上流からの抑制制御信号を受け取り、その信号に基づいて下流の出力経路をゲーティング（遮断）する。ゲーティングは抑制性ニューロンの活性化により実現され、出力ニューロンの活動を抑制する。制御信号の強度が大きいほど、ゲーティング効果が強くなる。 |
| **B2. Mechanism** | 抑制制御信号（下辺縁皮質から）がゲートニューロン（ITC）を活性化する。活性化されたITCニューロンは、出力ニューロン（CEA）へGABA（抑制性神経伝達物質）を放出し、CEAニューロンの膜電位を過分極させる。過分極によりCEAニューロンの発火が抑制され、下流の実行系への出力が遮断される。制御信号が強いほど、ITCの発火頻度が高まり、CEA抑制が強化される。 |
| **B3. Implementation** | ILからの制御信号をx_ILとする。ITC活性をy_ITCとすると、y_ITC = σ(w_IL_ITC × x_IL)。w_IL_ITCはIL→ITCシナプス重みで、消去学習により増強される: Δw_IL_ITC = η × x_IL × (x_CS × (1 - x_US))。ITCからCEAへの抑制はy_inhibition = α × y_ITC、αは抑制ゲイン。最終CEA出力はy_CEA = max(0, x_BLA - y_inhibition - θ)。y_inhibitionが大きいほど、CEA出力が抑制される。 |

### GN (第3階層): 文脈依存的恐怖促進

| 項目 | 内容 |
| ---- | ---- |
| **A1. Requirement** | 腹側海馬から文脈情報を受け取り、消去文脈と新文脈の差異を検出する。文脈が変化した場合、恐怖記憶の再活性化を促進するバイアス信号を生成し、基底外側扁桃体へ送る。同時に、消去記憶の影響を抑制し、恐怖記憶を優位にする。これにより、恐怖再発において文脈依存的な恐怖促進を実現する。 |
| **A2. Requirement realization by children** | 2つのUC（PL, BLA）により実現される。PLが文脈情報（海馬から）を受け取り、文脈変化を検出して恐怖促進バイアス信号を生成する。BLAがこのバイアス信号を受け取り、恐怖記憶ニューロンの興奮性を増強して恐怖記憶を再活性化する。PLとBLAの協調により、文脈依存的恐怖促進が実現される。 |
| **B1. Capability** | 文脈情報の変化を検出し、それに応じてバイアス信号を生成する。バイアス信号を下流の記憶回路に送り、特定の記憶痕跡の活性を選択的に増強する。これにより、文脈に依存して記憶の想起強度を動的に調節する。 |
| **B2. Mechanism** | 文脈情報（海馬から）がトップダウン制御ニューロン（前辺縁皮質）に入力される。現在の文脈と消去文脈との差異が大きい場合、トップダウンニューロンが活性化され、恐怖促進バイアス信号を生成する。このバイアス信号は記憶ニューロン（基底外側扁桃体の恐怖記憶ニューロン）に投射され、ニューロンの興奮性を増強する。結果として、条件刺激に対する恐怖記憶の応答性が高まり、恐怖駆動信号が強化される。 |
| **B3. Implementation** | 文脈入力をx_ctx、消去文脈をx_ctx_extとする。文脈変化検出信号をd_ctx = \|x_ctx - x_ctx_ext\|とする。PLの活性y_PLは y_PL = σ(w_ctx × d_ctx + x_BLA_feedback)。ここでx_BLA_feedbackはBLAからのフィードバック。PLからBLAへの恐怖促進バイアスはy_bias = γ × y_PL、γはバイアスゲイン。BLAの恐怖記憶活性はy_fear = σ(w_fear × x_CS + y_bias)。y_biasにより恐怖記憶が増強される。 |

## まとめ

TLF（恐怖条件づけ・消去・再発）と、第2階層の3つのGN（恐怖条件づけ、消去学習、恐怖再発）、および第3階層の5つのGN（恐怖記憶システム、恐怖反応実行、消去記憶システム、恐怖出力ゲーティング、文脈依存的恐怖促進）について、機能関連項目（A1, A2, B1, B2, B3）を定義した。

各ノードの機能が親ノードの要求と整合し、子ノード群により実現されることが確認された。次のステップ5では、これらの定義に基づいて最終レポートを作成する。
