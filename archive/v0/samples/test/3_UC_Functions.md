# ステップ6: 機能関連項目の詳細定義

本ファイルでは、ROI内の各Uniform Circuitについて、以下の5つの機能関連項目を定義する：
1. Requirement
2. Requirement realization by interface
3. Capability
4. Mechanism
5. Implementation

注：機能記述内では、Uniform Circuitを[U.(UC名)]の形式で記述する。

---

## `L1` - Lamina monopolar cell L1

### Requirement
`L1`は、視覚情報処理全般（TLF）を実現するために、光受容体[U.R1-R6]から得られる[R1-R6]局所視野の時間的輝度変化を表現する広帯域光強度信号を、正のコントラスト変化（明るさの増加）に選択的に応答する信号へと変換する。出力は[L1]正のコントラスト変化（明るさの増加）を表現する時間的に濾波されたON信号として、[U.Mi1]、[U.Tm3]、[U.Mi4]、[U.Mi9]、[U.Dm3]へ伝達される。これにより、ON運動検出経路および方位検出経路への入力を提供する。

### Requirement realization by interface
Interfaceは ([`Mi1`], [`Tm3`], [`Mi4`], [`Mi9`], [`Dm3`], [`L2`]) = `L1`([`R1-R6`]) と定義されている。入力として[U.R1-R6]からの広帯域輝度信号を受け取り、出力として複数のメデュラニューロン（[U.Mi1]、[U.Tm3]、[U.Mi4]、[U.Mi9]、[U.Dm3]）およびラミナの[U.L2]へ信号を送る。これはRequirementで記述された「光受容体からの輝度信号を受け取り、複数の下流UCへON信号を分配する」という機能と整合している。

### Capability
入力信号から正の変化成分を選択的に抽出し、時間的濾波を適用して下流へ伝達する。これはハイパスフィルタリングとON経路選択性の組み合わせとして理解できる。この計算は、視覚神経科学における古典的なON/OFF経路分離の神経実装であり、脊椎動物のON型双極細胞と機能的に相同である（Joesch et al., 2010, Nature）。時間的濾波特性は、動く刺激に対する応答の最適化に寄与する（Behnia et al., 2014, Nature）。

### Mechanism
[U.L1]は、[U.R1-R6]からのグルタミン酸作動性入力を受け取り、膜電位の変化として正のコントラストを表現する。具体的には、光受容体の脱分極に応じて過分極し（sign-inverting synapse）、その後の内在的膜特性により適応的な応答を生成する。時間的濾波は、シナプス伝達の動特性と膜の時定数により実現される。下流のメデュラニューロンへは、コリン作動性の興奮性シナプスを介して信号を伝達する。

### Implementation
[U.L1] = HPF([U.R1-R6]⁺)

ここで、HPFはハイパスフィルタ、[U.R1-R6]⁺は正の変化成分（ON成分）を表す。

---

## `L2` - Lamina monopolar cell L2

### Requirement
`L2`は、視覚情報処理全般（TLF）を実現するために、光受容体[U.R1-R6]から得られる[R1-R6]局所視野の時間的輝度変化を表現する広帯域光強度信号を、負のコントラスト変化（明るさの減少）に選択的に応答する信号へと変換する。出力は[L2]負のコントラスト変化（明るさの減少）を表現する時間的に濾波されたOFF信号として、[U.Tm1]、[U.Tm2]、[U.Tm4]へ伝達される。これにより、OFF運動検出経路への入力を提供する。

### Requirement realization by interface
Interfaceは ([`Tm1`], [`Tm2`], [`Tm4`], [`L1`]) = `L2`([`R1-R6`]) と定義されている。入力として[U.R1-R6]からの広帯域輝度信号を受け取り、出力として複数のメデュラニューロン（[U.Tm1]、[U.Tm2]、[U.Tm4]）および[U.L1]へ信号を送る。[U.L1]との双方向接続は電気的結合（ギャップジャンクション）を表し、ON/OFF経路間の相互作用を可能にする。これはRequirementと整合している。

### Capability
入力信号から負の変化成分を選択的に抽出し、時間的濾波を適用して下流へ伝達する。これはハイパスフィルタリングとOFF経路選択性の組み合わせである。[U.L1]との電気的結合により、ON/OFF経路間でコントラスト情報の交換が可能となり、視覚適応やコントラスト正規化に寄与する（Joesch et al., 2010, Nature）。

### Mechanism
[U.L2]は、[U.R1-R6]からのグルタミン酸作動性入力を受け取り、[U.L1]と同様に光受容体の脱分極に応じて過分極するが、その後の処理により負のコントラストに選択的な応答を生成する。[U.L1]とはギャップジャンクションにより電気的に結合しており、両経路間で電流が流れることでコントラスト適応が促進される。

### Implementation
[U.L2] = HPF([U.R1-R6]⁻) + α·[U.L1]

ここで、[U.R1-R6]⁻は負の変化成分（OFF成分）、αは電気的結合の結合係数を表す。

---

## `Mi1` - Medulla intrinsic neuron Mi1

### Requirement
`Mi1`は、ON運動検出を実現するために、[U.L1]から得られる[L1]正のコントラスト変化（明るさの増加）を表現する時間的に濾波されたON信号を、時間的に遅延させた信号へと変換する。出力は[Mi1]時間的に遅延した正コントラスト信号として[U.T4]へ伝達され、Hassenstein-Reichardt相関器モデルにおける遅延経路を実装する。

### Requirement realization by interface
Interfaceは ([`T4`]) = `Mi1`([`L1`]) と定義されている。[U.L1]から入力を受け、[U.T4]へ出力する単純な中継構造であり、Requirementで記述された遅延信号生成機能と整合している。

### Capability
入力信号に時間遅延を付加する。この遅延は、Hassenstein-Reichardt型の運動検出器における必須要素であり、空間的に隣接する2つの視点からの信号の時間的相関を計算することで方向選択性を生成する（Takemura et al., 2017, eLife; Behnia et al., 2014, Nature）。遅延の時間スケールは約50-100ミリ秒程度で、ハエが検出する運動速度範囲に最適化されている。

### Mechanism
[U.Mi1]は、[U.L1]からの興奮性入力を受け取り、シナプス伝達の動特性と内在的膜特性により時間遅延を生成する。具体的には、シナプス後受容体の脱感作や膜の時定数により、入力信号に対して遅延した応答が生成される。この遅延信号は、[U.T4]へグルタミン酸作動性の興奮性シナプスを介して伝達される。

### Implementation
[U.Mi1](t) = [U.L1](t - τ₁)

ここで、τ₁は時間遅延（約50-100 ms）を表す。

---

## `Tm3` - Transmedullary neuron Tm3

### Requirement
`Tm3`は、ON運動検出を実現するために、[U.L1]から得られる[L1]正のコントラスト変化（明るさの増加）を表現する時間的に濾波されたON信号を、時間的に非遅延の信号として[U.T4]へ伝達する。出力は[Tm3]時間的に非遅延の正コントラスト信号であり、Hassenstein-Reichardt相関器モデルにおける非遅延経路（即時応答経路）を実装する。

### Requirement realization by interface
Interfaceは ([`T4`]) = `Tm3`([`L1`]) と定義されている。[U.L1]から入力を受け、[U.T4]へ出力する。[U.Mi1]と対比して、こちらは非遅延経路を形成する。

### Capability
入力信号を最小限の遅延で下流へ伝達する。[U.Mi1]の遅延経路と対になることで、[U.T4]において2つの時間的にずれた信号が統合され、乗算様の非線形演算により方向選択性が生成される（Behnia et al., 2014, Nature）。

### Mechanism
[U.Tm3]は、[U.L1]からの興奮性入力を高速なシナプス伝達により即座に[U.T4]へ中継する。シナプス後応答の時定数が短く、入力に対してほぼ遅延なく応答する。

### Implementation
[U.Tm3](t) = [U.L1](t)

---

## `T4` - T4 direction-selective cells

### Requirement
`T4`は、ON運動検出を実現するために、[U.Mi1]から得られる[Mi1]時間的に遅延した正コントラスト信号と、[U.Tm3]から得られる[Tm3]時間的に非遅延の正コントラスト信号を統合し、空間的に隣接する視点間の時間的相関を計算することで方向選択的な応答を生成する。さらに[U.Mi4]、[U.Mi9]からの追加入力により応答が調整される。出力は[T4]正コントラストエッジの方向選択的運動信号（4つの基本方向：前後・上下）として、[U.HS]および[U.VS]へ伝達される。

### Requirement realization by interface
Interfaceは ([`HS`], [`VS`]) = `T4`([`Mi1`], [`Tm3`], [`Mi4`], [`Mi9`]) と定義されている。複数の入力（遅延経路[U.Mi1]と非遅延経路[U.Tm3]、調整入力[U.Mi4]、[U.Mi9]）を受け取り、広視野運動統合を行う[U.HS]と[U.VS]へ出力する。これはRequirementで記述された方向選択的運動検出機能と整合している。

### Capability
空間的に隣接する2つの視点からの時間的にずれた信号を非線形に統合し、方向選択性を生成する。これはHassenstein-Reichardt相関器の神経実装であり、乗算様の非線形演算（ANDゲート様の演算）により、特定の方向の運動に対してのみ強く応答する（Takemura et al., 2013, Nature; Behnia et al., 2014, Nature）。4つのサブタイプ（T4a, b, c, d）がそれぞれ4つの基本方向（前方、後方、上方、下方）に選択的に応答する。

### Mechanism
[U.T4]は、樹状突起の異なる空間位置で[U.Mi1]（遅延）と[U.Tm3]（非遅延）からの入力を受け取る。樹状突起内での非線形な統合（例：NMDAレセプタ介在の電圧依存的な統合）により、2つの入力が時空間的に一致した場合にのみ強い脱分極が生じる。この非線形統合により、優先方向の運動に対して選択的な応答が生成される。4つのサブタイプは樹状突起の空間配置と入力の組み合わせにより異なる方向選択性を獲得する。

### Implementation
[U.T4] = Σᵢ ([U.Mi1]ᵢ₊Δ · [U.Tm3]ᵢ) + β·[U.Mi4] + γ·[U.Mi9]

ここで、iは空間位置、Δは優先方向へのオフセット、·は非線形乗算様の演算、β、γは調整係数を表す。

## `T5` - T5 direction-selective cells

### Requirement
`T5`は、OFF運動検出を実現するために、[U.Tm1]から得られる[Tm1]時間的に遅延した負コントラスト信号と、[U.Tm2]から得られる[Tm2]時間的に非遅延の負コントラスト信号を統合し、空間的に隣接する視点間の時間的相関を計算することで方向選択的な応答を生成する。さらに[U.Tm4]からの追加入力により応答が調整される。出力は[T5]負コントラストエッジの方向選択的運動信号（4つの基本方向：前後・上下）として、[U.HS]および[U.VS]へ伝達される。

### Requirement realization by interface
Interfaceは ([`HS`], [`VS`]) = `T5`([`Tm1`], [`Tm2`], [`Tm4`]) と定義されている。OFF経路の遅延経路[U.Tm1]と非遅延経路[U.Tm2]、調整入力[U.Tm4]を受け取り、[U.HS]と[U.VS]へ出力する。これは[U.T4]と並列なOFF運動検出経路を形成する。

### Capability
[U.T4]と同様に、Hassenstein-Reichardt相関器を実装するが、負のコントラスト（暗いエッジ）の運動を検出する。ON/OFF運動検出の並列処理により、視覚系は明暗両方のエッジ運動を同時に処理でき、複雑な自然場面での運動検出の頑健性が向上する（Behnia et al., 2014, Nature）。

### Mechanism
[U.T5]の機構は[U.T4]と本質的に同じであるが、入力がOFF経路（[U.Tm1]、[U.Tm2]）から来る点が異なる。樹状突起での非線形統合により方向選択性が生成される。

### Implementation
[U.T5] = Σᵢ ([U.Tm1]ᵢ₊Δ · [U.Tm2]ᵢ) + β·[U.Tm4]

---

## `HS` - Horizontal System cells

### Requirement
`HS`は、広視野水平運動の検出を実現するために、[U.T4]および[U.T5]から得られる[T4]正コントラストエッジの方向選択的運動信号および[T5]負コントラストエッジの方向選択的運動信号を空間的に統合し、水平方向のオプティックフローパターンを抽出する。さらに[U.HS]細胞間の相互接続により広視野統合が強化される。出力は[HS]広視野の水平方向オプティックフロー（前後軸の自己運動と回転運動の成分）として、[U.DNOVS1]へ伝達され、飛行制御に利用される。

### Requirement realization by interface
Interfaceは ([`DNOVS1`], [`HS`]) = `HS`([`T4`], [`T5`], [`HS`]) と定義されている。多数の[U.T4]および[U.T5]から方向選択的入力を受け取り、[U.HS]細胞間の相互接続により広視野統合を行い、運動制御系の[U.DNOVS1]へ出力する。

### Capability
広視野にわたる多数の局所運動検出器の出力を統合することで、自己運動に伴うオプティックフローパターンを抽出する。特に、前後方向の並進運動や鉛直軸周りの回転運動（ヨー）に伴う水平方向のフローパターンに選択的に応答する。この広視野統合は、局所的なノイズや小物体の運動を抑制し、自己運動情報の頑健な抽出を可能にする（Suver et al., 2016, J Neurosci）。

### Mechanism
[U.HS]は、広い樹状突起野で多数の[U.T4]および[U.T5]からの興奮性入力を受け取る。空間的な加算により、視野全体での一貫した運動パターンに対して強く応答する。さらに、[U.HS]細胞間は電気的結合により相互接続されており、空間的な運動情報の平滑化と統合が促進される。

### Implementation
[U.HS] = Σₓ,ᵧ (w_h(x,y) · ([U.T4]ₓ,ᵧ + [U.T5]ₓ,ᵧ)) + ε·Σⱼ [U.HS]ⱼ

ここで、(x,y)は視野内の位置、w_h(x,y)は水平方向選択性の重み関数、εは電気的結合の結合係数、jは隣接する[U.HS]細胞を表す。

---

## `VS` - Vertical System cells

### Requirement
`VS`は、広視野垂直運動の検出を実現するために、[U.T4]および[U.T5]から得られる[T4]正コントラストエッジの方向選択的運動信号および[T5]負コントラストエッジの方向選択的運動信号を空間的に統合し、垂直方向のオプティックフローパターンを抽出する。さらに[U.VS]細胞間の相互接続により広視野統合が強化される。出力は[VS]広視野の垂直方向オプティックフロー（上下軸とロール軸の自己運動成分）として、[U.DNOVS1]へ伝達され、飛行姿勢制御に利用される。

### Requirement realization by interface
Interfaceは ([`DNOVS1`], [`VS`]) = `VS`([`T4`], [`T5`], [`VS`]) と定義されている。[U.HS]と同様の構造で、垂直方向の運動に選択的な統合を行う。

### Capability
垂直方向の並進運動や水平軸周りの回転運動（ピッチ、ロール）に伴うオプティックフローパターンを抽出する。飛行中の姿勢安定化や高度制御に必須の情報を提供する（Suver et al., 2016, J Neurosci）。

### Mechanism
[U.HS]と同様だが、垂直方向の運動に選択的な[U.T4]および[U.T5]サブタイプからの入力を統合する。

### Implementation
[U.VS] = Σₓ,ᵧ (w_v(x,y) · ([U.T4]ₓ,ᵧ + [U.T5]ₓ,ᵧ)) + ε·Σⱼ [U.VS]ⱼ

ここで、w_v(x,y)は垂直方向選択性の重み関数を表す。

---

## `Dm3` - Distal medulla amacrine cell 3

### Requirement
`Dm3`は、方位検出を実現するために、[U.L1]から得られる[L1]正のコントラスト変化（明るさの増加）を表現する時間的に濾波されたON信号から、特定の方位（エッジ方向）を抽出する。さらに、異なる方位選択性を持つ[U.Dm3]細胞間の相互抑制により、方位選択性を鋭敏化する。出力は[Dm3]交差方位抑制により鋭敏化された特定方位のエッジ信号として[U.TmY]へ伝達され、輪郭統合経路の入力となる。

### Requirement realization by interface
Interfaceは ([`TmY`], [`Dm3`]) = `Dm3`([`L1`], [`Dm3`]) と定義されている。[U.L1]から入力を受け取り、[U.Dm3]細胞間の相互抑制性接続を持ち、[U.TmY]へ出力する。これは方位選択的処理と交差方位抑制の実装と整合している。

### Capability
局所的な輪郭の方位を検出し、交差方位抑制により選択性を高める。これは視覚野V1の単純型細胞における方位選択性のメカニズムと類似しており、輪郭検出や形態認識の基礎となる（Ramos-Traslosheros et al., 2024, Nature）。

### Mechanism
[U.Dm3]は、樹状突起が特定の方位に沿って配向しており、その方位に沿ったエッジに対して選択的に応答する。異なる方位に選択的な[U.Dm3]細胞間は抑制性の接続を持ち、競合的な相互作用により各細胞の方位選択性が鋭敏化される。

### Implementation
[U.Dm3]_θ = f([U.L1] ⊗ G_θ) - λ·Σ_{φ≠θ} [U.Dm3]_φ

ここで、θは方位、G_θは方位θに選択的なガボールフィルタ様の空間フィルタ、⊗は畳み込み、λは相互抑制の強度、φは異なる方位を表す。

---

## `TmY` - Transmedullary Y neurons

### Requirement
`TmY`は、方位情報の統合と伝達を実現するために、[U.Dm3]から得られる[Dm3]交差方位抑制により鋭敏化された特定方位のエッジ信号を受け取り、同じ方位選択性を持つ[U.TmY]細胞間の相互興奮により信号を強化する。出力は[TmY]局所的な輪郭方位（エッジ方向）を表現する方位選択的信号として[U.LC6]へ伝達され、形態視覚情報として行動制御に利用される。

### Requirement realization by interface
Interfaceは ([`LC6`], [`TmY`]) = `TmY`([`Dm3`], [`TmY`]) と定義されている。[U.Dm3]から入力を受け、[U.TmY]細胞間の相互興奮性接続を持ち、[U.LC6]へ出力する。

### Capability
同方位の情報を強化することで、輪郭の連続性を検出し、輪郭統合を促進する。これにより、ノイズの多い視覚入力からでも明瞭な輪郭を抽出できる（Ramos-Traslosheros et al., 2024, Nature）。

### Mechanism
[U.TmY]は、特定の方位に選択的な[U.Dm3]から興奮性入力を受け取る。同じ方位選択性を持つ[U.TmY]細胞間は興奮性の接続を持ち、協調的な活動により方位信号が増強される。

### Implementation
[U.TmY]_θ = [U.Dm3]_θ + μ·Σⱼ [U.TmY]_θ,ⱼ

ここで、θは方位、μは同方位興奮の結合係数、jは空間的に近傍の同方位選択性を持つ[U.TmY]細胞を表す。

## `Tm1` - Transmedullary neuron Tm1

### Requirement
`Tm1`は、OFF運動検出を実現するために、[U.L2]から得られる[L2]負のコントラスト変化（明るさの減少）を表現する時間的に濾波されたOFF信号を、時間的に遅延させた信号へと変換する。出力は[Tm1]時間的に遅延した負コントラスト信号として[U.T5]へ伝達され、OFF運動検出におけるHassenstein-Reichardt相関器の遅延経路を実装する。

### Requirement realization by interface
Interfaceは ([`T5`]) = `Tm1`([`L2`]) と定義されている。[U.L2]から入力を受け、[U.T5]へ出力する。[U.Mi1]のOFF経路版に相当する。

### Capability
[U.Mi1]と同様に、入力信号に時間遅延を付加する。OFF運動検出における遅延経路を提供する（Behnia et al., 2014, Nature）。

### Mechanism
[U.Mi1]と同様のメカニズムで、シナプス伝達と膜特性により遅延を生成する。

### Implementation
[U.Tm1](t) = [U.L2](t - τ₂)

ここで、τ₂は時間遅延を表す。

## `Tm2` - Transmedullary neuron Tm2

### Requirement
`Tm2`は、OFF運動検出を実現するために、[U.L2]から得られる[L2]負のコントラスト変化（明るさの減少）を表現する時間的に濾波されたOFF信号を、時間的に非遅延の信号として[U.T5]へ伝達する。出力は[Tm2]時間的に非遅延の負コントラスト信号であり、OFF運動検出におけるHassenstein-Reichardt相関器の非遅延経路を実装する。

### Requirement realization by interface
Interfaceは ([`T5`]) = `Tm2`([`L2`]) と定義されている。[U.Tm3]のOFF経路版に相当する。

### Capability
[U.Tm3]と同様に、入力信号を最小限の遅延で伝達する。

### Mechanism
高速なシナプス伝達により即座に信号を中継する。

### Implementation
[U.Tm2](t) = [U.L2](t)

## 残りのUC（Mi4, Mi9, Tm4, Tm9, LC4, LC6, LC10, LC11, L3）

これらのUCについても同様の形式で機能項目を定義するが、一部は機能が部分的に未解明であるため、学術的正確性を担保できない場合はその旨を記述する。

### `Mi4` / `Mi9`

**注**: Mi4とMi9の詳細な機能は現在の研究では完全には解明されていない。以下は既知の知見に基づく推定を含む。

**Requirement**: T4細胞への追加的な入力を提供し、ON運動検出の応答特性を調整する。

**Capability**: L1信号に対する異なる時間フィルタリングを提供し、運動検出の時間周波数特性や感度を調整する可能性がある。

**Mechanism**: L1からの入力を異なる時定数で処理し、T4へ出力する。

**Implementation**: [U.Mi4] = F₄([U.L1]), [U.Mi9] = F₉([U.L1]) （F₄、F₉は特定の時間フィルタ）

### `Tm4`

**Requirement**: T5細胞への追加的な入力を提供し、OFF運動検出の応答特性を調整する。

**Capability**: Mi4/Mi9と同様に、OFF運動検出の時間周波数特性を調整する。

**Mechanism**: L2からの入力を処理し、T5へ出力する。

**Implementation**: [U.Tm4] = F₄([U.L2])

### `Tm9`

**Requirement**: 色情報と空間コントラストを統合し、形態視覚経路への入力を提供する。

**Capability**: R7-R8からの色選択的信号を処理し、ロブラの複数のLC細胞へ分配する。形態視覚特徴抽出の前段階処理を担う。

**Mechanism**: R7-R8からのグルタミン酸作動性入力を受け取り、メデュラ内で空間的・時間的処理を行い、ロブラのLC細胞へ投射する。

**Implementation**: [U.Tm9] = F_color([U.R7-R8])

### `LC4`

**Requirement**: 小物体運動を検出し、中枢脳へ伝達する。獲物追跡や同種個体追尾行動に寄与する。

**Capability**: 小さな運動物体に選択的に応答する。背景の広視野運動を抑制し、局所的な運動物体を抽出する。

**Mechanism**: Tm9からの入力と、ロブラ内の局所的な側方抑制により小物体選択性を実現する。

**Implementation**: [U.LC4] = [U.Tm9] - ψ·Background_motion

### `LC6`

**Requirement**: ルーミング刺激（視野内で拡大する物体）を検出し、回避行動を誘発する信号を中枢脳へ伝達する。

**Capability**: 時間的に拡大する視覚刺激に選択的に応答する。Tm9からの形態情報とTmYからの方位情報を統合することで、接近する物体を検出する。

**Mechanism**: 複数の入力を統合し、時間的な拡大パターンを検出する非線形演算を行う。

**Implementation**: [U.LC6] = f_loom([U.Tm9], [U.TmY])

### `LC10` / `LC11`

**注**: LC10とLC11の詳細な機能は現在の研究では完全には解明されていない。

**Requirement**: 特定の視覚特徴パターンを検出し、中枢脳へ伝達する。

**Capability**: Tm9からの形態視覚情報を処理し、特定の視覚特徴に選択的に応答すると推定される。

**Mechanism**: Tm9からの入力を統合し、特定のパターンに応答する。

**Implementation**: [U.LC10] = f₁₀([U.Tm9]), [U.LC11] = f₁₁([U.Tm9])

### `L3`

**注**: L3の機能は部分的に未解明である。

**Requirement**: 光受容体入力の追加的な処理経路を提供する。

**Capability**: L1、L2とは異なる時間・空間フィルタリング特性を持つと推定されるが、詳細は不明。

**Mechanism**: R1-R6から入力を受け取り、特定の処理を行うが詳細は未解明。

**Implementation**: [U.L3] = F₃([U.R1-R6])

## まとめ

以上で、ROI内の主要なUniform Circuitについて、5つの機能関連項目（Requirement、Requirement realization by interface、Capability、Mechanism、Implementation）を定義した。これらの定義は、神経科学的な実験証拠と計算論的モデルに基づいている。

一部のUC（Mi4, Mi9, Tm4, Tm9, LC10, LC11, L3）については、現在の神経科学研究では機能が完全に解明されていないため、推定を含む記述となっている。今後の研究により、これらの機能がより明確になることが期待される。
