| `GrC`             | 顆粒細胞。小脳顆粒層に位置する小型の興奮性ニューロン。苔状線維から頭部速度信号等を受け取り、平行線維として分子層に軸索を伸ばす | [`PC`, `GoC`, `BC`, `SC`] = `GrC`(`VN`, `GoC`) | [`GrC`]頭部速度信号および眼球運動関連信号を空間的に分散させた並列表現; | VORに必要な頭部運動情報を受け取り、小脳皮質の広範な領域に分散させて伝達する      | `VN`から頭部速度信号を受け取り、`GoC`からの抑制的調節を受けながら、`PC`、`GoC`、`BC`、`SC`へ平行線維を通じて出力する       | 入力信号を高次元空間に展開し、空間的に分散した並列表現に変換する   | スパース符号化と空間的展開。少数の活性化された顆粒細胞が、T字型に分岐した平行線維を通じて多数のプルキンエ細胞に信号を分配する           | y = f(W_mf * x_vn - W_goc * x_goc)、ここでf()はReLU様の活性化関数、W_mfは苔状線維重み、W_gocはゴルジ細胞抑制重み                           |
| `PC`              | プルキンエ細胞。小脳皮質の唯一の出力ニューロン。平行線維と登上線維から入力を受け、前庭核へGABA作動性抑制出力を送る     | [`VN`] = `PC`(`GrC`, `IO`, `BC`, `SC`)         | [`PC`]VORゲイン調節信号。頭部速度に対する適切な眼球運動補正量;    | 頭部速度信号と視覚誤差信号を統合し、VORゲインを適切に調節するための抑制出力を生成する | `GrC`から平行線維経由で頭部速度信号、`IO`から登上線維経由で誤差信号を受け取り、`BC`と`SC`からの抑制を統合して、`VN`への出力を決定する | 複数の入力信号を非線形に統合し、学習によって調節可能な出力を生成する | 平行線維シナプスでのLTD/LTPによる重み調節。登上線維による複雑スパイクが誤差信号として作用し、同時活性化された平行線維シナプスの可塑性を誘導 | y = sigma(W_pf(t) * x_grc + W_cf * x_io - W_bc * x_bc - W_sc * x_sc)、dW_pf/dt = -eta * x_cf * x_grc（LTD学習則） |
| `GoC`             | ゴルジ細胞。顆粒層の抑制性介在ニューロン。平行線維から興奮を受け、顆粒細胞にフィードバック抑制を行う              | [`GrC`] = `GoC`(`GrC`)                         | [`GoC`]顆粒細胞活動の時間的および空間的ゲイン制御信号;         | 顆粒細胞の過剰な活性化を防ぎ、入力信号の時間的精度を高める                | `GrC`からの平行線維入力を受け取り、同じ`GrC`集団へフィードバック抑制を行う負帰還ループを形成する                         | 入力活動に応じた負帰還を通じて、回路全体のゲインと時間応答を調節する | フィードバック抑制による自動ゲイン制御。高活動時には強い抑制、低活動時には弱い抑制を適用し、動作範囲を維持                     | y = g(W_pf_goc * x_grc)、x_grc_regulated = x_grc * (1 - alpha * y)、ここでalphaは抑制強度                             |
| `BC`              | 籠細胞。分子層の抑制性介在ニューロン。平行線維から興奮を受け、プルキンエ細胞体と軸索起始部を抑制                | [`PC`] = `BC`(`GrC`)                           | [`BC`]プルキンエ細胞への低周波選択的抑制信号;              | プルキンエ細胞の低周波応答成分を選択的に抑制し、高周波信号の伝達を促進する        | `GrC`からの平行線維入力を受け取り、`PC`の細胞体領域に抑制を投射する                                        | 低周波信号を選択的にフィルタリングし、高域通過特性を実現する     | HCN1チャネルを介したソーマコンダクタンスの増加。低周波入力時にシャンティング抑制が増強される                          | y_bc = h_low(W_pf_bc * x_grc)、h_low()は低周波成分を抽出するフィルタ関数                                                      |
| `SC`              | 星状細胞。分子層の抑制性介在ニューロン。平行線維から興奮を受け、プルキンエ細胞樹状突起を抑制                  | [`PC`] = `SC`(`GrC`)                           | [`SC`]プルキンエ細胞への高周波選択的抑制信号;              | プルキンエ細胞の高周波応答成分を選択的に抑制し、低周波信号の伝達を促進する        | `GrC`からの平行線維入力を受け取り、`PC`の樹状突起領域に抑制を投射する                                       | 高周波信号を選択的にフィルタリングし、低域通過特性を実現する     | 樹状突起でのシャンティング抑制。高周波入力に対して素早く応答し、急速な電位変化を減衰させる                             | y_sc = h_high(W_pf_sc * x_grc)、h_high()は高周波成分を抽出するフィルタ関数                                                    |

| `VN`              | 前庭核 (ROI外)。VOR経路の中継核。半規管からの頭部速度信号を受け取り、苔状線維として小脳に投射。プルキンエ細胞からの抑制を受けて眼球運動核へ出力を調節 | [`GrC`, `OMN`] = `VN`(SemicircularCanals, `PC`) | [`VN`]頭部速度信号および小脳によって調節された眼球運動指令; | 頭部回転を検出し、適切な眼球運動指令を生成する。小脳からの調節信号を統合する  | 半規管から頭部速度信号、`PC`からVORゲイン調節信号を受け取り、`GrC`へ苔状線維入力、`OMN`へ眼球運動指令を出力する | 前庭入力と小脳性調節を統合し、眼球運動指令を生成する | プルキンエ細胞からのGABA作動性抑制による出力調節。抑制が強いとVORゲイン低下、弱いとゲイン上昇 | y_omn = W_vest * x_head - W_pc * y_pc、ここでx_headは頭部速度、y_pcはPC出力             |
| `IO`              | 下オリーブ核 (ROI外)。登上線維の起源。視覚誤差信号（網膜スリップ）を受け取り、プルキンエ細胞へ教師信号を伝達                       | [`PC`] = `IO`(RetinaAOS)                        | [`IO`]視覚誤差信号（網膜スリップ）を表す教師信号;      | 網膜上の像のずれ（視覚誤差）を検出し、小脳での学習を誘導する教師信号を生成する | 副視覚系/視索核から視覚誤差情報を受け取り、登上線維として`PC`へ教師信号を出力する                      | 視覚的なエラー情報を検出し、学習誘導信号に変換する  | 網膜スリップの方向と大きさに応じた発火。1-2Hzの低頻度発火で複雑スパイクを誘発          | y_io = sign(retinal_slip) * magnitude(retinal_slip)、発火確率 p = sigmoid(y_io) |
| `OMN`             | 眼球運動核 (ROI外)。動眼神経核と外転神経核を含む。前庭核からの入力を受け、外眼筋を駆動してVOR応答を実行                        | [ExtraocularMuscles] = `OMN`(`VN`)              | [`OMN`]外眼筋への運動指令信号;               | 前庭核からの指令を外眼筋の収縮パターンに変換し、眼球運動を実行する       | `VN`から眼球運動指令を受け取り、外眼筋へ運動ニューロン出力を行う                               | 運動指令を筋収縮パターンに変換する          | 興奮性シナプス伝達による運動ニューロン駆動。push-pull構成による拮抗筋の協調制御       | y_muscle = W_omn * x_vn、眼球位置 theta = integral(y_muscle)                    |

## UC採用基準の検証

### ROI内UC

| UC | ROI内配置 | TLF関連性 | 情報同質性 | 粒度適切性 |
|----|----------|----------|-----------|-----------|
| `GrC` | ✓ 小脳顆粒層 | ✓ 前庭信号の入力経路 | ✓ 頭部速度信号を平行線維に変換 | ✓ メゾスコピック |
| `PC` | ✓ 小脳皮質 | ✓ VOR適応学習の中心 | ✓ 統合された運動誤差信号 | ✓ メゾスコピック |
| `GoC` | ✓ 小脳顆粒層 | ✓ 入力ゲイン制御 | ✓ 抑制性調節信号 | ✓ メゾスコピック |
| `BC` | ✓ 小脳分子層 | ✓ PC活動調節 | ✓ 低周波抑制信号 | ✓ メゾスコピック |
| `SC` | ✓ 小脳分子層 | ✓ PC活動調節 | ✓ 高周波抑制信号 | ✓ メゾスコピック |

### ROI外UC（入出力）

| UC | 位置 | 役割 |
|----|------|------|
| `VN` | 脳幹（延髄/橋） | 入力源（苔状線維）および出力先（PC投射先） |
| `IO` | 脳幹（延髄） | 入力源（登上線維） |
| `OMN` | 脳幹（中脳/橋） | 最終出力先（VOR実行） |
