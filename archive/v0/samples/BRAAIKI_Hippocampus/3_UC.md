# Uniform Component (UC) 定義

## 海馬における情報処理の基本単位

本ドキュメントでは、海馬（ROI）内で自己位置推定（TLF）を実現するUniform Componentを定義します。

---

## UC一覧（完全版：Interface, Output Semantics, Function）

| Uniform Component | Comment | Interface | Output Semantics | Function |

| `DG` | 歯状回顆粒細胞層（Dentate Gyrus Granule Cells）。嗅内皮質からの空間情報と文脈情報を受け取り、パターン分離を実行する。類似した空間パターンを区別可能な表現に変換し、疎な符号化を行う。海馬における最初の情報処理段階。 | `MEC_IN`, `LEC_IN`, `MS_IN` | 分離された空間文脈パターン（Separated Spatial-Contextual Pattern）。入力された空間情報と文脈情報の組み合わせを、疎で重複の少ない神経表現に変換したもの。類似した環境や経験を区別可能にする。 | (`MEC_IN`\|周期的空間符号と経路積分情報) と (`LEC_IN`\|環境特徴と文脈情報) の組み合わせ入力に対して、競合的抑制と疎な活性化パターンを用いたパターン分離を実行する。(`MS_IN`\|シータリズムと行動状態) により時間的に調節され、入力の類似性に関わらず異なる神経集団を活性化することで、重複を最小化した表現を生成する。顆粒細胞の低い発火率と広い受容野により、高次元空間での分離を実現する。 |
| `CA3` | CA3錐体細胞層（CA3 Pyramidal Cells）。歯状回から分離された情報と、嗅内皮質からの直接入力を受け取る。強力な反回性結合により自己連想ネットワークを形成し、部分的な手がかりから完全な空間表現を復元する（パターン補完）。空間記憶の保存と想起の中心的役割を担う。 | `DG`, `MEC_IN`, `LEC_IN`, `CA3`, `MS_IN` | 連想的空間表現（Associative Spatial Representation）。部分的な手がかりから復元された完全な空間記憶パターン。環境の統合的な表現であり、過去の経験と現在の入力を結びつける。 | (`DG`\|分離された空間文脈パターン)、(`MEC_IN`\|周期的空間符号と経路積分情報)、(`LEC_IN`\|環境特徴と文脈情報) を入力として受け取り、強力な反回性側枝 (`CA3`\|連想的空間表現) を通じた自己連想処理により、部分的手がかりから完全なパターンを復元する。(`MS_IN`\|シータリズムと行動状態) により、符号化モード（新規パターンの学習）と想起モード（既存パターンの復元）が切り替えられる。ヘブ学習により反回性結合が強化され、頻繁に共起する空間パターンが連合される。アトラクタ動態により、ノイズや部分的情報から安定した空間表現を生成する。 |

| `LEC_IN` | 外側嗅内皮質入力（Lateral Entorhinal Cortex Input）。ROI外だが、海馬への主要入力として定義。環境内の物体、ランドマーク、文脈情報などの非空間的特徴を提供する。「何」の情報を符号化。 | - | 環境特徴と文脈情報（Environmental Features and Context）。環境内の物体、ランドマーク、感覚的特徴、状況的文脈などの非空間的情報。「何が」あるかの情報。 | ROI外の入力UCのため、Function記述は省略。外側嗅内皮質における上流の情報処理により生成される。 |

## 注記

### UC選定の根拠

1. **DG、CA3、CA1、SUB**: 海馬内部の主要な錐体細胞層であり、ROI内に位置する
   - 各領域は機能的に区別される同質的な神経細胞集団
   - 自己位置推定の異なる計算段階を担当
   - メゾスコピックレベルとして適切な粒度

2. **MEC_IN、LEC_IN、MS_IN**: ROI外だが、海馬への必須入力として定義
   - これらがないと海馬の自己位置推定機能が説明できない
   - 各入力は機能的に明確に区別される情報を提供
   - HCDの完全性のために必要

### 介在ニューロンについて

各領域（DG、CA3、CA1）には多様な介在ニューロンが存在し、局所的な抑制制御を行っています。しかし、本HCDでは以下の理由から、介在ニューロンを独立したUCとして定義しません：

1. 介在ニューロンは主に局所回路内での抑制制御を行い、UCから独立した情報処理単位というよりは、各UCの内部機構の一部と見なす方が適切
2. 自己位置推定という計算機能の記述において、介在ニューロンの役割は各錐体細胞層の機能の一部として組み込まれる
3. HCDの記述レベルを維持するため、より粗いレベルで記述

ただし、各UCのFunction記述において、抑制性制御の役割は適宜言及します。

### UCの粒度について

海馬のCA領域はさらに細分化できます（例: CA3a, CA3b, CA3c、CA1の層構造など）。しかし、自己位置推定というTLFを記述する上では、現在のUC粒度が適切であると判断しました：

- より細かい区分は、現時点での神経科学的証拠では機能的差異が完全には明確でない
- メゾスコピックレベルでの情報処理の流れを記述するという目的に合致
- 必要に応じて将来的に細分化可能な構造
