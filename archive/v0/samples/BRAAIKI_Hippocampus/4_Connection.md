# Connection 定義

## UC間の情報接続

本ドキュメントでは、定義したUC間の接続を、BIFに基づいて記述します。

## 接続の特性

### 主要な情報処理経路

1. **三シナプス経路**: `MEC_IN`/`LEC_IN` → `DG` → `CA3` → `CA1` → `SUB`
   - 海馬の古典的な主経路
   - 段階的な情報処理: パターン分離 → 連想記憶 → 時間的統合 → 出力

2. **直接経路**: `MEC_IN`/`LEC_IN` → `CA3`
   - 嗅内皮質からCA3への直接投射
   - より高速な情報伝達

3. **側頭アンモン路**: `MEC_IN`/`LEC_IN` → `CA1`
   - 嗅内皮質層IIIからCA1への直接経路
   - 現在の感覚情報を直接CA1に供給
   - CA3からの予測情報と比較するための経路

4. **反回性経路**: `CA3` → `CA3`
   - CA3内部のフィードバック
   - 連想記憶とパターン補完のための自己連想ネットワーク

### 調節性入力

- **`MS_IN` → `DG`/`CA3`/`CA1`**: シータリズム調節
  - 海馬全体の時間的組織化
  - 符号化と想起のモード切り替え
  - 時間的符号化の制御

## BIFからConnectionへのマッピング

BIF（2_BIF.md）で特定された神経組織間の解剖学的接続を、UC間の接続にマッピングしました：

- **嗅内皮質層II → 歯状回/CA3の接続** → `MEC_IN`/`LEC_IN` → `DG`/`CA3`
- **歯状回 → CA3の苔状線維** → `DG` → `CA3`
- **CA3 → CA3の反回性側枝** → `CA3` → `CA3`
- **CA3 → CA1のシャファー側枝** → `CA3` → `CA1`
- **嗅内皮質層III → CA1の側頭アンモン路** → `MEC_IN`/`LEC_IN` → `CA1`
- **CA1 → 海馬台** → `CA1` → `SUB`
- **内側中隔核 → 海馬各領域** → `MS_IN` → `DG`/`CA3`/`CA1`

各Connectionは、複数の解剖学的投射を統合したものや、単一の投射経路に対応するものがあります。

---

## 注記

1. 本Connectionリストは、自己位置推定に直接関与する主要な経路を中心に記載しています。
2. 介在ニューロンを介した抑制性接続は、各UCの内部機構として扱い、独立したConnectionとしては記載していません。
3. 海馬台からの出力（`SUB` → 嗅内皮質、前頭前皮質など）は、ROI外への出力であり、TLFの実現に直接関与しないため、Connectionとしては記載していません（これらはROI_Outputとして扱います）。
