# 3_UC.md - Uniform Component（UC）定義

## 対象領域
- **ROI**: 小脳片葉（Cerebellar Flocculus）
- **TLF**: VOR（前庭動眼反射）の適応的制御

---

## Uniform Component一覧（概要）

| Uniform Component | Comment | Interface | Output Semantics |
| ------ | -------- | -------- | -------- |
| `GrC` | 顆粒細胞。入力信号の時空間パターンを分散表現に変換。 | `VN`, `GoC` | 前庭・運動信号の高次元スパース表現 |
| `PC` | プルキンエ細胞。小脳皮質唯一の出力ニューロン。 | `GrC`, `IO`, `BC`, `SC` | VORゲイン調整信号 |
| `BC` | バスケット細胞。PC細胞体への側方抑制。 | `GrC` | 低周波フィルタリング信号 |
| `SC` | ステレート細胞。PC樹状突起への抑制。 | `GrC` | 高周波フィルタリング信号 |
| `GoC` | ゴルジ細胞。GrCへのフィードバック抑制。 | `GrC`, `VN` | 入力ゲイン正規化信号 |

---

## UC詳細定義

### `GrC` - 顆粒細胞（Granule Cells）

| 項目 | 内容 |
| ---- | ---- |
| **Comment** | 小脳皮質顆粒層に位置する興奮性ニューロン。苔状線維からの入力を受け、平行線維を介してプルキンエ細胞や分子層介在ニューロンに投射。脳内で最も数の多い神経細胞。入力信号の時空間パターンを分散表現に変換する。 |
| **Interface** | `VN`, `GoC` |
| **Output Semantics** | 前庭・運動信号の高次元スパース表現。入力の時空間パターンを分離可能な分散コードに変換。頭部速度・眼球運動情報の基底関数表現。 |
| **A1. Requirement** | VORにおいて、前庭核から受け取った頭部速度信号を、プルキンエ細胞が学習に利用できる形式に変換する。具体的には、低次元の入力信号（頭部速度）を高次元のスパースな活動パターンに展開し、類似した入力を分離可能にする。 |
| **A2. Requirement realization by interface** | 前庭核（`VN`）から苔状線維経由で頭部速度信号を受け取り、ゴルジ細胞（`GoC`）からの抑制により活動のスパース性が調整される。これにより、入力信号の時間的パターンが空間的なスパース表現に変換され、下流のPCでの学習が促進される。 |
| **B1. Capability** | 低次元入力を高次元スパース表現に変換する次元拡張。類似入力の分離（パターン分離）。時間的パターンの空間的表現への変換。 |
| **B2. Mechanism** | 各顆粒細胞は約4本の苔状線維から入力を受け、複数入力の同時活性化時のみ発火する（AND論理に近い）。大量の顆粒細胞（ヒトで約500億個）が異なる入力組み合わせに応答し、スパースな活動パターンを生成。ゴルジ細胞によるフィードバック抑制が活動を一定レベルに維持。 |
| **B3. Implementation** | y_i = f(sum_j(w_ij * x_j) - theta_i - I_GoC) where y_i: i番目のGrCの出力, x_j: j番目の苔状線維入力, w_ij: シナプス重み, theta_i: 発火閾値, I_GoC: ゴルジ細胞からの抑制, f: ReLU類似の活性化関数 |

---

### `PC` - プルキンエ細胞（Purkinje Cells）

| 項目 | 内容 |
| ---- | ---- |
| **Comment** | 小脳皮質唯一の出力ニューロン。GABA作動性で前庭核に抑制性出力を送る。平行線維と登上線維の2種類の入力を統合し、VORゲイン調整信号を生成。複雑スパイク（登上線維由来）と単純スパイク（平行線維由来）の2種類の発火パターンを持つ。 |
| **Interface** | `GrC`, `IO`, `BC`, `SC` |
| **Output Semantics** | VORゲイン調整信号。学習により修正された眼球運動指令の補正量。頭部速度に対する適切な眼球速度補償の計算結果。 |
| **A1. Requirement** | VORにおいて、頭部速度信号（GrC経由）と視覚誤差信号（IO経由）を統合し、前庭核への抑制出力を通じてVORゲインを適切に調整する。誤差信号に基づいて入力-出力関係を学習し、視覚像の安定化に必要な眼球運動補正量を出力する。 |
| **A2. Requirement realization by interface** | 顆粒細胞（`GrC`）から平行線維経由で頭部速度の分散表現を受け取り、下オリーブ核（`IO`）から登上線維経由で誤差信号を受け取る。誤差信号と平行線維活動の同時発生により、平行線維-PC間シナプス強度が修正される（LTD/LTP）。バスケット細胞（`BC`）とステレート細胞（`SC`）からの抑制により出力のタイミングと周波数特性が調整される。 |
| **B1. Capability** | 多入力の重み付き統合。教師信号に基づくシナプス可塑性による入出力関係の学習。時間的に精密な抑制性出力の生成。 |
| **B2. Mechanism** | 約20万本の平行線維からの興奮性入力を樹状突起で受け取り、各シナプスの重みに基づいて統合。登上線維からの複雑スパイクは、同時に活動した平行線維シナプスの長期抑圧（LTD）を誘導。これにより、誤差を引き起こした入力パターンへの応答が減少。バスケット/ステレート細胞からの抑制が出力の時間精度を向上。 |
| **B3. Implementation** | r_PC = f(sum_i(w_i * y_i) - I_BC - I_SC), dw_i/dt = -eta * y_i * CF where r_PC: PC発火率, y_i: i番目のGrCからの入力, w_i: シナプス重み, I_BC, I_SC: 介在ニューロンからの抑制, CF: 登上線維活動（誤差信号）, eta: 学習率, f: 非線形活性化関数 |

---

### `BC` - バスケット細胞（Basket Cells）

| 項目 | 内容 |
| ---- | ---- |
| **Comment** | 分子層下部に位置するGABA作動性抑制性介在ニューロン。平行線維から興奮性入力を受け、プルキンエ細胞の細胞体と軸索起始部を強力に抑制。pinceau構造を形成し、低周波応答をフィルタリング。 |
| **Interface** | `GrC` |
| **Output Semantics** | プルキンエ細胞への側方抑制信号。低周波成分のフィルタリング。近傍PCの出力タイミング制御。 |
| **A1. Requirement** | VORにおいて、プルキンエ細胞の出力を空間的・時間的に整形する。特に低周波成分をフィルタリングし、VOR応答の時間精度を向上させる。また、側方抑制により近傍PC間のコントラストを強調する。 |
| **A2. Requirement realization by interface** | 顆粒細胞（`GrC`）から平行線維経由で入力を受け取り、活性化されると近傍のプルキンエ細胞を抑制する。平行線維が矢状面に沿って走行するため、同一の入力パターンに応答するPC群に対して協調的な抑制を提供。 |
| **B1. Capability** | 側方抑制による空間的コントラスト強調。低周波フィルタリング。出力タイミングの同期化。 |
| **B2. Mechanism** | 平行線維からの興奮性入力により活性化され、GABAを放出してPC細胞体と軸索起始部（AIS）を抑制。pinceau構造によるAIS抑制は特に強力で、PCの出力を直接制御。HCN1チャネルを介した低周波フィルタリング機構により、低周波の入力に対するPC応答を選択的に抑制。 |
| **B3. Implementation** | I_BC = g_BC * H_LP(sum_i(w_i * y_i)) * (V_PC - E_GABA) where I_BC: BCからPCへの抑制電流, g_BC: コンダクタンス, H_LP: 低域通過フィルタ伝達関数, y_i: GrC入力, V_PC: PC膜電位, E_GABA: GABA逆転電位 |

---

### `SC` - ステレート細胞（Stellate Cells）

| 項目 | 内容 |
| ---- | ---- |
| **Comment** | 分子層上部に位置するGABA作動性抑制性介在ニューロン。平行線維から興奮性入力を受け、プルキンエ細胞の樹状突起を抑制。高周波応答をフィルタリングし、時間的精度を向上。 |
| **Interface** | `GrC` |
| **Output Semantics** | プルキンエ細胞樹状突起への抑制信号。高周波成分のフィルタリング。入力統合の時間窓制御。 |
| **A1. Requirement** | VORにおいて、プルキンエ細胞への入力統合過程を調整する。特に高周波成分をフィルタリングし、入力の時間窓を制限することで、VOR応答の時間精度と安定性を向上させる。 |
| **A2. Requirement realization by interface** | 顆粒細胞（`GrC`）から平行線維経由で入力を受け取り、活性化されるとプルキンエ細胞の樹状突起を抑制する。樹状突起への抑制は入力統合の時間窓を制限し、高周波ノイズを除去する。 |
| **B1. Capability** | 高周波フィルタリング。入力統合時間窓の制御。樹状突起計算の調整。 |
| **B2. Mechanism** | 平行線維からの興奮性入力により活性化され、GABAを放出してPC樹状突起を抑制。樹状突起への抑制は興奮性シナプス入力のシャンティングを引き起こし、高周波入力への応答を選択的に減弱。BCとは相補的に働き、PCの周波数応答帯域を規定。 |
| **B3. Implementation** | I_SC = g_SC * H_HP(sum_i(w_i * y_i)) * (V_dend - E_GABA) where I_SC: SCからPC樹状突起への抑制電流, g_SC: コンダクタンス, H_HP: 高域通過フィルタ伝達関数, y_i: GrC入力, V_dend: 樹状突起膜電位, E_GABA: GABA逆転電位 |

---

### `GoC` - ゴルジ細胞（Golgi Cells）

| 項目 | 内容 |
| ---- | ---- |
| **Comment** | 顆粒層に位置するGABA/グリシン作動性抑制性介在ニューロン。顆粒細胞と苔状線維から入力を受け、顆粒細胞にフィードバック抑制を提供。入力ゲインを調整し、時間窓を制御。 |
| **Interface** | `GrC`, `VN` |
| **Output Semantics** | 顆粒細胞へのフィードバック抑制信号。入力ゲインの正規化。時間窓の動的調整。信号対雑音比の最適化。 |
| **A1. Requirement** | VORにおいて、顆粒細胞層の活動レベルを適切な範囲に維持する。入力強度に応じてゲインを自動調整し、弱い入力でも強い入力でも顆粒細胞の活動がスパースかつ安定した状態を保つ。また、時間窓を制御して入力の時間精度を向上させる。 |
| **A2. Requirement realization by interface** | 顆粒細胞（`GrC`）から上行軸索と平行線維経由で、前庭核（`VN`）から苔状線維経由で入力を受け取る。GrCからのフィードバック入力により活動レベルを検出し、GrCに抑制を送ることで活動を一定レベルに維持。苔状線維からのフィードフォワード入力により入力タイミングを検出し、時間窓を制御。 |
| **B1. Capability** | フィードバック制御による活動レベル正規化。時間窓制御。スパース性の維持。 |
| **B2. Mechanism** | 顆粒細胞の上行軸索と平行線維から興奮性入力を受け、また苔状線維からも直接入力を受ける。活性化されるとGABA/グリシンを放出し、グロメルルス内で顆粒細胞樹状突起を抑制。この負のフィードバックループにより、顆粒細胞の活動レベルが自動的に調整される。1つのGoC活性化で数百のGrCが抑制される。 |
| **B3. Implementation** | I_GoC = g_GoC * (alpha * sum_i(y_i) + beta * sum_j(x_j)) * (V_GrC - E_inh) where I_GoC: GoCからGrCへの抑制電流, g_GoC: コンダクタンス, y_i: GrCからの入力（フィードバック）, x_j: 苔状線維入力（フィードフォワード）, alpha, beta: 重み係数, V_GrC: GrC膜電位, E_inh: 抑制性逆転電位 |

## ROI外構造（入出力ノード）

| 構造名 | Comment |
| ------ | -------- |
| `VN` (ROI外) | 前庭核（Vestibular Nuclei）。内側前庭核（MVN）、上前庭核（SVN）を含む。前庭器官からの信号を中継し、苔状線維経由で小脳に入力を送る。また、プルキンエ細胞からの抑制性出力を受け、動眼神経核へVOR信号を送る。 |
| `IO` (ROI外) | 下オリーブ核（Inferior Olive）。登上線維の起源。副視索系から視覚誤差信号（retinal slip）を受け取り、教師信号としてプルキンエ細胞に伝達。 |
| `OMN` (ROI外) | 動眼神経核（Oculomotor Nuclei）。外転神経核、動眼神経核を含む。前庭核からの信号を受け、外眼筋を制御してVORを実行。 |
