## 小脳片葉におけるVOR適応的制御のHCD

---

## 1. TLFとROIの概要

### TLF: VOR（前庭動眼反射）の適応的制御
前庭動眼反射（Vestibulo-Ocular Reflex, VOR）は、頭部の動きに対して眼球を反対方向に動かし、網膜上の視覚像を安定させる反射機構である。本HCDでは、VORの**適応的学習**、すなわちVORゲインの調整メカニズムを対象とする。

VORゲインとは、頭部速度に対する眼球速度の比率であり、理想的にはゲイン=1.0で視覚像が完全に安定する。しかし、眼鏡の装用や加齢などによりゲインがずれた場合、小脳がこれを学習によって修正する。

### ROI: 小脳片葉（Cerebellar Flocculus）
小脳片葉は前庭小脳（Vestibulocerebellum）の一部であり、VOR適応において中心的な役割を果たす。小脳片葉の損傷はVOR学習を永続的に阻害することが知られており、この領域がVOR適応に必須であることが確立されている。

---

## 2. 定義されたUCの一覧

### ROI内UC（5種類）

| UC | 名称 | 主な役割 | 神経科学的根拠 |
| -- | ---- | -------- | -------------- |
| `GrC` | 顆粒細胞 | 入力信号の高次元スパース表現への変換 | 小脳皮質で最も数の多いニューロン。苔状線維入力を約200,000倍の次元に展開 |
| `PC` | プルキンエ細胞 | 学習に基づくVORゲイン調整信号の生成 | 小脳皮質唯一の出力細胞。平行線維-PC間LTDが学習の基盤 |
| `BC` | バスケット細胞 | PC出力の低周波フィルタリング | PC細胞体への強力な抑制。pinceau構造による軸索起始部抑制 |
| `SC` | ステレート細胞 | PC入力の高周波フィルタリング | PC樹状突起への抑制。入力統合時間窓の制御 |
| `GoC` | ゴルジ細胞 | 入力ゲインの自動調整 | GrCへのフィードバック抑制。活動レベルの正規化 |

### ROI外構造（3種類）

| 構造 | 名称 | 役割 |
| ---- | ---- | ---- |
| `VN` | 前庭核 | 頭部速度信号の入力源、VOR出力先 |
| `IO` | 下オリーブ核 | 視覚誤差信号（教師信号）の入力源 |
| `OMN` | 動眼神経核 | 眼球運動の最終出力先 |

## 3. 情報処理フロー

### 入力 → 出力の処理経路

```
【入力層】
  VN ─────────────────────────────────────────┐
  (頭部速度)                                    │
       │                                       │
       ↓ 苔状線維                              │
                                               │
【顆粒層】                                      │
  GrC ◄─────── GoC                             │
  (スパース表現)  (フィードバック抑制)            │
       │           ↑                           │
       │           │                           │
       ↓ 平行線維   │                           │
                   │                           │
【分子層】          │                           │
  BC ──────────────┤                           │
  (低周波フィルタ)   │                           │
       │           │                           │
  SC ──────────────┤                           │
  (高周波フィルタ)   │                           │
       │           │                           │
       ↓ 抑制      │                           │
                   │                           │
【プルキンエ層】     │                           │
  PC ◄────────────┘                           │
  (学習・統合)                                  │
       ↑                                       │
       │ 登上線維                              │
       │                                       │
  IO ──┘                                       │
  (視覚誤差)                                    │
       │                                       │
       │                                       │
       ↓ 抑制性出力                             │
                                               │
【出力層】                                       │
  VN ◄─────────────────────────────────────────┘
  (VORゲイン調整)
       │
       ↓
  OMN
  (眼球運動)
```

### 学習メカニズム

1. **誤差検出**: 網膜滑り（retinal slip）が副視索系→下オリーブ核経路で検出され、登上線維経由でPCに伝達
2. **連合学習**: 登上線維活動（誤差信号）と平行線維活動（入力パターン）が同時に発生すると、そのシナプスにLTDが誘導される
3. **ゲイン調整**: LTDによりPCの応答が変化し、前庭核への抑制出力が修正されてVORゲインが適応

## 4. 主要な発見

### 4.1 小脳皮質の計算原理
- **スパースコーディング**: 顆粒細胞による高次元スパース表現が、類似入力の分離と学習の汎化を両立
- **教師あり学習**: 登上線維が「教師信号」として機能し、誤り駆動学習を実現
- **フィードバック制御**: ゴルジ細胞による自動ゲイン調整が、広範囲の入力強度に対するロバスト性を提供

### 4.2 分子層介在ニューロンの相補的役割
- バスケット細胞（低周波フィルタ）とステレート細胞（高周波フィルタ）が相補的に働き、PC出力の周波数帯域を規定
- これにより、VOR応答の時間精度が向上

### 4.3 学習の分子メカニズム
- 平行線維-PC間シナプスのLTD（長期抑圧）がVOR適応の主要メカニズム
- 近年の研究では、LTP（長期増強）も重要な役割を果たすことが明らかに

## 5. 制約と今後の課題

### 5.1 本HCDの制約

1. **細胞内多様性の未考慮**: 同じ細胞タイプ内でも機能的に異なるサブタイプが存在するが、本HCDでは単一のUCとして扱っている

2. **時間遅延の未モデル化**: 登上線維による学習には約100msの時間遅延が関与するが、数式レベルでの時間遅延は明示的にモデル化していない

3. **小脳核の省略**: 深部小脳核もVOR適応に関与する可能性があるが、本HCDでは小脳皮質に限定

4. **可塑性部位の限定**: 平行線維-PC間以外にも複数のシナプス部位で可塑性が生じるが、主要部位のみを記述

### 5.2 今後の課題

1. **定量的モデルへの拡張**: B3で定義した数式を実装し、シミュレーションによる検証を行う

2. **VOR以外の機能への拡張**: 同じ小脳皮質回路が他の運動学習（眼球追従、リーチング等）にどのように利用されるかを検討

3. **発達と加齢の影響**: 回路構造は一定でも、シナプス強度や可塑性能力は発達・加齢で変化するため、その影響を組み込む

4. **病態モデルへの応用**: 小脳変性疾患（脊髄小脳失調症など）での回路機能障害をHCDベースで解析
