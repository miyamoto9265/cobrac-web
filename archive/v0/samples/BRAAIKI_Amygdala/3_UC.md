# Uniform Component (UC) 定義

## UCの一覧

以下の表は、恐怖条件付けと消去のHCDを構成するUniform Component（情報処理の基本単位）を示します。

| Uniform Component | Comment | Interface | Output Semantics | Function |
| ------ | -------- | -------- | -------- | -------- |
| `LA` | 外側扁桃体（Lateral Amygdala）。条件刺激（CS）と無条件刺激（US）の感覚情報を受け取り、両者の連合学習を実行する。恐怖条件付けの初期学習段階における中核的な役割を担う。 | 聴覚視床(MGv/PIN), 聴覚皮質(A1/Te1), 体性感覚視床(VPL/VPM) | 条件刺激と無条件刺激の連合強度、CS-US連合の獲得度 | (聴覚視床\|条件刺激の迅速な聴覚情報)、(聴覚皮質\|条件刺激の詳細な聴覚情報)、(体性感覚視床\|無条件刺激の痛覚情報)を受け取り、ヘブ則に基づく連合学習により、条件刺激と無条件刺激の時間的近接性を検出し、シナプス可塑性（LTP/LTD）を通じて連合強度を符号化する。 |
| `BLA` | 基底外側扁桃体（Basolateral Amygdala）。外側扁桃体から連合情報を受け取り、海馬からの文脈情報や前頭前野からの制御信号を統合する。恐怖記憶の情動価評価と記憶の統合を担当。 | `LA`, 腹側海馬(vHPC), 青斑核(LC), 腹側被蓋野(VTA), `vmPFC`, `dmPFC` | 統合された恐怖情動価、文脈依存的な恐怖記憶表現、消去・想起バランス | (`LA`\|CS-US連合強度)、(腹側海馬\|文脈情報)、(青斑核\|ノルアドレナリン性記憶固定化信号)、(腹側被蓋野\|ドーパミン性報酬予測誤差)、(`vmPFC`\|消去記憶・安全性評価)、(`dmPFC`\|恐怖記憶想起信号)を統合し、文脈依存的に恐怖情動価を評価する。前頭前野からの拮抗的入力（vmPFC: 抑制、dmPFC: 促進）を重み付けし、現在の状況における恐怖記憶の表現強度を決定する。 |
| `ITC` | 介在細胞群（Intercalated Cells）。扁桃体内の抑制性ニューロン集団。前頭前野からの入力を受けて中心扁桃体への抑制を行い、恐怖消去において重要な役割を果たす。GABA作動性。 | `BLA`, `vmPFC` | 恐怖反応抑制信号、消去学習時の抑制ゲート状態 | (`BLA`\|統合された恐怖情動価)と(`vmPFC`\|消去記憶・安全性評価信号)を受け取り、vmPFCからの入力が強い場合にゲート機能を活性化し、GABA作動性抑制を通じてCeAへの恐怖信号の伝達を遮断する。消去学習時に特に活性化され、恐怖反応の抑制制御を実行する。 |
| `CeA` | 中心扁桃体（Central Amygdala）。扁桃体の主要な出力核。基底外側扁桃体からの興奮性入力と介在細胞群からの抑制性入力を統合し、恐怖反応（凍結、自律神経反応）を出力する。 | `BLA`, `ITC` | 恐怖反応出力強度、防御行動・自律神経反応の駆動信号 | (`BLA`\|統合された恐怖情動価)からの興奮性入力と(`ITC`\|恐怖反応抑制信号)からの抑制性入力を統合し、両者の差分演算により最終的な恐怖反応出力強度を決定する。この出力は、ROI外の運動系（PAG）、自律神経系（視床下部）、情動系（BNST）へ送信され、具体的な恐怖反応を駆動する。 |
| `vmPFC` | 腹内側前頭前野（Ventromedial Prefrontal Cortex / Infralimbic cortex）。恐怖消去学習において中核的な役割を担う。扁桃体からの恐怖情報を受け取り、介在細胞群や基底外側扁桃体へ抑制信号を送ることで恐怖反応を減弱させる。 | `BLA`, 青斑核(LC) | 消去記憶の強度、安全性評価信号、恐怖抑制制御信号 | (`BLA`\|統合された恐怖情動価)と(青斑核\|ノルアドレナリン性消去促進信号)を受け取り、条件刺激が危険な結果を伴わない経験が反復された場合に、安全性評価信号を生成する。この信号は消去記憶として固定化され、ITCとBLAへの抑制性制御信号として送信され、恐怖反応の減弱を促進する。 |
| `dmPFC` | 背内側前頭前野（Dorsomedial Prefrontal Cortex / Prelimbic cortex）。恐怖記憶の想起と発現を促進する。基底外側扁桃体への興奮性投射を通じて、条件刺激に対する恐怖反応を強化する。vmPFCと拮抗的に機能。 | `BLA` | 恐怖記憶想起信号、脅威検出・警戒信号、恐怖発現促進 | (`BLA`\|統合された恐怖情動価)を受け取り、脅威の存在を評価する。恐怖情動価が高い場合、恐怖記憶の想起を促進する信号をBLAへフィードバックし、恐怖反応の発現を強化する。vmPFCと拮抗的に作用し、消去学習が不十分な状況や新規脅威の検出時に優位となる。 |

## UCの選定理由

### ROI内のUC
以下のUCはROI（扁桃体および前頭前野）内に位置し、恐怖条件付けと消去のTLFにおいて不可欠な情報処理を担当します：

- **`LA`**: 扁桃体内。感覚情報の連合学習における入力ゲート
- **`BLA`**: 扁桃体内。情報統合と記憶形成の中心
- **`ITC`**: 扁桃体内。恐怖反応の抑制制御
- **`CeA`**: 扁桃体内。恐怖反応の出力
- **`vmPFC`**: 前頭前野内。消去記憶の形成と維持
- **`dmPFC`**: 前頭前野内。恐怖記憶の発現制御

### 粒度の妥当性
各UCは、メゾスコピックレベルとして適切な粒度を持っています：
- 各UCは解剖学的に同定可能な神経組織に対応
- 機能的に同質的な情報処理を実行
- 異なるUCは異なる計算機能を担当
- 上位階層のTLF（恐怖条件付けと消去）を実現するために必要十分な分割

## ROI外の重要な神経組織（UCとして採用せず）

以下の神経組織は、TLF実現に重要ですが、ROI外に位置するためUCとして定義しません：
- **聴覚視床（MGv/PIN）**: ROI_Inputとして条件刺激を供給
- **聴覚皮質（A1/Te1）**: ROI_Inputとして詳細な聴覚情報を供給
- **体性感覚視床（VPL/VPM）**: ROI_Inputとして無条件刺激を供給
- **腹側海馬（vHPC）**: ROI_Inputとして文脈情報を供給
- **青斑核（LC）**: 神経修飾系としてノルアドレナリンを供給
- **腹側被蓋野（VTA）**: 神経修飾系としてドーパミンを供給
- **中脳水道周囲灰白質（PAG）**: ROI_Outputとして防御行動を実行
- **視床下部（HYP）**: ROI_Outputとして自律神経反応を実行
- **分界条床核（BNST）**: ROI_Outputとして持続的不安を生成
