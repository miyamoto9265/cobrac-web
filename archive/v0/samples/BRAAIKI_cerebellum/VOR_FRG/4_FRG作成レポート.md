# 4_FRG作成レポート

## 対象情報

- **TLF**: VOR（Vestibulo-Ocular Reflex / 前庭動眼反射のゲイン適応制御）
- **ROI**: 小脳片葉複合体（Floccular Complex）
- **ROI内UC**: GrC（顆粒細胞）, PC（プルキンエ細胞）, GoC（ゴルジ細胞）, BC（籠細胞）, SC（星状細胞）

---

## ステップ1: 初期分解の判断根拠

### 第2階層の分解方針

TLF「VOR（前庭動眼反射のゲイン適応制御）」を以下の2つのGNに分解した：

1. **前庭入力の分散符号化処理**: 入力段階の処理
2. **適応的VOR応答の計算**: 出力段階の処理

**判断根拠**: 小脳片葉複合体の情報処理は、解剖学的・機能的に「顆粒層での入力処理」と「分子層・プルキンエ細胞層での出力計算」の2段階に明確に分離される。この分離は小脳皮質の層構造に対応しており、神経科学的に妥当な分解軸である。

### 第3階層の分解方針

**前庭入力の分散符号化処理** → 2つの子GN：
- **入力信号の高次元空間展開**: 顆粒細胞によるスパース符号化と平行線維への信号分配
- **入力活動のフィードバックゲイン制御**: ゴルジ細胞による負帰還

**判断根拠**: 顆粒層の情報処理は、「前方向の信号変換（展開）」と「帰還的な活動調節（ゲイン制御）」に機能的に分離可能であり、異なる細胞タイプ（GrC vs GoC）が主に担当する。

**適応的VOR応答の計算** → 3つの子GN：
- **多シナプス入力の非線形統合**: プルキンエ細胞での信号統合
- **周波数選択的フィルタリング**: 分子層介在ニューロンによる周波数調節
- **誤差駆動型シナプス可塑性**: 登上線維による学習制御

**判断根拠**: VOR応答の計算には、(1) リアルタイムの信号統合、(2) 応答の時間特性の調節、(3) 長期的なゲイン適応、の3つの異なるメカニズムが関与する。これらは異なる時間スケール（ミリ秒、サイクル単位、分〜時間）で動作し、独立した制御パラメータを持つ。

### 第4階層の分解方針

**周波数選択的フィルタリング** → 2つの子GN：
- **低周波成分の選択的抑制**: 籠細胞によるソーマ抑制（高域通過フィルタ）
- **高周波成分の選択的抑制**: 星状細胞による樹状突起抑制（低域通過フィルタ）

**判断根拠**: 周波数選択的フィルタリングは、低周波と高周波で異なる神経メカニズム（HCN1チャネル介在のソーマ抑制 vs 樹状突起シャンティング抑制）と異なる抑制部位（細胞体 vs 樹状突起）を用いる。この2つは相補的だが独立した制御機構である。

## ステップ2: マージの判断根拠

### マージ1: 入力層処理の統合

**対象**: 入力信号の高次元空間展開 + 入力活動のフィードバックゲイン制御  
**結果**: → 入力信号の空間展開とゲイン制御

**根拠**:
- **回路的不可分性**: GrCとGoCは顆粒層内で閉じた負帰還ループ（GrC→GoC→GrC）を形成しており、一方の機能が他方の状態に即時的に依存する。GrCの活動レベルはGoCの抑制により制約され、GoCの発火はGrCの活動により駆動される
- **機能的統合性**: スパース符号化の品質（適切な活性化率の維持）は展開とゲイン制御の協調動作に依存しており、どちらか一方では機能が成立しない
- **UC紐づけの効率性**: 最終的にGrC + GoCのペアに紐づくことが自然であり、統合により1つのGNで2つのUCに対応する構造が実現される

### マージ2: 統合と可塑性の統合

**対象**: 多シナプス入力の非線形統合 + 誤差駆動型シナプス可塑性  
**結果**: → 適応的信号統合

**根拠**:
- **シナプス的同一性**: 信号統合と可塑性は同じ平行線維-プルキンエ細胞（PF-PC）シナプス上で同時進行する。統合で使用されるシナプス重みは、可塑性によりリアルタイムで更新される
- **機能的不可分性**: PCにおける「現在の出力」は「過去の学習の結果」であり、統合と可塑性を分離すると、PCの本質的な計算原理（適応的フィルタ）が不明瞭になる
- **解釈可能性の向上**: 「適応的信号統合」という統合的概念は、小脳の適応フィルタ仮説（Adaptive Filter Theory, Dean et al., 2010）と直接対応し、神経科学コミュニティでの理解が容易

### マージ3: 周波数フィルタの統合

**対象**: 低周波成分の選択的抑制 + 高周波成分の選択的抑制  
**結果**: → 周波数選択的フィルタリング（リーフノード化）

**根拠**:
- **機能的相補性**: BCとSCは同じ入力源（平行線維）から駆動され、同じターゲット（PC）を異なる部位（ソーマ vs 樹状突起）で抑制する相補的フィルタペアである。帯域特性の調節という機能は両者の協調により初めて実現される
- **UC紐づけの効率性**: BC + SCのペアとして1つのGNに紐づけることで、制約（各GN最大2UC）を満たしつつ、機能的に意味のある構造が実現される
- **深さの適正化**: 過度に深い階層はUC紐づけ時の制約違反リスクを高めるため、リーフノード化により構造を簡素化

### マージ4: 冗長な親ノードの削除

**対象**: 前庭入力の分散符号化処理（子が1つのみ）  
**結果**: → 削除、子ノードをTLFの直接の子に昇格

**根拠**: マージ1の結果、子ノードが1つのみとなった親ノードは、グラフの複雑性を増すだけで情報量を追加しない。FRGの解釈可能性を高めるため、冗長な中間ノードを削除した。

## ステップ3: UC紐づけの妥当性

### 紐づけ1: 入力信号の空間展開とゲイン制御 → GrC + GoC

**神経科学的妥当性**:
- GrCは小脳顆粒層の主要な興奮性ニューロンであり、苔状線維入力を受け取り、T字型に分岐した平行線維として分子層に投射する。この解剖学的構造が「空間展開」の物理的基盤となる
- GoCは顆粒層の主要な抑制性介在ニューロンであり、平行線維からの興奮を受けてGrCに負帰還抑制を行う。これが「ゲイン制御」の実体である
- 両者は糸球体（glomerulus）内で密結合しており、機能的に不可分な処理ユニットを形成する
- **文献的支持**: Marr-Albus理論（1969, 1971）において、GrCの展開符号化とGoCによるゲイン制御は小脳入力処理の基本原理として広く認められている

### 紐づけ2: 適応的信号統合 → PC + GrC

**神経科学的妥当性**:
- PCは小脳皮質の唯一の出力ニューロンであり、約150,000本の平行線維（GrC出力）から興奮性入力を受ける。この大規模な収束が「信号統合」の基盤である
- PF-PCシナプスにおけるLTD（長期抑圧）は、登上線維（IO由来）と平行線維の同時活性化により誘導される。これがVORゲイン適応の主要メカニズムであり、「適応的」の実体である
- GrCは分散符号化された入力信号をPCに供給する入力源であり、GrC-PC間のシナプス接続の強度分布がVORゲインを決定する
- **文献的支持**: Ito（1982）のVOR適応学習モデルにおいて、PF-PCシナプスのLTDがVORゲイン減少の神経基盤であることが実験的に確立されている。また、LTPによるゲイン増加もBoyden & Raymond（2003）により報告されている

### 紐づけ3: 周波数選択的フィルタリング → BC + SC

**神経科学的妥当性**:
- BCはPC細胞体および軸索起始部（pinceau構造）に強力なGABA作動性抑制を行う。HCN1チャネルを介したソーマコンダクタンスの増加により、特に低周波入力に対するシャンティング抑制が増強される（Nolan et al., 2003）
- SCはPC樹状突起にGABA作動性シナプスを形成し、樹状突起でのシャンティング抑制により高周波の急速な電位変化を選択的に減衰させる
- BCとSCの異なる抑制部位（ソーマ vs 樹状突起）と異なる時定数は、相補的な周波数フィルタとしての機能分化を支持する
- **文献的支持**: Häusser & Clark（1997）による小脳分子層介在ニューロンの周波数依存性抑制特性の報告、Mittmann et al.（2005）によるフィードフォワード抑制の時間特性の解析が、この紐づけの妥当性を支持する

## 制約充足の総括

### GN-UC接続数制約

| 制約 | 要件 | 結果 | 判定 |
|------|------|------|------|
| 制約1: GN→UC | 各GN最大2UC | 全GN = 2UC | ✓ |
| 制約2: UC→GN | 各UC最大2GN | 最大 = GrC(2GN), 他は1GN | ✓ |
| 必須: 各GN複数UC | 各GN ≥ 2UC | 全GN = 2UC | ✓ |

### ROI制約

| 制約 | 結果 | 判定 |
|------|------|------|
| ROI内UCのみ使用 | GrC, PC, GoC, BC, SC（全てROI内） | ✓ |
| ROI外UC不使用 | VN, IO, OMNは情報フロー図で参考表示のみ | ✓ |

### 構造的妥当性

| 観点 | 評価 |
|------|------|
| 全ROI内UCの網羅 | 5/5 UC使用 ✓ |
| ノード名の重複なし | 全ノード名がユニーク ✓ |
| DAG構造 | 循環なし ✓ |
| 親子の十分性 | 各親の機能が子の組み合わせで実現される ✓ |
| BIF整合性 | UC間接続が既知の神経解剖学的接続と一致 ✓ |

## 最終FRG構造サマリー

```
TLF: VOR（前庭動眼反射のゲイン適応制御）
├── GN(L2): 入力信号の空間展開とゲイン制御
│   ├── UC: GrC（信号空間展開器）
│   └── UC: GoC（入力ゲイン制御器）
└── GN(L2): 適応的VOR応答の計算
    ├── GN(L3): 適応的信号統合
    │   ├── UC: PC（適応的統合出力器）
    │   └── UC: GrC（信号空間展開器）  ※共有ノード
    └── GN(L3): 周波数選択的フィルタリング
        ├── UC: BC（低周波抑制フィルタ）
        └── UC: SC（高周波抑制フィルタ）
```

- ノード総数: 10（TLF:1, GN:4, UC:5）
- 階層数: 4（TLF → L2 GN → L3 GN → UC）
- GN-UC接続数: 6（3GN × 2UC）
- 共有UC: GrC（2つのGNに所属）
