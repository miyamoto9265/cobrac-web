# ステップ5: FRG作成レポート

## 概要

本レポートでは、小脳小節におけるVOR（前庭動眼反射）適応学習のFRG（Function Realization Graph）作成プロセスについて、各ステップでの判断理由、マージの根拠、UC紐づけの妥当性、機能詳細の説明を包括的に報告する。

---

## 1. ステップ1: TLFの段階的分解

### 分解方針

VOR適応学習を実現するために必要な主要な部分機能を以下のように特定：

1. **感覚運動情報の統合**: 前庭、視覚、運動コマンドの情報を統合
2. **文脈の表現**: 異なる感覚運動状況を区別可能な表現を生成
3. **誤差信号の検出**: 視覚誤差（retinal slip）を検出
4. **適応的なゲイン調整**: 誤差に基づいてVORゲインを調整
5. **出力の時間的調整**: 適切な時間スケールで応答

### 初期分解結果

- **第1階層**: TLF（VOR適応学習）
- **第2階層**: 3つのGN（感覚運動文脈表現、誤差駆動型可塑性、適応的出力生成）
- **第3階層**: 7つのGN
- **第4階層**: 3つのGN

合計13個のGNを定義。

### 分解の判断理由

#### 第2階層の分解

TLFを以下の3つの主要機能に分解：
1. **感覚運動文脈表現**: 入力の表現に特化
2. **誤差駆動型可塑性**: 学習メカニズムに特化
3. **適応的出力生成**: 出力の生成に特化

**理由**: VOR適応学習は、(1)文脈の認識、(2)誤差に基づく学習、(3)学習に基づく出力、という3つの明確に異なるプロセスから構成される。これらは機能的に独立しており、それぞれが独自の計算を担当する。

#### 第3階層・第4階層の分解

各第2階層GNをさらに細分化：
- 感覚運動文脈表現 → 入力統合、拡張符号化、ゲイン調整
- 誤差駆動型可塑性 → 重み更新、誤差信号統合
- 適応的出力生成 → 出力計算、周波数調整

**理由**: 各機能が複数のサブプロセスから構成されることが神経科学的に知られている。例えば、文脈表現は単なる入力受容ではなく、拡張符号化とゲイン調整を含む複雑なプロセスである。

## 2. ステップ2: 冗長性の削減とノードのマージ

### マージの必要性評価

初期分解結果を分析した結果、以下の結論に至った：

**マージ不要**: 各GNが独立した明確な機能を持ち、重複や過剰な分解が見られない。

### 評価の根拠

1. **機能の独立性**: 各GNが異なる計算プロセスを担当
2. **階層構造の妥当性**: 親子関係が論理的に整合
3. **解釈可能性**: グラフが理解しやすい
4. **神経科学的裏付け**: 各GNが既知の神経メカニズムに対応

### ただし後に調整が必要と判明

ステップ3でUCとの紐づけを行う際、接続数制約（各GN≤2UC、各UC≤2GN）を満たすことが困難であることが判明。そのため、ステップ3でGN構造を調整することとなった。

## 3. ステップ3: UCとの紐づけとFRGの完成

### 制約と課題

指示書で定められた制約：
1. 各GNは最大2つのUCに接続
2. 各UCは最大2つのGNに接続
3. 各GNは複数のUCに分解される

### 初期紐づけの試行と問題点

リーフノード（第3・第4階層のGN）を直接UCに紐づけようとしたところ、以下の問題が発生：

- **GrCが5つ以上のGNに接続** → 制約違反
- **PCが3つ以上のGNに接続** → 制約違反
- **GoCが3つのGNに接続** → 制約違反

**原因**: リーフノードの粒度が細かすぎ、多くのGNが同じUC（特にGrCとPC）に依存していた。

### 解決策: 第2階層GNの再構成

制約を満たすため、第2階層のGN構造を以下のように再設計：

| 新GN名 | 機能 | 接続UC |
| ------ | ---- | ------ |
| 文脈拡張表現 | 感覚運動情報の統合と高次元拡張 | GrC, GoC |
| 適応的可塑性 | 誤差駆動型の重み学習 | PC, GrC |
| 出力計算調整 | VORゲイン調整信号の計算と低周波調整 | PC, BC |
| 周波数最適化 | 周波数帯域の最適化 | BC, SC |

### 再構成の判断理由

#### 統合1: 入力処理系

「多モダリティ入力統合」と「高次元拡張符号化」を統合 → **文脈拡張表現**

**理由**: 両者は連続したプロセスであり、GrCとGoCの協調で実現される単一の機能と見なせる。入力統合と拡張符号化は分離できない密接な関係にある。

#### 統合2: 可塑性機構

「シナプス重み更新」と「誤差信号統合」を統合 → **適応的可塑性**

**理由**: 両者はPCで実現される単一の可塑性メカニズムの2つの側面（誤差の受容と重みの変化）であり、分離する必要性が低い。

#### 統合3: 出力調整系

「文脈依存的出力計算」と低周波調整を統合 → **出力計算調整**

「低周波数フィルタリング」と「高周波数フィルタリング」を統合 → **周波数最適化**

**理由**: 出力の計算と周波数調整は密接に関連し、PCとBC/SCの協調で実現される。周波数フィルタリングは低周波と高周波の相補的な抑制により実現されるため、両者を統合することで機能的な統一性が向上。

### 最終的なGN-UC紐づけ

| GN | UC | 接続数確認 |
| -- | -- | ---------- |
| 文脈拡張表現 | GrC, GoC | ✓ GN側: 2UC |
| 適応的可塑性 | PC, GrC | ✓ GN側: 2UC |
| 出力計算調整 | PC, BC | ✓ GN側: 2UC |
| 周波数最適化 | BC, SC | ✓ GN側: 2UC |

| UC | GN | 接続数確認 |
| -- | -- | ---------- |
| GrC | 文脈拡張表現、適応的可塑性 | ✓ UC側: 2GN |
| GoC | 文脈拡張表現 | ✓ UC側: 1GN |
| PC | 適応的可塑性、出力計算調整 | ✓ UC側: 2GN |
| BC | 出力計算調整、周波数最適化 | ✓ UC側: 2GN |
| SC | 周波数最適化 | ✓ UC側: 1GN |

**結果**: すべての制約を満たす ✓

### 神経科学的妥当性

各GN-UC紐づけの神経科学的根拠：

#### 文脈拡張表現 → GrC, GoC

- **GrC**: HCDで「苔状線維入力の高次元拡張表現」と定義。脳内最多の細胞（約500億個）により、低次元入力を極めて高次元に拡張
- **GoC**: HCDで「顆粒細胞層活動の時空間制御信号」と定義。GrCへのフィードバック抑制により、拡張表現の質を制御

**神経科学的根拠**: GrCとGoCの両方が苔状線維入力を受け、GoCがGrCを抑制するフィードバック回路を形成（HCD 4_Connection.md）。両者の協調により、適切なスパース性とパターン分離が実現される。

#### 適応的可塑性 → PC, GrC

- **PC**: HCDで「シナプス可塑性によるVORゲイン調整」と定義。平行線維-PCシナプスでLTD/LTPが生じる
- **GrC**: PCの可塑性の対象となる平行線維入力を提供

**神経科学的根拠**: GrCの平行線維がPCにシナプスを形成（HCD 4_Connection.md: GrC→PC）。登上線維からの誤差信号とGrCの平行線維活動が同時発生すると、LTDが誘導される（Marr-Albusモデル）。これがVOR適応学習の基礎となる。

#### 出力計算調整 → PC, BC

- **PC**: HCDで「VOR適応ゲイン調整信号」を生成。平行線維の線形結合を計算
- **BC**: HCDで「低周波数抑制信号」を生成。PCの低周波応答を抑制

**神経科学的根拠**: PCが平行線維入力の重み付き線形結合を計算し、VORゲイン調整信号を前庭神経核に出力（HCD 3_UC.md）。BCがPCの細胞体・軸索起始部を抑制することで、低周波数応答を減少させる（HCD 4_Connection.md: BC→PC）。

#### 周波数最適化 → BC, SC

- **BC**: 低周波数成分を抑制
- **SC**: 高周波数成分を抑制

**神経科学的根拠**: BCとSCは相補的な周波数フィルタリングを実行（HCD 3_UC.md）。BCは平行線維バーストの低周波数（5-10 Hz）に強く応答、SCは高周波数（20-50 Hz）に応答。両者の協調により、PCは中間周波数帯域（10-20 Hz）で選択的に応答する。

## 4. ステップ4: 機能詳細の説明

### 機能関連項目の定義方針

HCDにおけるUCの機能定義と同様の観点から、TLFと各GNについて以下の5項目を定義：

1. **A1. Requirement**: 親ノードから要求される計算機能
2. **A2. Requirement realization by children**: 子ノードの組み合わせによる実現方法
3. **B1. Capability**: 意味論的要素を除去した一般的な計算機能
4. **B2. Mechanism**: 計算機構の具体的な説明
5. **B3. Implementation**: 数式による表現

### 各ノードの機能詳細の整合性

#### TLF（VOR適応学習）

**A1とA2の整合性**:
- A1: VORゲインの適応的調整という全体機能を記述
- A2: 4つのGN（文脈拡張表現、適応的可塑性、出力計算調整、周波数最適化）の協調で実現されることを説明

✓ **整合**: 4つのGNが協調することで、視覚誤差を最小化するVOR適応学習が実現される

**B1-B3の流れ**:
- B1: 誤差駆動型教師あり学習システムとして一般化
- B2: 入力拡張、可塑性、出力計算、周波数調整という4つのメカニズムを説明
- B3: 特徴変換Φ(x)、重み更新dw/dt、出力計算y(t)を数式で表現

✓ **一貫**: CapabilityからMechanism、Implementationへと論理的に具体化

#### 第2階層GN

各GNについて、親ノード（TLF）の要求を満たし、子ノード（UC）で実現される機能として記述：

- **文脈拡張表現**: 入力の高次元拡張という計算機能を、GrCとGoCの協調で実現
- **適応的可塑性**: 誤差駆動型の重み学習を、PCとGrCの協調で実現
- **出力計算調整**: 出力計算と低周波調整を、PCとBCの協調で実現
- **周波数最適化**: 周波数帯域の最適化を、BCとSCの協調で実現

✓ **整合**: すべてのGNが親ノードの要求を満たし、子ノードで実現可能

### 数式の妥当性

各ノードのB3（Implementation）で記述した数式が、神経科学的に妥当か確認：

#### TLF: 誤差駆動型学習

```
y(t) = w(t)^T Φ(x(t))
dw/dt = η e(t) Φ(x(t))
```

**妥当性**: δルール（ウィドロー・ホフの学習則）またはパーセプトロン学習則に相当。教師あり学習の標準的な定式化。

#### 文脈拡張表現: 拡張符号化

```
φ_j = f(Σ_i w_ji x_i - g)
g = α Σ_j φ_j
```

**妥当性**: ReLUネットワークによる特徴抽出とフィードバックゲイン制御。神経ネットワークモデルの標準的な定式化。

#### 適応的可塑性: LTD/LTP

```
dw_j/dt = -η_LTD r_j(t) e(t) + η_LTP r_j(t) (1 - e(t))
```

**妥当性**: 小脳のLTD/LTPモデルに基づく。Marr-Albusモデルの数式化として広く受け入れられている。

#### 出力計算調整: 線形読み出しと低周波抑制

```
V(t) = Σ_j w_j r_j(t) - I_low(t)
y(t) = f(V(t) - θ)
```

**妥当性**: 線形-非線形（LN）モデル。神経科学で広く使われる単純なモデル。

#### 周波数最適化: 帯域通過フィルタ

```
I_low(t) = γ_low * LPF(r(t), f_low)
I_high(t) = γ_high * HPF(r(t), f_high)
```

**妥当性**: 低域通過・高域通過フィルタの組み合わせ。BCとSCの周波数選択性を表現する標準的な方法。

## 5. 制約と今後の課題

### FRGの制約

#### 制約1: 階層の簡略化

接続数制約を満たすため、第2階層を4つのGNに簡略化した。これにより：
- **利点**: 制約を満たし、解釈可能性が向上
- **欠点**: 初期分解で特定した詳細な機能（第3・第4階層のGN）が失われた

**影響**: 細かい機能分解が失われたことで、一部の詳細な計算プロセスがGN名から直接読み取れなくなった。ただし、機能詳細（A1-B3）で補完されている。

#### 制約2: UC粒度の固定

UCはHCDで定義されたものを使用するため、UCの粒度を変更できない。これにより：
- **利点**: HCDとの整合性が保たれる
- **欠点**: GN-UC紐づけの自由度が制限される

**影響**: UCが5つしかないため、GNも4つに制限される。より詳細なFRGを作成するには、UCをさらに細分化する必要があるが、それはHCDの再定義を要する。

#### 制約3: ROI内UCのみ使用

指示書に従い、ROI内（小脳小節内）のUCのみを使用した。これにより：
- **利点**: FRGが小脳小節の情報処理に焦点を当てる
- **欠点**: VOR適応学習には小脳外の要素（登上線維、苔状線維の起源）も重要だが、それらはFRGに含まれない

**影響**: FRGはVOR適応学習の一部（小脳小節での処理）のみを記述しており、全体像ではない。

### 今後の課題

#### 課題1: 定量的パラメータの推定

機能詳細（B3）で記述した数式には、未定義のパラメータが多数含まれる：
- 学習率（η, η_LTD, η_LTP）
- ゲイン係数（α, γ_low, γ_high）
- カットオフ周波数（f_low, f_high）
- シナプス重み（w_ji, w_j）

これらのパラメータを、実験データから推定する必要がある。

#### 課題2: FRGの実装とシミュレーション

本FRGを実際にシミュレーションモデルとして実装し、以下を検証：
- VOR適応学習の再現
- 小節除去の効果の再現
- 異なる視覚条件下での適応の予測

シミュレーションにより、FRGの妥当性を定量的に評価できる。

#### 課題3: 階層の詳細化

接続数制約を緩和または代替手段を導入し、より詳細な階層構造を持つFRGを作成：
- 各GNを2つ以上のUCに分解可能にする
- 各UCが2つ以上のGNに接続可能にする
- または、中間階層のノードを導入し、階層を深くする

これにより、初期分解で特定した詳細な機能を保持したFRGが作成可能。

#### 課題4: HCDとFRGの統合

HCDとFRGは相補的な記述であり、統合することでより完全な理解が得られる：
- **HCD**: UC間の接続（神経解剖学的接続）を記述
- **FRG**: TLFからUCへの機能分解（計算機能の階層）を記述

両者を統合したモデルにより、「どの機能がどのUCで実現され、それらがどのように接続されているか」を包括的に記述できる。

#### 課題5: 他の小脳機能への拡張

小脳小節はVOR適応だけでなく、以下の機能にも関与：
- 滑動性追跡眼球運動（Smooth pursuit）
- 視運動性眼振（Optokinetic response）

これらの機能のFRGを作成し、VOR適応学習のFRGと比較することで、小脳小節の多機能性を理解できる。

## 6. 結論

### FRG作成の成果

本タスクでは、小脳小節におけるVOR適応学習のFRGを作成した：
- **階層数**: 3階層（TLF、GN、UC）
- **GN数**: 4個
- **UC数**: 5個
- **接続数制約**: すべて遵守

### FRGの特徴

1. **機能的階層構造**: TLFが4つのGNに分解され、各GNが2つのUCで実現される明確な階層
2. **制約遵守**: GN-UC間の接続数制約をすべて満たす
3. **神経科学的妥当性**: HCDに基づく神経科学的根拠を持つ
4. **機能詳細の定義**: 各ノードの計算機能を詳細に記述（A1-B3）
5. **解釈可能性**: グラフ構造と機能詳細により、VOR適応学習の計算メカニズムが理解可能

### FRGの意義

本FRGは、VOR適応学習という複雑な学習機能を、階層的に分解し、実際の神経組織（UC）と接地させることで、以下の理解を促進：
- **機能分解**: TLFがどのような部分機能から構成されるか
- **実装**: 各部分機能がどのUCで実現されるか
- **計算原理**: 各機能がどのような計算機構で実現されるか

### 今後の展望

本FRGは、VOR適応学習の計算神経科学的理解の基盤となる。今後、定量的パラメータの推定、シミュレーションモデルの構築、HCDとの統合により、より完全で検証可能なモデルへと発展させることができる。
