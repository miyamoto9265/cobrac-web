| 適応的可塑性       | 視覚誤差信号（網膜滑り）を受容し、その誤差が最小化されるように、感覚運動文脈（高次元特徴表現）とVORゲイン調整出力の対応関係を可塑的に学習する。入力は高次元特徴表現と誤差信号、出力は更新された対応関係（シナプス重み）。                              | 2つの子UC（PC、GrC）の協調により実現される。GrCが高次元特徴表現を平行線維として提供し、PCがその平行線維入力と登上線維からの誤差信号を統合する。誤差信号と平行線維活動が同時に発生すると、平行線維-PCシナプス重みが可塑的に変化する（LTD）。誤差信号がない場合は逆方向の可塑性（LTP）が生じる。この機構により、誤差駆動型の教師あり学習が実現される。 | 誤差信号に基づいてシナプス重みを更新する教師あり学習機構。入力活動と誤差信号の相関に応じて重みを変化させ、誤差を最小化する方向に学習する。                                    | 誤差検出：登上線維により視覚誤差信号を受容。共活性化検出：平行線維活動と誤差信号の時間的重なりを検出。可塑性誘導：共活性化時に細胞内カルシウム濃度が上昇し、シナプス重みを減少させる（LTD）。逆の可塑性：誤差信号がない場合、活性化された平行線維シナプス重みが増加（LTP）。平衡：LTDとLTPのバランスにより、誤差最小化に向けた重み調整が実現される。                     | 平行線維入力 r_j(t)、誤差信号 e(t)、シナプス重み w_j(t)。<br>dw_j/dt = -η_LTD r_j(t) e(t) + η_LTP r_j(t) (1 - e(t))<br>ここで η_LTD はLTD学習率、η_LTP はLTP学習率。誤差が大きい時（e(t)が大きい）、活性化された平行線維のシナプス重みが減少。誤差が小さい時、活性化された平行線維のシナプス重みが増加。平衡状態では、特定の文脈xに対する出力y = Σ_j w_j φ_j(x)が誤差を最小化する。                                                                                            |
| 出力計算調整       | 学習されたシナプス重み（感覚運動文脈と出力の対応関係）に基づいて、現在の感覚運動文脈に対応するVORゲイン調整信号を計算する。さらに、出力信号の低周波数成分を抑制することで、出力の時間特性を調整する。入力は高次元特徴表現、出力は周波数調整されたVORゲイン調整信号。       | 2つの子UC（PC、BC）の協調により実現される。PCが平行線維入力（高次元特徴表現）の重み付き線形結合を計算し、VORゲイン調整信号を生成する。BCがPCの低周波数応答を抑制することで、出力の周波数帯域を高周波側にシフトさせる。これにより、適切な時間スケールでのVORゲイン調整が実現される。                                   | 学習された重みベクトルと入力特徴ベクトルの内積により出力を計算する線形読み出し器（linear readout）。さらに、出力の低周波数成分を選択的に抑制する周波数フィルタ。                  | 線形結合：各平行線維入力に学習されたシナプス重みを乗じ、総和を計算。閾値処理：総和が閾値を超えると発火。抑制統合：低周波数抑制信号を受け取り、膜電位を過分極。周波数選択：低周波数入力に対する応答が抑制され、高周波数入力に対して選択的に応答。出力生成：調整された発火率が前庭神経核へのVORゲイン調整信号となる。                                          | 平行線維入力 r_j(t)、シナプス重み w_j、低周波数抑制 I_low(t)、膜電位 V(t)、出力 y(t)。<br>V(t) = Σ_j w_j r_j(t) - I_low(t)<br>y(t) = f(V(t) - θ)<br>ここで f は活性化関数（例：ReLU）、θ は発火閾値。低周波数抑制 I_low(t) は、入力の低周波数成分に比例：I_low(t) = γ LPF(Σ_j r_j(t), f_cutoff) （低域通過フィルタ）。これにより、y(t)は高周波数成分を選択的に伝達。                                                                                    |
| 周波数最適化       | 出力信号の周波数帯域を最適化するため、低周波数成分と高周波数成分の両方を抑制する。これにより、VORゲイン調整信号が適切な周波数帯域（中間周波数）で応答するようにチューニングされる。入力は平行線維活動、出力は低周波・高周波抑制信号。                        | 2つの子UC（BC、SC）の協調により実現される。BCが平行線維活動の低周波数成分に応答し、PCへの低周波数抑制を生成する。SCが平行線維活動の高周波数成分に応答し、PCへの高周波数抑制を生成する。両者の相補的な抑制により、PCは中間周波数帯域で選択的に応答するようにチューニングされる。                                      | 入力信号の周波数スペクトルを解析し、特定の周波数帯域を選択的に抑制する帯域消去フィルタ（band-stop filter）。低周波と高周波の両方を抑制することで、中間周波数帯域を通過させる帯域通過特性を実現。 | 低周波検出：平行線維入力の低周波数成分（例：5-10 Hz）に選択的に応答するニューロン集団（BC）が、持続的な抑制を生成。高周波検出：平行線維入力の高周波数成分（例：20-50 Hz）に選択的に応答するニューロン集団（SC）が、抑制を生成。抑制統合：両方の抑制がPCに収束し、低周波と高周波の両方に対するPC応答を減少。帯域通過：中間周波数帯域（例：10-20 Hz）でのみPCが強く応答。 | 平行線維入力 r(t)、低周波抑制 I_low(t)、高周波抑制 I_high(t)。<br>I_low(t) = γ_low * LPF(r(t), f_low)<br>I_high(t) = γ_high * HPF(r(t), f_high)<br>ここで LPF は低域通過フィルタ、HPF は高域通過フィルタ、γ_low と γ_high は抑制強度係数。PCの膜電位：V_PC(t) = (興奮性入力) - I_low(t) - I_high(t)。周波数応答：H(f) = 1 / (1 + (f/f_low)^2) * (f/f_high)^2 / (1 + (f/f_high)^2)、これは f_low < f < f_high で最大となる帯域通過特性。 |

## 各項目の整合性確認

### TLFの整合性

**A1とA2の整合性**:
- A1（Requirement）: VORゲインの適応的調整
- A2（Requirement realization by children）: 4つのGN（文脈拡張表現、適応的可塑性、出力計算調整、周波数最適化）で実現

✓ **整合**: 4つのGNの組み合わせでVOR適応学習が実現される

**B1-B3の流れ**:
- B1（Capability）: 誤差駆動型教師あり学習
- B2（Mechanism）: 入力拡張、可塑性、出力計算、周波数調整
- B3（Implementation）: 数式による記述

✓ **一貫**: CapabilityからMechanism、Implementationへと論理的に展開

### 文脈拡張表現の整合性

**親ノードとの関係**:
- 親ノード（TLF）は「感覚運動情報の統合と拡張表現」を要求
- 本GNはその要求を満たす

✓ **整合**

**子ノード（GrC、GoC）との関係**:
- GrCが拡張表現を生成
- GoCがゲイン調整により質を最適化
- 両者の協調で文脈拡張表現が実現

✓ **整合**
