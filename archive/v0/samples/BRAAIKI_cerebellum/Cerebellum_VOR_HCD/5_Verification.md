### 2. 情報フローの妥当性：ROI_InputからROI_Outputへの情報処理経路が成立しているか

#### ROI_Input（小脳小節への入力）
1. **前庭情報**: `MF_VN`, `MF_VIII`（前庭神経核、一次前庭神経）
2. **視覚誤差信号**: `CF_IO`（下オリーブ核からの登上線維）
3. **運動コマンドコピー**: `MF_PMT`（傍正中束核）
4. **その他の情報**: `MF_PN`, `MF_PH`（橋底核、舌下神経周囲核群）

#### ROI_Output（小脳小節からの出力）
- **VORゲイン調整信号**: `PC` → `VN_output`（前庭神経核）

#### 情報処理経路の検証

**経路1: 直接興奮性経路**
```
ROI_Input (苔状線維) → GrC → PC → VN_output (ROI_Output)
```
- 5種類の苔状線維入力が顆粒細胞を興奮
- 顆粒細胞の平行線維がプルキンエ細胞を興奮
- プルキンエ細胞が前庭神経核を抑制（VORゲイン調整）
- **状態**: ✓ 成立

**経路2: フィードバック抑制経路**
```
ROI_Input (苔状線維) → GrC ⇄ GoC → GrC → PC → VN_output
```
- 苔状線維が顆粒細胞とゴルジ細胞の両方を興奮
- 顆粒細胞もゴルジ細胞を興奮（フィードバック）
- ゴルジ細胞が顆粒細胞を抑制（ゲイン調整）
- 調整された顆粒細胞活動がPCへ
- **状態**: ✓ 成立

**経路3: フィードフォワード抑制経路（BC/SC経由）**
```
ROI_Input (苔状線維) → GrC → BC/SC → PC → VN_output
```
- 顆粒細胞の平行線維がBC/SCを興奮
- BC/SCがPCを抑制（周波数フィルタリング）
- 周波数調整されたPC活動が前庭神経核へ
- **状態**: ✓ 成立

**経路4: 可塑性誘導経路**
```
ROI_Input (登上線維) → PC (シナプス可塑性) ← GrC
```
- 登上線維（視覚誤差信号）がPCに複雑スパイクを誘発
- 平行線維-PCシナプス重みが可塑的に変化（LTD/LTP）
- VORゲインが適応的に調整
- **状態**: ✓ 成立

**結論**: ROI_InputからROI_Outputへの情報処理経路が明確に成立している。複数の並列経路（直接経路、抑制性調整経路、可塑性経路）が存在し、相互に協調してVOR適応学習を実現する構造になっている。

### 3. UCの適切性：重複や欠落がないか、粒度は適切か

#### 重複の検証
各UCが異なる情報処理機能を担当しているか確認：

- `GrC`: 拡張符号化（expansion recoding）
- `GoC`: ゲイン調整・時空間制御
- `BC`: 低周波数フィルタリング
- `SC`: 高周波数フィルタリング
- `PC`: シナプス可塑性による適応学習・出力生成

**結論**: ✓ 重複なし。各UCは独自の機能を担当している。

#### 欠落の検証
VOR適応学習に必要な情報処理機能がすべてカバーされているか確認：

1. **入力統合**: ✓ GrCが担当
2. **パターン分離**: ✓ GrCが担当
3. **ゲイン調整**: ✓ GoCが担当
4. **周波数フィルタリング**: ✓ BC/SCが担当
5. **適応学習**: ✓ PCが担当（登上線維によるLTD/LTP）
6. **出力生成**: ✓ PCが担当

**結論**: ✓ 欠落なし。VOR適応学習に必要なすべての機能がカバーされている。

#### 粒度の検証

- `GrC`: 脳内最多の細胞だが、集団として単一の処理単位（拡張符号化）と見なせる → ✓ 適切
- `GoC`: 抑制性介在ニューロンとして独立した機能単位 → ✓ 適切
- `BC`: 細胞体レベルでPCを抑制する特異的機能 → ✓ 適切
- `SC`: 樹状突起レベルでPCを抑制する特異的機能 → ✓ 適切
- `PC`: 小脳皮質からの唯一の出力ニューロンとして独立した単位 → ✓ 適切

**結論**: ✓ 粒度適切。各UCはメゾスコピックレベルとして適切な粒度を持つ。

### 5. TLFとの整合性：定義されたHCDがTLFを実現できる構造になっているか

#### TLF: VOR適応学習（VOR adaptive gain control）

#### 必要な機能要素
1. **前庭入力の受容**: ✓ `MF_VN`, `MF_VIII`経由で実現
2. **視覚誤差信号の受容**: ✓ `CF_IO`経由で実現
3. **運動コマンドの受容**: ✓ `MF_PMT`経由で実現
4. **入力の統合と特徴抽出**: ✓ `GrC`が実現
5. **誤差駆動型学習**: ✓ `PC`の登上線維による可塑性で実現
6. **VORゲイン調整出力**: ✓ `PC`→`VN_output`で実現

#### VOR適応学習のメカニズム

1. **正常なVOR**: 頭部運動時、前庭入力が前庭神経核を経由して動眼神経核に到達し、代償性眼球運動を生成
   
2. **視覚誤差の検出**: 視線が不安定な場合、網膜滑り（retinal slip）が生じ、視索核・下オリーブ核を経由して登上線維に伝達される
   
3. **小脳小節の役割**:
   - 前庭情報、運動コマンドコピー、視運動情報が苔状線維として`GrC`に入力
   - `GrC`が文脈特異的な高次元表現を生成
   - `PC`が平行線維入力を統合し、前庭神経核への抑制を生成
   - 登上線維（視覚誤差信号）が`PC`の平行線維-PCシナプスを可塑的に変化させる
   
4. **適応学習**:
   - 視覚誤差が生じると、登上線維が活性化
   - その時点で活性化している平行線維-PCシナプスにLTDが誘導される
   - 次回同じ文脈では、PC応答が減少し、前庭神経核への抑制が減少
   - 結果として、VORゲインが調整され、視覚誤差が最小化される

**結論**: ✓ HCDはTLF（VOR適応学習）を実現できる完全な構造を持つ。

## 追加検証：計算論的妥当性

### Marr-Albusモデルとの対応

**Marr-Albusモデル**は、小脳学習の古典的理論：
- 平行線維: 文脈情報を伝達
- 登上線維: 教師信号を伝達
- プルキンエ細胞: 平行線維-PCシナプスの可塑性により学習

**本HCDとの対応**:
- `GrC`の平行線維出力: 文脈情報（感覚運動統合表現） → ✓ 対応
- `CF_IO`: 教師信号（視覚誤差） → ✓ 対応
- `PC`: シナプス可塑性による学習 → ✓ 対応

**結論**: ✓ 本HCDはMarr-Albusモデルと完全に一致する構造を持つ。

### カーネルマシンとしての小脳

最近の計算論（Cerebellum as a kernel machine）との対応：
- `GrC`: カーネル基底関数として機能し、入力を高次元特徴空間に射影
- `PC`: カーネル基底関数の線形結合により出力を計算
- 登上線維: 重要な入力パターンを記憶するための信号

**結論**: ✓ 本HCDは最新の計算論とも整合する。
