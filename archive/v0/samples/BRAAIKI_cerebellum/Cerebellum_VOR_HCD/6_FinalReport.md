## 1. TLFとROIの概要

### Top Level Function (TLF)
**VOR適応学習（Vestibulo-Ocular Reflex Adaptive Gain Control）**

VOR（前庭動眼反射）は、頭部運動時に視線を安定させるための反射である。VOR適応学習は、視覚フィードバック（網膜滑り：retinal slip）に基づいて、VORゲイン（眼球速度/頭部速度比）を調整し、視線安定性を最適化する学習プロセスである。

### Region of Interest (ROI)
**小脳小節（Cerebellar Flocculus）**

小脳小節は、小脳皮質の一部で、前庭-動眼系の制御に特化した領域である。VOR適応学習において中心的な役割を果たし、小節を除去するとVORの新規適応学習が永久に不可能になることが実験的に示されている。

### ROIの妥当性
小脳小節は以下の理由からVOR適応学習のROIとして適切である：

1. **適切な入力**: 前庭情報、視覚誤差信号、運動コマンドコピーを受容
2. **適切な出力**: 前庭神経核への抑制性投射によりVORゲインを調整
3. **機能的必須性**: 小節除去により適応学習が完全に消失
4. **豊富な神経科学的証拠**: 解剖学、電気生理学、行動学的研究により裏付け

## 2. 定義されたUCの一覧

本HCDでは、小脳小節内に5つのUniform Circuit（UC）を定義した。

### UC一覧と役割

| Circuit ID | 名称 | 役割 | 根拠 |
| ---------- | ---- | ---- | ---- |
| `GrC` | 顆粒細胞<br>(Granule Cells) | 苔状線維入力の高次元拡張表現。多様な感覚運動情報を組み合わせてスパース符号化により分離可能な高次元特徴空間に投影 | 脳内最多の神経細胞（約500億個）。拡張符号化（expansion recoding）を実現し、下流のPCが線形読み出し可能な表現を生成。糸球内で複数の苔状線維から入力を受け、平行線維として出力する構造が、組み合わせ符号化を可能にする |
| `GoC` | ゴルジ細胞<br>(Golgi Cells) | 顆粒細胞層活動の時空間制御。顆粒細胞の活動パターンを時間的に同期させ、空間的にグループ選択することで情報伝達ゲインを調整 | 苔状線維からのフィードフォワード興奮と顆粒細胞からのフィードバック興奮を受け、顆粒細胞に抑制を返す。顆粒細胞層の過剰活性化を防ぎ、適切なダイナミックレンジとリズミカルな発火パターンを生成 |
| `BC` | バスケット細胞<br>(Basket Cells) | 低周波数抑制。平行線維入力の低周波数成分に応答してPCの細胞体・軸索起始部を抑制し、PCの応答周波数帯域を調整 | PCの細胞体・軸索起始部にバスケット様シナプス複合体を形成。低周波数バーストに対して強い応答を示し、HCN1チャネル活性化によるシャント抑制を引き起こす。PC発火の開始点近くで作用するため、出力を直接制御できる |
| `SC` | ステラ細胞<br>(Stellate Cells) | 高周波数抑制。平行線維入力の高周波数成分に応答してPCの樹状突起を抑制し、PCの応答周波数帯域を調整 | PCの樹状突起にシナプスを形成。高周波数バーストに対して選択的に応答し、平行線維からの興奮性入力を局所的に相殺。BCと相補的な周波数フィルタリングを実現 |
| `PC` | プルキンエ細胞<br>(Purkinje Cells) | VOR適応ゲイン調整信号の生成。平行線維からの多数の入力と登上線維からの誤差信号を統合し、シナプス可塑性により適応学習を実現。前庭神経核への抑制により、VORゲインを調整 | 小脳皮質からの唯一の出力ニューロン。約20万の平行線維シナプスと1本の登上線維シナプスを受ける。登上線維の活性化により平行線維-PCシナプスに長期抑圧（LTD）が誘導され、適応学習が実現される（Marr-Albusモデル） |

## 3. 情報処理フロー：ROI_InputからROI_Outputへの処理の流れ

### 3.1 ROI_Input（小脳小節への入力）

| 入力 | 起源 | 内容 |
| ---- | ---- | ---- |
| `MF_VN` | 前庭神経核 | 頭部運動に関する前庭情報、視運動情報 |
| `MF_VIII` | 一次前庭神経（Scarpa神経節） | 半規管からの一次前庭情報（頭部角速度） |
| `MF_PN` | 橋底核 | 大脳皮質からの運動関連情報 |
| `MF_PH` | 舌下神経周囲核群 | 前庭動眼反射関連情報 |
| `MF_PMT` | 傍正中束核 | 運動コマンドのコピー（efference copy）、サッケード関連情報 |
| `CF_IO` | 下オリーブ核（β核・背内側細胞柱） | 視覚誤差信号（網膜滑り：retinal slip） |

### 3.2 ROI内での情報処理

#### 段階1: 入力統合と拡張符号化（`GrC`）
- 5種類の苔状線維入力が`GrC`の樹状突起に収束
- `GrC`は入力の組み合わせパターンに選択的に応答
- 低次元の苔状線維入力を高次元の平行線維表現に拡張（約500億個のGrCによる拡張）
- スパース符号化により、異なる入力パターンが高次元空間で分離可能になる

#### 段階2: ゲイン調整とパターン整形（`GoC`）
- `GoC`は苔状線維と`GrC`の両方から興奮性入力を受ける
- `GrC`に対して抑制性フィードバックを提供
- 顆粒細胞層の活動をリズミカルに制御し、時空間的なパターンを整形
- 過剰活性化を防ぎ、適切なダイナミックレンジを維持

#### 段階3: 周波数フィルタリング（`BC`, `SC`）
- `GrC`の平行線維が`BC`と`SC`を興奮
- `BC`は低周波数成分に応答し、PCの細胞体・軸索起始部を抑制
- `SC`は高周波数成分に応答し、PCの樹状突起を抑制
- 両者の協調作用により、PCの応答周波数帯域が最適化される

#### 段階4: 統合と可塑性（`PC`）
- `PC`は平行線維からの多数の弱い興奮性入力を統合
- `BC`と`SC`からの抑制により、発火閾値と周波数特性が調整される
- 登上線維（`CF_IO`）からの視覚誤差信号が複雑スパイクを誘発
- 誤差信号と平行線維活動の同時発生により、平行線維-PCシナプスに長期抑圧（LTD）が誘導される
- シナプス重みの変化により、特定の感覚運動文脈でのPC応答が調整される

#### 段階5: 出力生成
- `PC`は単純スパイクとして発火し、GABA作動性の抑制性投射を前庭神経核に送る
- PC発火率の変化が、前庭神経核の二次ニューロンへの抑制量を調整
- 前庭神経核の活動が調整されることで、VORゲイン（眼球速度/頭部速度比）が変化

### 3.3 ROI_Output（小脳小節からの出力）

| 出力 | 投射先 | 内容 |
| ---- | ------ | ---- |
| `PC` → `VN_output` | 前庭神経核（内側・上前庭神経核） | VOR適応ゲイン調整信号。前庭神経核の二次ニューロンへの抑制により、VORゲインを調整 |

### 3.4 適応学習のメカニズム

1. **初期状態**: VORゲインが最適でない場合、頭部運動時に網膜滑り（retinal slip）が生じる
2. **誤差信号の伝達**: 網膜滑り→視索核/背側副視索核→下オリーブ核→登上線維→PC
3. **シナプス可塑性の誘導**: 登上線維の活性化時に活性化していた平行線維-PCシナプスにLTDが誘導される
4. **PC応答の変化**: 次回同じ感覚運動文脈では、PC応答が減少
5. **VORゲインの調整**: PC抑制の減少により、前庭神経核の活動が増加し、VORゲインが調整される
6. **誤差の最小化**: 調整後、網膜滑りが減少し、視線が安定する

## 4. 主要な発見

### 発見1: 多層的な制御機構
小脳小節は、単純な入出力変換ではなく、多層的な制御機構を持つ：
- **拡張符号化層**（`GrC`）: パターン分離
- **ゲイン調整層**（`GoC`）: ダイナミックレンジ制御
- **周波数フィルタリング層**（`BC`, `SC`）: 時間的特性の最適化
- **統合・学習層**（`PC`）: 適応学習と出力生成

これらの層が協調することで、ロバストで適応的なVORゲイン制御が実現される。

### 発見2: フィードバック回路の重要性
`GrC`と`GoC`の間のフィードバック回路が、顆粒細胞層の活動を動的に制御する。これにより：
- 過剰活性化の防止
- リズミカルな発火パターンの生成
- 中心-周辺構造によるパターン選択

このフィードバック機構が、安定した情報処理を可能にする。

### 発見3: 周波数依存的な抑制制御
`BC`と`SC`は、異なる周波数帯域でPCを抑制する：
- `BC`: 低周波数帯域の抑制（細胞体・軸索起始部）
- `SC`: 高周波数帯域の抑制（樹状突起）

この相補的なフィルタリングにより、PCは最適な周波数帯域で選択的に応答できる。これは、VORが適切な時間スケール（数十Hz程度）で動作するために重要である。

### 発見4: Marr-Albusモデルの実装
本HCDは、古典的なMarr-Albusモデルを神経科学的に詳細に実装している：
- **平行線維**（`GrC`出力）: 文脈情報を高次元に拡張して伝達
- **登上線維**（`CF_IO`）: 誤差信号（教師信号）を伝達
- **プルキンエ細胞**（`PC`）: シナプス可塑性により学習

さらに、`GoC`, `BC`, `SC`という介在ニューロンが、このモデルを補完し、より洗練された情報処理を実現している。

### 発見5: カーネルマシンとしての小脳
最近の計算論（Cerebellum as a kernel machine）との対応：
- `GrC`: カーネル基底関数として機能し、入力を高次元特徴空間に射影
- `PC`: カーネル基底関数の線形結合（シナプス重みによる重み付け和）により出力を計算
- 登上線維: 重要な入力パターンを選択的に記憶するための信号

この観点から、小脳小節は線形分類器（または回帰器）として機能し、高次元特徴空間での線形分離可能性を利用してVORゲインを調整していると解釈できる。

## 5. 制約と今後の課題

### 5.1 本HCDの制約

#### 制約1: ROIの範囲の限定
本HCDは小脳小節（Flocculus）に限定しており、VOR経路全体はカバーしていない：
- **含まれていない**: 前庭神経核、下オリーブ核、動眼神経核、前庭器官
- **理由**: TLFを「VOR適応学習」に限定したため、適応学習の中心である小脳小節にROIを絞った

今後、VOR全体をモデル化する場合は、ROIを拡張し、前庭神経核や動眼神経核もUCとして定義する必要がある。

#### 制約2: 粒度の選択
各UCは細胞種レベルで定義されており、個々の神経細胞の多様性は捨象されている：
- 例えば、`PC`は小節内のすべてのプルキンエ細胞を単一のUCとして扱っている
- 実際には、PCは空間的に異なる受容野を持ち、異なるVOR成分（水平、垂直、回旋）を制御する

より詳細なモデルでは、PCをさらに細分化し、空間的・機能的な多様性を表現する必要がある。

#### 制約3: 可塑性の部位
本HCDでは、平行線維-PCシナプスの可塑性（LTD/LTP）を主要な学習メカニズムとして記述したが、実際には複数の可塑性部位が存在する：
- 苔状線維-顆粒細胞シナプス
- 平行線維-プルキンエ細胞シナプス（本HCDで記述）
- 前庭神経核内のシナプス

小節の除去後も適応VORゲインが維持される現象は、前庭神経核内の可塑性で説明される可能性がある。今後、ROIを拡張してこれらの可塑性部位も含める必要がある。

#### 制約4: 時間動態の簡略化
本HCDの数式（B3. Implementation）では、時間動態を簡略化している：
- 膜電位の時間微分方程式ではなく、定常状態の発火率を記述
- シナプス動態、イオンチャネル動態などの詳細は省略

より詳細なシミュレーションモデルを構築する場合は、Hodgkin-Huxley型モデルやコンパートメントモデルを使用する必要がある。

#### 制約5: 個体差と種差
本HCDは、複数の種（ネコ、サル、ウサギ、ゼブラフィッシュなど）からの知見を統合している：
- 種による解剖学的・機能的差異は捨象されている
- 個体差も考慮されていない

特定の種や個体を対象とする場合は、種特異的・個体特異的なパラメータ調整が必要である。

### 5.2 今後の課題

#### 課題1: 定量的パラメータの推定
本HCDの数式には、以下のような未定義のパラメータが含まれている：
- シナプス重み（w_ij, v_ki, u_kj, W_pj）
- ゲイン係数（α_ff, α_fb, β, γ_BC, γ_SC）
- 発火閾値（θ, θ_GoC, θ_BC, θ_SC, θ_PC）
- 学習率（η_LTD, η_LTP）

これらのパラメータを、実験データ（電気生理学記録、行動データ）から推定する必要がある。

#### 課題2: シミュレーションモデルの構築
本HCDをシミュレーションモデルとして実装し、以下を検証する：
- VOR適応学習の再現
- 小節除去の効果の再現
- 異なる視覚条件下での適応の予測

シミュレーションにより、HCDの妥当性を定量的に検証できる。

#### 課題3: ROIの拡張
VOR全体をモデル化するために、以下のROI拡張が考えられる：
- 前庭神経核の詳細化（内側、上、外側、下前庭神経核の分離）
- 下オリーブ核の詳細化（β核、背内側細胞柱の分離）
- 動眼神経核の追加（CN III, IV, VI）
- 前庭器官の追加（半規管、耳石器官）

これにより、VORの末梢から中枢、出力までの全経路をカバーできる。

#### 課題4: 他の小脳機能との統合
小脳小節はVOR適応だけでなく、以下の機能にも関与している：
- 滑動性追跡眼球運動（Smooth pursuit）
- 視運動性眼振（Optokinetic response）
- 姿勢制御への寄与

これらの機能を統合的にモデル化することで、小脳小節の多機能性を理解できる。

#### 課題5: 疾患モデルの構築
本HCDを基盤として、以下の疾患モデルを構築できる：
- 小脳変性症（プルキンエ細胞の脱落）
- 前庭神経炎（前庭入力の喪失）
- 眼振症（VORゲインの異常）

疾患モデルにより、病態メカニズムの理解と治療法の開発に貢献できる。
