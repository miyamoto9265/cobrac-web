# FRG機能詳細

本ファイルでは、FRGの各ノード（TLFおよびGN）について、機能関連項目を定義する。

## 機能関連項目の定義

### 1. R.Perceptual-Speed（TLF）

#### Requirement
[R.Perceptual-Speed]は、視覚刺激間の類似性と相違点を迅速かつ正確に比較する機能を実現する。入力として、[U.Early-Visual-Features]（基本視覚特徴）、[U.High-Level-Visual-Representation]（カテゴリー特異的視覚表現）、[U.Top-Down-Attention-Control]（注意制御信号）を受け取り、出力として[U.Decision-Output]（類似/相違の判定結果）を生成する。この機能は、文字、数字、物体、パターンなど多様な視覚刺激に対応し、同時提示と順次提示の両方に対応し、迅速性と正確性のバランスを取る。

#### Requirement realization by interface
Interfaceは([U.Decision-Output]) = R.Perceptual-Speed([U.Early-Visual-Features], [U.High-Level-Visual-Representation], [U.Top-Down-Attention-Control])である。入力として基本視覚特徴とカテゴリー表現を受け取り、注意制御によって処理を調整し、最終的な決定出力を生成する。Requirementで記述された入出力関係とInterfaceは整合している。

#### Capability
多様な視覚刺激を統一的な表現空間に変換し、表現間の類似性を計算し、決定基準と比較して二値判断を下す一般的な比較判断機能。この機能は、視覚カテゴリー（文字、数字、物体など）に依存せず、関係性符号化とドリフト拡散モデルという汎用的な計算原理に基づく。類似性メトリックと決定基準を動的に調整することで、多様なタスク要求に適応する。

**神経科学的根拠**: Perceptual Speedは頭頂間溝を中心とする分散ネットワークによって実現される（Liu et al., 2025）。階層的視覚処理、関係性符号化、証拠蓄積という複数の計算原理が統合されている。

#### Mechanism
階層的処理: 視覚入力は、低次特徴抽出（V1/V2） → 高次カテゴリー認識（Fusiform Gyrus） → 統合表現構築（後部IPS） → 類似性計算（LIP） → 決定形成（前部IPS）という階層を経て処理される。各段階で情報が抽象化され、最終的に二値決定に変換される。並列処理: 現在刺激の比較経路と、記憶刺激との比較経路が並列に存在し、LIPで統合される。フィードバック制御: トップダウン注意制御により、処理効率と決定基準が動的に調整される。

---

### 2. R.Stimulus-Processing

#### Requirement
[R.Stimulus-Processing]は、視覚刺激の処理（統合と記憶）を実現する。入力として、[U.Early-Visual-Features]、[U.High-Level-Visual-Representation]、[U.Thalamic-Attention-Hub]（注意調整信号）、[U.Top-Down-Attention-Control]、[U.Oculomotor-Control]（眼球運動フィードバック）を受け取り、出力として[U.Pattern-Comparison]（比較処理のための統合表現）を生成する。この機能は、視覚特徴の統合と短期記憶への保存を含む。

#### Requirement realization by interface
Interfaceは([U.Pattern-Comparison]) = R.Stimulus-Processing([U.Early-Visual-Features], [U.High-Level-Visual-Representation], [U.Thalamic-Attention-Hub], [U.Top-Down-Attention-Control], [U.Oculomotor-Control])である。複数の視覚情報源からの入力を統合し、記憶として保持し、比較処理に必要な表現を出力する。Requirementと整合している。

#### Capability
多層的視覚特徴を統合し、タスク関連情報を選択的に強化し、短期記憶として維持する機能。階層的フィードフォワード統合、注意による動的重み付け、リカレント神経回路による記憶維持という複数のメカニズムを組み合わせる。眼球運動中も記憶を安定に保つための座標変換も含む。

**神経科学的根拠**: 後頭頂皮質は視覚情報統合のハブとして機能し（Gamberini et al., 2024）、視覚ワーキングメモリにおいて変換された表現を維持する（eNeuro, 2025）。

#### Mechanism
視覚統合: 後部IPS（U.Visual-Input-Integration）は、V1/V2からの低次特徴とFusiform Gyrusからの高次カテゴリー表現を受け取り、注意信号（Pulvinar, dlPFC）による重み付けを適用して統合表現を構築する。記憶維持: 背側LIP（U.Working-Memory-Maintenance）は、統合表現をリカレント神経回路によって数秒間維持する。タスク目標に応じて表現が変換され、タスク関連情報が優先的に保持される。眼球運動フィードバック（FEF）により、網膜座標から頭部中心座標への変換が行われ、眼球運動中も記憶が安定する。

---

### 3. R.Comparison-And-Decision

#### Requirement
[R.Comparison-And-Decision]は、類似性評価と決定形成を実現する。入力として、[U.Visual-Input-Integration]（統合視覚表現）、[U.Working-Memory-Maintenance]（記憶表現）、[U.Motion-Processing]（動き情報）、[U.Thalamic-Attention-Hub]、[U.Top-Down-Attention-Control]を受け取り、出力として[U.Decision-Output]（決定信号）、[U.Oculomotor-Control]（眼球運動指令）、[U.High-Level-Visual-Representation]（トップダウン視覚調整）を生成する。この機能は、視覚表現間の類似性を計算し、証拠を蓄積して二値決定を下す。

#### Requirement realization by interface
Interfaceは([U.Decision-Output], [U.Oculomotor-Control], [U.High-Level-Visual-Representation]) = R.Comparison-And-Decision([U.Visual-Input-Integration], [U.Working-Memory-Maintenance], [U.Motion-Processing], [U.Thalamic-Attention-Hub], [U.Top-Down-Attention-Control])である。統合表現と記憶表現を比較し、決定を形成し、複数の出力（決定、眼球運動、視覚調整）を生成する。Requirementと整合している。

#### Capability
高次元視覚表現間の類似性距離を計算し、時間的に証拠を蓄積し、閾値判定によって二値決定を下す機能。関係性符号化、ドリフト拡散モデル、トップダウンフィードバックという計算原理を統合する。決定境界を動的に調整することで、速度-正確性トレードオフを制御する。

**神経科学的根拠**: LIPは関係性符号化により類似性を計算し（Nature Communications, 2025）、前部IPSは証拠蓄積により決定を形成する（Greenberg et al., 2012; Basti et al., 2022）。

#### Mechanism
類似性計算: LIP（U.Pattern-Comparison）は、統合表現（U.Visual-Input-Integration）と記憶表現（U.Working-Memory-Maintenance）を高次元空間内の点として扱い、重み付き距離を計算する。注意信号（Thalamic-Attention-Hub）は特徴次元への重みを調整する。決定形成: 前部IPS（U.Comparison-Decision）は、類似性距離情報を時間的に蓄積する（ドリフト拡散プロセス）。蓄積された証拠が決定境界に達すると、二値決定が下される。決定境界は、トップダウン制御（Top-Down-Attention-Control）によって調整される。出力: 決定信号はdlPFC（Decision-Output）へ、眼球運動指令はFEF（Oculomotor-Control）へ、視覚調整信号はFusiform Gyrus（High-Level-Visual-Representation）へ送られる。

---

### 4. R.Visual-Integration-And-Memory

#### Requirement
[R.Visual-Integration-And-Memory]は、視覚特徴統合とワーキングメモリを実現する。入力として、[U.Early-Visual-Features]、[U.High-Level-Visual-Representation]、[U.Thalamic-Attention-Hub]、[U.Top-Down-Attention-Control]、[U.Oculomotor-Control]を受け取り、出力として[U.Pattern-Comparison]（比較のための表現）を生成する。この機能は、[U.Visual-Input-Integration]による統合と[U.Working-Memory-Maintenance]による記憶維持を含む。

#### Requirement realization by interface
Interfaceは([U.Pattern-Comparison]) = R.Visual-Integration-And-Memory([U.Early-Visual-Features], [U.High-Level-Visual-Representation], [U.Thalamic-Attention-Hub], [U.Top-Down-Attention-Control], [U.Oculomotor-Control])である。このGNは2つのUC（U.Visual-Input-Integration, U.Working-Memory-Maintenance）によって実現される。U.Visual-Input-Integrationは視覚入力を統合し、U.Working-Memory-Maintenanceは記憶を維持する。両者の出力はU.Pattern-Comparisonへ送られる。Requirementと整合している。

#### Capability
多層的視覚特徴を統合し、短期記憶として維持し、比較処理に適した形式で出力する機能。階層的統合、注意による重み付け、リカレント維持、座標変換という複数のメカニズムを組み合わせる。

**神経科学的根拠**: 後部IPSは視覚統合のハブ（Gamberini et al., 2024）、LIPdはワーキングメモリ維持（eNeuro, 2025）。

#### Mechanism
U.Visual-Input-Integrationは、低次視覚特徴と高次カテゴリー表現を注意信号で重み付けして統合する。U.Working-Memory-Maintenanceは、統合表現をリカレント回路で維持し、眼球運動フィードバックで座標変換する。両者の出力がU.Pattern-Comparisonへ送られ、現在刺激と記憶刺激の比較が可能になる。

---

### 5. R.Similarity-And-Judgment

#### Requirement
[R.Similarity-And-Judgment]は、パターン比較と比較決定を実現する。入力として、[U.Visual-Input-Integration]、[U.Working-Memory-Maintenance]、[U.Motion-Processing]、[U.Thalamic-Attention-Hub]、[U.Top-Down-Attention-Control]を受け取り、出力として[U.Decision-Output]、[U.Oculomotor-Control]、[U.High-Level-Visual-Representation]を生成する。この機能は、[U.Pattern-Comparison]による類似性計算と[U.Comparison-Decision]による決定形成を含む。

#### Requirement realization by interface
Interfaceは([U.Decision-Output], [U.Oculomotor-Control], [U.High-Level-Visual-Representation]) = R.Similarity-And-Judgment([U.Visual-Input-Integration], [U.Working-Memory-Maintenance], [U.Motion-Processing], [U.Thalamic-Attention-Hub], [U.Top-Down-Attention-Control])である。このGNは2つのUC（U.Pattern-Comparison, U.Comparison-Decision）によって実現される。U.Pattern-Comparisonは類似性を計算し、U.Comparison-Decisionは決定を形成する。Requirementと整合している。

#### Capability
視覚表現間の類似性距離を計算し、証拠蓄積により二値決定を下す機能。関係性符号化とドリフト拡散モデルを統合し、決定境界を動的に調整する。

**神経科学的根拠**: LIPは関係性符号化（Nature Communications, 2025）、前部IPSは証拠蓄積（Greenberg et al., 2012）。

#### Mechanism
U.Pattern-Comparisonは、統合表現と記憶表現の距離を計算し、注意による重み付けを適用する。U.Comparison-Decisionは、距離情報を時間的に蓄積し、閾値に達したら決定を下す。決定信号はdlPFCへ、眼球運動指令はFEFへ、視覚調整信号はFusiform Gyrusへ送られる。
