## 1. TLFとROIの概要

### 1.1 Top Level Function: 自己位置推定

**定義**: 自己位置推定とは、生物が環境内における自身の現在位置を、外部感覚入力と内部状態の統合により確率的に推定する認知機能である。

**機能要件**:
- 空間座標情報（格子信号、境界信号）の入力処理
- 自己運動情報（速度、方向）の統合
- 過去の空間経験との照合
- 曖昧な入力からの位置推定
- 行動制御システムへの位置情報の出力

### 1.2 Region of Interest: 海馬

**解剖学的定義**: 側頭葉内側部に位置する脳構造。歯状回（DG）、CA3領域、CA1領域、海馬台（Subiculum）から構成される。

**機能的重要性**: 
- 1971年のO'Keefeによる場所細胞の発見以来、空間認知の中枢として確立
- 2014年ノーベル生理学・医学賞（O'Keefe, Moser夫妻）の受賞対象
- 臨床的に海馬損傷が空間ナビゲーション障害を引き起こすことが確認

## 2. 定義されたUCの一覧

| UC | 神経組織 | 主要機能 | 根拠 |
| -- | -------- | -------- | ---- |
| `DG` | 歯状回 | パターン分離 | 顆粒細胞の疎な発火パターン、類似入力の直交化 |
| `CA3` | 海馬CA3領域 | パターン補完 | 再帰的側枝による自己連想記憶、Hopfield型ネットワーク |
| `CA1` | 海馬CA1領域 | 場所表現の統合 | 場所細胞の存在、感覚と記憶の統合 |
| `SUB` | 海馬台 | 情報分配 | 下流領域への選択的投射、多様な空間表現の並列出力 |

### 各UCの機能サマリー

#### `DG`（歯状回）
嗅内皮質からの連続的な空間座標入力を、疎な離散的パターンに変換する。約2%の顆粒細胞のみがアクティブとなる競合的抑制により、類似した位置や環境を区別可能な直交化表現を生成。

#### `CA3`（海馬CA3領域）
歯状回からの疎なパターンと嗅内皮質からの直接入力を受け、再帰的側枝（recurrent collaterals）による自己連想記憶として機能。部分的な位置手がかりから、過去に学習した完全な空間パターンを復元。

#### `CA1`（海馬CA1領域）
CA3からの記憶ベースの空間情報と、嗅内皮質からの感覚ベースの空間情報をベイズ的に統合。場所細胞の集団活動として、環境内の現在位置の確率分布を表現。自己位置推定の最終出力段階。

#### `SUB`（海馬台）
CA1からの場所表現を受け取り、下流の各脳領域（乳頭体、視床、帯状皮質、側坐核）が必要とする形式に変換・分配。空間ナビゲーション行動や意思決定への入力インターフェース。

## 3. 情報処理フロー

### 3.1 ROI_InputからROI_Outputへの処理経路

```
[ROI外入力]
┌─────────────────────────────────────────────────────────────┐
│ MEC: 格子座標、頭方向、境界、速度                           │
│ LEC: 文脈、物体情報                                        │
│ ATN: 頭方向フィードバック                                  │
│ MS: シータリズム調節                                        │
└─────────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────┐
│                    [ROI内処理]                              │
│                                                             │
│  MEC/LEC ──→ DG ──────→ CA3 ──────→ CA1 ──────→ SUB       │
│    │         (分離)     (補完)     (統合)     (分配)       │
│    │           │          │          │                     │
│    └───────────┴──────────┴──────────┘                     │
│              直接経路（バイパス）                           │
│                                                             │
│  ATN ─────────────────────────→ CA1                        │
│  MS ──────────────────────────→ DG/CA3/CA1                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────┐
│ [ROI外出力]                                                 │
│ MB: 場所・方向情報（Papez回路）                            │
│ ATN: 頭方向更新                                            │
│ ACC: 経路・道順情報                                        │
│ NAc: 報酬位置情報                                          │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 計算論的解釈

本HCDは、自己位置推定をベイズ推定の枠組みで解釈可能である：

1. **事前分布（Prior）**: CA3からのパターン補完された空間表現
2. **尤度（Likelihood）**: MEC/LECからの現在の感覚入力
3. **事後分布（Posterior）**: CA1の場所細胞活動として表現される位置推定

シータ振動の異なる位相でこれらの入力が分離処理され、適応的な重み付け統合が実現される。

## 4. 主要な発見

### 4.1 三シナプス回路と直接経路の並列処理

海馬には、嗅内皮質からCA1への2つの主要経路が存在する：
- **三シナプス回路**: EC → DG → CA3 → CA1（記憶処理経路）
- **直接経路**: EC → CA1（感覚処理経路）

これらの並列処理により、過去の経験と現在の感覚を独立に処理し、最終的にCA1で統合することが可能となる。

### 4.2 シータリズムによる時間的組織化

内側中隔からのシータリズム（6-10Hz）が、海馬内の情報処理を時間的に組織化する。シータの異なる位相で符号化と想起が分離され、これにより過去と現在の情報の混同が防止される。

### 4.3 場所細胞の確率的位置表現

CA1の場所細胞の集団活動は、環境内の位置の確率分布として解釈可能である。不確実性が高い状況では複数の場所細胞が同時に活性化し、確実性が高まると活動が単一の位置に収束する。

### 4.4 海馬台の選択的情報分配

海馬台は単なる中継構造ではなく、下流ターゲットに応じて異なる空間表現を選択的に生成・分配する。これにより、ナビゲーション、記憶、報酬学習など多様な認知機能が同一の位置情報を共有しつつ、それぞれに最適な形式で利用可能となる。

## 5. 制約と今後の課題

### 5.1 本HCDの制約

1. **CA2領域の省略**: CA2は社会的記憶に関与するが、自己位置推定への直接的寄与は限定的であるため本HCDでは省略した。

2. **学習過程の非記述**: 場所細胞の形成やパターン補完の学習過程は、本HCDの静的な記述では捉えられていない。

3. **局所抑制回路の抽象化**: 介在ニューロンによる局所抑制は各UCの内部処理として抽象化されており、詳細なダイナミクスは記述されていない。

4. **海馬傍回構造の簡略化**: 嗅周皮質、海馬傍皮質などの海馬傍回構造は、入力源として抽象化されている。

### 5.2 今後の拡張可能性

1. **時間細胞の統合**: 海馬の時間細胞を含め、時空間統合の自己位置推定への拡張

2. **リプレイ現象のモデル化**: 睡眠時や休息時の場所細胞のシーケンス再生

3. **報酬との統合**: 報酬予測誤差信号との統合による目標指向ナビゲーション

4. **病態モデル**: アルツハイマー病などにおける海馬機能障害のモデル化
