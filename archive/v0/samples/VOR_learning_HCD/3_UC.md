# ステップ3-6: Uniform Circuit（UC）の定義と機能関連項目

VOR学習における小脳の情報処理単位と各UCの計算機能

## 完全なUniform Circuit表

| Circuit ID | Names | Comment | Interface | Output Semantics | Requirement | Requirement realization by interface | Capability | Mechanism | Implementation |

| `PN` | Pontine nuclei | **ROI外: noROI(input)** | | [`PN`]視覚運動情報（optic flow）、視覚野および前頭眼野からの情報; | | | | | |
| `NOT-AOS` | Nucleus of the optic tract / Accessory optic system | **ROI外: noROI(input)** | | [`NOT-AOS`]網膜像のずれ（retinal slip）を方向選択的に符号化した視覚誤差情報; | | | | | |
| `IO` | Inferior olivary nucleus | **ROI外: noROI(input)** | | [`IO`]VOR誤差信号（retinal slip errorに基づく教師信号）、シナプス可塑性を誘導する指示信号; | | | | | |
| `GrC` | Granule cells | **ROI内** | [`PF`] = `GrC`(`VN-input`, `PN`, `GoC`) | [`GrC`]時空間的にフィルタリングされた多感覚統合情報（前庭感覚および視覚運動情報の結合表現）; | VOR学習を実現するために、入力:[U.VN-input]の頭部運動情報と入力:[U.PN]の視覚運動情報を統合し、抑制性調整:[U.GoC]によって時空間的にフィルタリングされた多感覚統合表現を出力:[U.PF]として生成する必要がある。この変換により、下流の[U.PC]が適切な感覚文脈でシナプス可塑性を実行できる。 | Interfaceは、[U.VN-input]と[U.PN]からの異なる感覚モダリティ入力と、[U.GoC]からの抑制性フィードバックを受け取り、[U.PF]へ出力することを示している。これにより、Requirementで要求される多感覚統合と時空間フィルタリングが実現可能である。入力の組み合わせが、VOR学習に必要な感覚文脈を提供する。 | 異なる感覚モダリティ（前庭感覚、視覚）を統合し、抑制性ゲイン制御下で高次元表現空間へ拡張符号化（expansion recoding）を行う能力。各顆粒細胞は約4つの異なる感覚入力をランダムに統合し、疎な活動パターン（sparse coding）を生成することで、パターン分離（pattern separation）を実現する（Cayco-Gajic et al., 2023; Nature Comm. Biol. 2023）。この能力は、下流での連想学習を可能にする。 | 顆粒細胞は、複数の苔状線維入力を樹状突起の爪（dendritic claws）で受け取り、閾値以上の同時入力があった場合に発火する。ゴルジ細胞からのGABA作動性抑制により、顆粒細胞集団の活動が疎化され、感覚アンサンブル間の重複が制限される。この抑制は刺激特異的に動員され、多感覚アンサンブルを非相関化する。約100倍の拡張（苔状線維数に対する顆粒細胞数）により、入力パターンが高次元空間に埋め込まれ、線形分離可能性が向上する（kernel機械的視点、Frontiers Comp. Neurosci. 2022）。 | [U.GrC] = Θ(Σ w_mf * [U.VN-input] + Σ w_pn * [U.PN] - [U.GoC])、ここでΘは閾値関数、w_mfとw_pnは各入力の重み |
| `GoC` | Golgi cells | **ROI内** | [`GrC`] = `GoC`(`VN-input`, `PN`, `PF`) | [`GoC`]顆粒細胞層の活動を時空間的に調整する抑制性ゲイン制御信号; | VOR学習において、入力:[U.VN-input]、[U.PN]および[U.PF]からの興奮性入力を統合し、出力:[U.GrC]への抑制性ゲイン制御信号を生成して、顆粒細胞集団の活動を時空間的に調整する必要がある。これにより、顆粒細胞の疎な符号化と、情報伝達のタイミング・可変性の制御を実現する。出力:[U.GrC]の活動スパース性を最適化することで、[U.PC]での効率的な学習を支援する。 | Interfaceは、[U.VN-input]と[U.PN]からのフィードフォワード入力、および[U.PF]からのフィードバック入力を受け取り、[U.GrC]へ抑制出力することを示している。この構造により、Requirementで要求されるフィードフォワード・フィードバック抑制の両方が実現され、顆粒細胞活動の時空間的調整が可能となる。 | 異なる経路からの興奮性入力を統合し、標的神経集団への抑制性ゲイン制御とタイミング調整を行う能力。ゴルジ細胞は、顆粒細胞とは機能的に異なる苔状線維入力を受け取り、経路特異的な制御を実現する（bioRxiv 2024）。中程度の抑制レベルがパターン分離性能を最適化し、フィードフォワードとフィードバック抑制回路が符号化拡張と非相関化に異なる効果を及ぼす（Nature Sci. Rep. 2025）。 | ゴルジ細胞は、苔状線維および平行線維からの興奮性入力を統合し、GABA作動性抑制を顆粒細胞の樹状突起に対して小脳糸球体（glomerulus）内で実行する。この抑制は、シナプス小胞性GABAリリースによるphasic inhibition（α1-GABA-A受容体媒介）と、アンビエントGABAによるtonic inhibition（α6-GABA-A受容体媒介）の二つのメカニズムで作用する（Frontiers Cell. Neurosci. 2014）。抑制のタイミングにより、顆粒細胞集団全体の再現性が向上し、個々のスパイク精度は低下するが、情報伝達の時間的忠実性が制御される（J. Neurosci. 2024）。 | [U.GoC] = f(Σ w_mf * ([U.VN-input] + [U.PN]) + Σ w_pf * [U.PF])、ここでfは活性化関数 |
| `PF` | Parallel fibers | **ROI内** | [`PC`, `BC`, `SC`, `GoC`] = `PF`(`GrC`) | [`PF`]空間的に拡散された多感覚統合情報（前庭感覚・視覚運動情報の広範な結合パターン）; | VOR学習において、入力:[U.GrC]の疎な多感覚統合情報を、出力:[U.PC]、[U.BC]、[U.SC]、[U.GoC]へ空間的に拡散して伝達する必要がある。この拡散により、各[U.PC]は約10万の平行線維シナプスを介して多様な感覚文脈情報を受け取り、VOR適応に必要な条件付き学習（conjunctive learning）が可能になる。また、[U.BC]と[U.SC]への投射により側方抑制回路を駆動し、[U.GoC]へのフィードバックにより抑制調整を実現する。 | Interfaceは、[U.GrC]からの単一入力を、複数の下流ターゲット（[U.PC]、[U.BC]、[U.SC]、[U.GoC]）へ分岐出力することを示している。この1対多の構造により、Requirementで要求される空間的拡散と、多様な下流回路の同時駆動が実現される。平行線維の物理的な空間的広がりが、この機能的拡散を支える。 | 単一顆粒細胞からの情報を、数百から数千の下流ニューロンへ空間的に拡散し、高次元情報パターンを伝達する能力。各平行線維は分子層で数ミリメートルにわたって伸び、その経路上の多数のプルキンエ細胞樹状突起と交差する。この構造により、各プルキンエ細胞は10万以上の異なる平行線維からシナプス入力を受け取り、膨大な数の感覚結合パターン（sensory conjunction）を表現できる。この幾何学的配置は、小脳がカーネルマシンとして機能するための基盤を提供する。 | 平行線維は、顆粒細胞の軸索がT字型に分岐して生成される。各平行線維は、その軌道に沿って遭遇するプルキンエ細胞の樹状突起に対して興奮性グルタミン酸作動性シナプスを形成する。シナプス伝達は、AMPA受容体およびmGlu1受容体によって媒介され、それぞれ速い電流と遅い信号を生成する（Frontiers Synaptic Neurosci. 2016）。平行線維の幾何学的配置により、同一の顆粒細胞からの情報が、空間的に離れた複数のプルキンエ細胞に同時に到達し、情報の並列処理を可能にする。 | [U.PC] = Σ_i [U.PF]_i, [U.BC] = Σ_j [U.PF]_j, [U.SC] = Σ_k [U.PF]_k, [U.GoC] = Σ_l [U.PF]_l （各下流ターゲットは平行線維の異なるサブセットから入力を受ける） |
| `BC` | Basket cells | **ROI内** | [`PC`] = `BC`(`PF`) | [`BC`]プルキンエ細胞の出力パターンを鋭敏化する側方抑制信号; | VOR学習において、入力:[U.PF]の空間的活動パターンを検出し、出力:[U.PC]の軸索初節周囲へ抑制を行うことで、プルキンエ細胞の出力パターンを鋭敏化（sharpening）する必要がある。この側方抑制により、活動的なプルキンエ細胞の周辺の非活動的なプルキンエ細胞が抑制され、出力信号の空間的コントラストが向上し、VOR調整信号の精度が高まる。[U.PF]の活動パターンと[U.PC]の出力パターンの対応関係を最適化する。 | Interfaceは、[U.PF]からの興奮性入力を受け、[U.PC]へ抑制性出力を行うことを示している。この構造により、Requirementで要求される平行線維活動パターンの検出とプルキンエ細胞への側方抑制が実現される。フィードフォワード抑制回路の構造が、出力パターンの鋭敏化を支える。 | 平行線維からの興奮性入力パターンを検出し、標的ニューロン集団に対してフィードフォワード側方抑制を実行する能力。バスケット細胞は、活性化された平行線維の軌道に沿って興奮し、その近傍のプルキンエ細胞の軸索初節に強力なGABA作動性抑制を行う。この抑制は、単なるブロッキングではなく、プルキンエ細胞集団の応答ダイナミクスを整形し、winner-take-all的な計算を実現する（Frontiers Mol. Neurosci. 2019）。 | バスケット細胞は、分子層深部に細胞体を持ち、平行線維から興奮性グルタミン酸作動性入力を受ける。バスケット細胞の軸索は、小脳回（folium）を横断する方向に伸び、複数のプルキンエ細胞の軸索初節周囲に"バスケット"状のシナプス接触を形成する。ここでGABAを放出し、プルキンエ細胞の活動電位発生を強力に抑制する。この抑制は、活動的な平行線維ビームの両側に位置するプルキンエ細胞を選択的に抑制し、中央の活性化されたプルキンエ細胞の出力を相対的に増強する。 | [U.BC] = f([U.PF]), [U.PC]_inhibited = [U.PC]_original - w_bc * [U.BC]、ここでw_bcは抑制重み、側方位置に依存 |
| `SC` | Stellate cells | **ROI内** | [`PC`] = `SC`(`PF`) | [`SC`]プルキンエ細胞の樹状突起における情報統合を調整する側方抑制信号; | VOR学習において、入力:[U.PF]の活動パターンを検出し、出力:[U.PC]の樹状突起へ抑制を行うことで、プルキンエ細胞樹状突起における情報統合を調整する必要がある。この抑制により、プルキンエ細胞が統合する平行線維入力の時空間的パターンが選択的に調整され、[U.PC]での[U.PF]入力の統合効率が最適化される。[U.BC]と協調して、プルキンエ細胞の入出力関係を整形する。 | Interfaceは、[U.PF]からの興奮性入力を受け、[U.PC]へ抑制性出力を行うことを示している。この構造により、Requirementで要求される平行線維活動の検出と樹状突起レベルでの抑制が実現される。樹状突起への抑制位置が、入力統合の調整機能を可能にする。 | 平行線維活動を検出し、プルキンエ細胞樹状突起に対してフィードフォワード抑制を実行することで、樹状突起の情報統合を局所的に調整する能力。ステラート細胞は、バスケット細胞よりも分子層の浅部に位置し、プルキンエ細胞の樹状突起に対してGABA作動性抑制を行う。この抑制は、樹状突起における興奮性入力の統合を調整し、樹状突起コンパートメントの計算を制御する。小脳皮質の抑制性介在ニューロンは、単に興奮をブロックするのではなく、ニューロン応答ダイナミクスを複雑に整形する（Frontiers Mol. Neurosci. 2019）。 | ステラート細胞は分子層に位置し、平行線維から興奮性入力を受ける。その軸索はプルキンエ細胞の樹状突起に対してGABA作動性シナプスを形成し、局所的な抑制を提供する。この抑制は、プルキンエ細胞が受け取る平行線維入力の空間的・時間的パターンを整形し、樹状突起における非線形計算を調整する。バスケット細胞が軸索初節での出力を制御するのに対し、ステラート細胞は樹状突起での入力統合を制御することで、プルキンエ細胞の入出力関係を多層的に調整する。 | [U.SC] = f([U.PF]), [U.PC]_dendrite = ([U.PF]_input - w_sc * [U.SC]) * g_dendrite、ここでw_scは抑制重み、g_dendriteは樹状突起の統合関数 |
| `PC` | Purkinje cells | **ROI内** | [`VN-output`] = `PC`(`PF`, `IO`, `BC`, `SC`) | [`PC`]学習により適応的に調整されたVOR抑制信号、前庭-眼球運動変換のゲイン調整信号; | VOR学習において、入力:[U.PF]の多感覚統合情報、入力:[U.IO]の誤差信号、入力:[U.BC]と[U.SC]の側方抑制信号を統合し、出力:[U.VN-output]への抑制信号を生成する必要がある。[U.IO]からの誤差信号（retinal slip error）が登上線維経由で到達した時、[U.PF]との同時活性化により平行線維-プルキンエ細胞シナプスで可塑性（LTDまたはLTP）が誘導され、VORゲインが適応的に調整される。この学習により、[U.VN-output]への抑制が最適化され、頭部運動に対する眼球運動の補償精度が向上する。 | Interfaceは、[U.PF]から膨大な数の興奮性入力、[U.IO]から単一の強力な教師信号、[U.BC]と[U.SC]から抑制性調整信号を受け、[U.VN-output]へ出力することを示している。この構造により、Requirementで要求される多入力統合と学習依存的な出力調整が実現される。特に[U.PF]と[U.IO]の同時活性化がシナプス可塑性を誘導する構造が、VOR学習の神経基盤を提供する。 | 大規模な興奮性入力を統合し、誤差信号に基づいてシナプス重みを適応的に調整することで、入出力変換を学習する能力。プルキンエ細胞は、平行線維-プルキンエ細胞シナプスで長期抑圧（LTD）と長期増強（LTP）を実行し、運動学習を実現する。LTDはゲイン減少、LTPはゲイン増加を媒介する（Broussard & Titley, 2013）。登上線維による複雑スパイクが教師信号として機能し、平行線維の同時活性パターンに対してヘッブ的またはanti-ヘッブ的な可塑性を誘導する（Najafi et al., 2024）。この教師あり学習メカニズムは、Marr-Albus-Ito理論の核心である。 | 平行線維とプルキンエ細胞樹状突起のシナプスにおいて、平行線維刺激によるmGluR1活性化とIP3生成、登上線維刺激による電位依存性カルシウムチャネル（VGCC）開口とカルシウム流入が、IP3受容体で統合される。この同時検出により、プロテインキナーゼC（PKC）が活性化され、AMPA受容体がリン酸化されてエンドサイトーシスにより除去され、LTDが生じる（Nature Rev. Neurosci. 2002）。一方、高頻度平行線維刺激はLTPを誘導し、AMPA受容体が増加する。この双方向可塑性により、VORゲインは増減両方向に調整可能となる。プルキンエ細胞は前庭神経核へGABA作動性抑制投射を行い、この抑制の強度変化がVORゲインを調整する。 | [U.PC] = Σ_i w_i(t) * [U.PF]_i - w_bc * [U.BC] - w_sc * [U.SC]、可塑性則: dw_i/dt = η * [U.IO] * ([U.PF]_i - θ)、ここでw_i(t)は時間依存的なシナプス重み、ηは学習率、θは閾値 |
