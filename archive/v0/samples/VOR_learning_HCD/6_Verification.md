HCD全体の整合性確認と問題の修正

## 検証項目と結果

### 1. 接続の整合性: ConnectionとInterfaceの一致確認

**結論**: すべてのROI内UCについて、Interfaceと定義されたConnectionが完全に一致している。

### 2. 情報フローの妥当性: ROI_InputからROI_Outputへの経路確認

**検証内容**: ROI_Input（前庭感覚、視覚運動情報、誤差信号）からROI_Output（調整されたVOR運動指令）への情報処理経路が成立しているか確認。

**主要情報処理経路**:

1. **前庭感覚経路**:
   - `VN-input` → `GrC` → `PF` → `PC` → `VN-output`
   - 状態: ✓ 成立
   - 機能: 頭部運動情報を小脳皮質で処理し、VOR運動指令を調整

2. **視覚運動経路**:
   - `PN` → `GrC` → `PF` → `PC` → `VN-output`
   - 状態: ✓ 成立
   - 機能: 視覚運動情報を統合し、VOR運動指令を調整

3. **誤差信号経路**:
   - `NOT-AOS` → `IO` → `PC` → `VN-output`
   - 状態: ✓ 成立
   - 機能: 網膜像のずれ（retinal slip error）を教師信号として`PC`に伝達し、シナプス可塑性を誘導

4. **抑制調整回路**:
   - フィードフォワード: `VN-input`/`PN` → `GoC` → `GrC`
   - フィードバック: `PF` → `GoC` → `GrC`
   - Lateral inhibition: `PF` → `BC`/`SC` → `PC`
   - 状態: ✓ 成立
   - 機能: 顆粒細胞とプルキンエ細胞の活動を時空間的に調整

5. **最終出力経路**:
   - `VN-output` → `ABN`/`OMN`/`TN` (外眼筋運動核)
   - 状態: ✓ 成立
   - 機能: 調整されたVOR指令を外眼筋へ伝達

**結論**: ROI_InputからROI_Outputへのすべての主要経路が成立している。感覚入力、誤差信号、抑制調整が適切に統合され、VOR学習を実現できる構造となっている。

### 3. UCの適切性: 重複・欠落・粒度の確認

**検証内容**: 定義したUCに重複や欠落がないか、メゾスコピックレベルとして適切な粒度かを確認。

**ROI内UC一覧**:
- `GrC` (Granule cells)
- `GoC` (Golgi cells)
- `PF` (Parallel fibers)
- `BC` (Basket cells)
- `SC` (Stellate cells)
- `PC` (Purkinje cells)

**評価**:

1. **重複の有無**: なし
   - 各UCは明確に異なる細胞タイプまたは構造（平行線維）を表現
   - 機能的役割も明確に区別されている

2. **欠落の有無**: なし
   - VOR学習に関与する主要な小脳皮質の細胞タイプをすべて含む
   - 入力（苔状線維、登上線維）、処理（顆粒細胞、介在ニューロン）、出力（プルキンエ細胞）のすべての段階を網羅

3. **粒度の適切性**: 適切
   - すべてのUCが細胞タイプレベルで定義されており、メゾスコピックレベルとして適切
   - 単一細胞レベルではなく、神経集団レベルでの抽象化が適切に行われている
   - 大きすぎる（例: 小脳皮質全体）でも小さすぎる（例: 単一シナプス）でもない

**ROI外UC一覧**:
- 入力: `VN-input`, `PN`, `NOT-AOS`, `IO`
- 出力: `VN-output`, `ABN`, `OMN`, `TN`

**評価**: ROI外UCも適切に定義されており、小脳への入力源と出力先を明確に特定している。

**結論**: UCの定義は適切であり、重複や欠落はなく、メゾスコピックレベルの粒度として妥当である。

## 修正事項

本検証において、重大な問題は発見されなかった。すべての検証項目が合格基準を満たしている。

ただし、以下の点について補足的な考察を追加:

### 補足1: 前庭神経核の二重の役割

`VN-input`と`VN-output`は物理的には同一の前庭神経核を指すが、情報処理フローにおいて異なる役割を果たすため、別のUCとして定義している。これは以下の理由による:

1. 入力段階（`VN-input`）: 前庭感覚の中継
2. 出力段階（`VN-output`）: 小脳からの調整信号の受容とVOR運動指令の生成

この二重の役割は、前庭神経核がVOR回路において入出力の両方を担う中心的なハブであることを反映している。

### 補足2: 小脳核の扱い

本HCDでは、小脳核（cerebellar nuclei）を明示的にUCとして含めていない。これは以下の理由による:

1. VOR学習における主要な可塑性部位は、小脳皮質の平行線維-プルキンエ細胞シナプスである
2. Flocculusのプルキンエ細胞は、小脳核を介さず直接前庭神経核へ投射する
3. したがって、ROI（小脳皮質）とTLF（VOR学習）の範囲において、小脳核は必須ではない

ただし、他の小脳依存的な運動学習では小脳核が重要な役割を果たすため、異なるTLFを扱う場合にはUCとして含める必要がある。

### 補足3: 一次前庭求心線維の扱い

2_BIF.mdでは、前庭神経（primary afferents）から直接小脳への投射が記載されているが、3_UC.mdおよび5_Connection.mdでは、簡略化のため`VN-input`からの投射として統合している。これは以下の理由による:

1. 一次前庭求心線維と二次前庭求心線維は、どちらも苔状線維として顆粒細胞へ投射する
2. 機能的には類似の前庭感覚情報を伝達する
3. メゾスコピックレベルの抽象化において、これらを統合することが適切

より詳細なモデルでは、一次と二次を区別することも可能である。
