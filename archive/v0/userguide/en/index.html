1. Introduction

Related files CoBRAC files (instruction documents, conversion scripts, etc.) are available on GitHub: https://github.com/miyamoto9265/CoBRAC.

What is CoBRAC?

CoBRAC (Collaborative Brain Reference Architecture Compiler) is a workflow for structurally describing information processing in a brain region (ROI) that implements a computational function (TLF), based on neuroscientific evidence. The final deliverable is BRA (Brain Reference Architecture) data, exported as an Excel file with the extension .bra.xlsx.

→

→

The Excel file contains five sheets:

SheetContent
ProjectProject metadata (Contributor, Project ID, etc.)
ReferencesReference list
CircuitsUniform Circuit (UC) definitions
ConnectionsConnections between UCs
FRGFunction Realization Graph integrated with UC data

How to use this guide

  1. First-time users: read Chapters 2–4 for concepts and workflow
  2. Start work: follow Chapters 5 onward in Phase order
  3. Detailed writing rules: have your AI agent read the relevant instruction_*.md files
  4. Before submission: use the checklist in Chapter 11

2. Core concepts

TermDescription
TLF (Top Level Function)The computational function to describe (e.g., VOR learning, spatial navigation)
ROI (Region of Interest)Brain region where the TLF is implemented (e.g., cerebellum, hippocampus)
UC (Uniform Circuit)Basic unit of HCD (neural population). “Circuit” is a project-specific term, not a synaptic circuit
BIF (Brain Information Flow)Anatomical projection data supporting connections
ConnectionInformation transfer between UCs based on BIF
InterfaceUC input/output relation: ([outputs], ...) = UC-name([inputs], ...)
Output SemanticsMeaning of information coded by a UC
GN (Group Node)Intermediate FRG node representing a sub-function of the TLF
HCDHypothetical Component Graph — information-processing graph of UCs and Connections
FRGFunction Realization Graph — hierarchical decomposition of TLF grounded in UCs

10. Using AI agents

Supported tools CoBRAC work is done with an AI agent (Cursor, Claude Code, Codex, or any tool with agent capabilities). Have the agent read each instruction_*.md and perform tasks according to those instructions.
Output quality HCD, FRG, and CSV content generated by AI agents depends heavily on the model you use. Higher-capability models tend to produce better literature surveys, consistency checks, and complex functional descriptions. However, neuroscientific validity and citation accuracy must always be verified by a human.

Basic workflow

  1. Open the CoBRAC repository (_latest_version) as the agent working directory
  2. Explicitly reference the instruction file for the current Phase
  3. Always specify TLF, ROI, Project ID, and other parameters

Prompt examples

Start Phase 1

Following instruction_1_HCD.md, start HCD creation with
ROI: hippocampus, TLF: spatial navigation.
Project folders are already created.

HCD complete → start FRG

HCD is complete. Following instruction_2_FRG.md, start FRG creation
using the TLF and UCs from HCD outputs.

FRG complete → create CSV

FRG is complete. Following instruction_3_csv.md,
create all five CSV files.

What humans must verify

  • Citation accuracy (DOI, author-year)
  • Neuroscientific validity of ROI/TLF
  • UC naming rules and GN–UC constraints
  • Consistency between Connections and Interfaces

11. Quality checklist

HCD

  • Information path from ROI_Input to ROI_Output is valid
  • Every Connection has a Reference ID
  • Connections match Interfaces
  • UC names use Kebab-case and backticks in markdown
  • Outside-ROI UCs have noROI comments
  • 5_Verification.md completed
  • 8_diagram.md Mermaid diagram created

FRG

  • Only inside-ROI UCs used
  • Each GN decomposed into multiple UCs
  • GN–UC constraints satisfied (max 2 each)
  • TLF Interface consistent with noROI I/O
  • 4_機能詳細.md complete

CSV / xlsx

  • All five CSV files in English
  • No duplicate or missing entries in References.csv
  • Correct Node ID format in FRG.csv (R.* / U.*)
  • .bra.xlsx has five sheets
  • Contributor / Project ID reflected in Circuits and Connections

B. Naming conventions

  • UC — Kebab-case, no spaces (e.g. flocculus-purkinje)
  • GN — R. + Kebab-case (e.g. R.error-computation)
  • UC in FRG.csv — U. + Circuit ID
