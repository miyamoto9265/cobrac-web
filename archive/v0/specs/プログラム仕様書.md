複数のcsvを加工して一つのxlsxファイルにするPythonスクリプトを作成する。
対象のcsvは、
Project.csv
References.csv
Circuit.csv
Connections.csv
FRG.csv

最初に、ContributerとProject IDをユーザーが入力する。

Project.csv
のA2にContributer
のB2にProject ID
を入力

References.csv
はそのまま

Circuit.csvは、D, E, F列に
Sub-Circuits すべて空欄
Super Class すべて空欄
Uniform すべてTRUE
列を挿入する。
I, J, K列に(2列空けるという意味)
Size すべて空欄
Output Semantics (0) すべて空欄
Physiological Data すべて空欄
M列、N列に
Contributor 全行ユーザーが入力したContributor
Project ID　全行ユーザーが入力したProject ID

Connection.csvは
以下のようなヘッダーの列を挿入
B列 sCID relation
全行 「'=」を入力
C列 Notation of sCID in Literature
A列の内容のコピー
E列 rCID relation
全行 「'=」を入力
F列 Notation of rCID in Literature
D列の内容のコピー
G列 Size
すべて空欄
N列 In-depth literature
すべて空欄
O列 Contributor　全行ユーザーが入力したContributor
P列 Project ID　全行ユーザーが入力したProject ID

FRG.csvは、
E列とF列を
E列の内容+改行+<<mechanism to realize the capability>>+改行+F列の内容+改行+<<mechanism realized by grainest coding scheme>>
でconcat
して、新たなE列 
Capability&Mechanism
としてマージ
以降の列は前に詰める

その後、それぞれのファイル名をシートとして、
Project References Circuits Connections FRG
の順番になるようにエクセルファイルを作成する
ファイル名は「ProjectID」.bra.xlsx
