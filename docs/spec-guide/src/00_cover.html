CoBRAC Agents 仕様書

LLM のエージェントと検査するプログラムで BRA を作る Web アプリの、
システム・ハーネス・命名・Canon・版と BRA-DB・オーケストレーター・運用
第 1 部
システムの全体像

アーキテクチャ、利用者と権限、画面、ジョブ、データモデル、ワーカー。

第 2 部
ハーネス

推論する LLM（CoBRAC エージェント）と検査するワーカーで 1 件の BRA を作る仕組み。

第 3 部
UC Descriptor と facet

回路を SABRA の単位と 9 本の facet で名付け、プロジェクトをまたいで同じキーで呼ぶ規則。

第 4 部
Canon（整合単位の実装）

回路の定義をそろえる BRA の範囲と、その版・取り込み・審査の手続き。

第 5 部
版と BRA-DB（仮）on AWS

凍結した版を、BRA-DB スキーマ v4.6 のデータベースに来歴つきで登録する。

第 6 部
CoBRAC オーケストレーター

多数の ROI × TLF を計画にまとめ、順序の計算・バッチ実行・再計画まで自動で進める。

第 7 部
AWS インフラ・セキュリティ・運用

AWS の構成と予算、個人情報とセキュリティ、リリースとデプロイ、速度と費用。
