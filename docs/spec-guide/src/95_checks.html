付録 E

検査項目の一覧

本付録は、ワーカーが BRA を作るときに行う検査をすべて挙げ、それぞれに検査 ID を付けた一覧です。検査の流れと直し方は 3.10 に、名前の検査は 2.10 に、HCD と FRG の整合は 3.11 に、Canon との照合は第 5 部に記載しています。本付録は、それらの検査を 1 つの番号の体系でたどるための索引です。

検査 IDCoBRAC の検査につける番号です。QC-種別-連番 の形で、種別も連番も 2 けたです。
Master の番号WBAI の BRA data: Error code List (Master) の番号です。検査が BRA の決まりに由来するとき、その番号を併記します。
扱い問題が見つかったとき、エージェントに直させるか、ワーカーが直すか、記録だけにするかを示します。

E.1 検査 ID と番号の体系

検査 ID は QC-種別-連番 の形です（QC は Quality Control の略）。種別の番号は、ワーカーが検査する順に振られています。新しい検査はその種別の最後に追加し、廃止した番号は使い回しません。整合の所見（X1 など）と Canon の衝突（C1 など）は、以前からのコードがログや画面に出るため、表に旧コードを併記しています。

出どころ

各表の「出どころ」の列は、検査の根拠を示します。

  • Master の番号：WBAI の BRA data: Error code List (Master) に番号がある検査です。Master は Review Tool 4.4 が参照する表で、リポジトリの docs/bra/BRA-data-Error-code-List-Master.xlsx に保存されています。番号はシートごとに分かれ、References が 1〜28、Circuits が 101〜171、Connections が 201〜294、FRG が 401〜571、FRG_FunctionalityReview が 1001〜2206 です。
  • BRA（番号なし）：Template-v2-3 や Data Preparation Manual の決まりで、Master に番号がないものです。
  • CoBRAC：CoBRAC が独自に加えた検査です。Master の決まりに CoBRAC が照合を加えたものは、Master の番号を先に書き、CoBRAC が加えた部分を添えています。

Master の各番号には Error type があり、0 は自動エラー、1 は人が確認するエラー、2 は自動警告、3 は人が確認する警告です。CoBRAC の扱いは Error type とは別に決めています。
