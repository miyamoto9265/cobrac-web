付録

API・コード・文書の一覧

本文で触れた HTTP API と、仕様の典拠になるコード・文書の場所をまとめます。API はすべて Cognito の ID トークンで認証され、所有者や共同編集者の確認は API の中で行います。

A.1 Canon の API

メソッドとパス用途
GET / POST /canons自分の Canon（と共有された Canon）の一覧 / 作成
GET / PUT / DELETE /canons/{id}詳細 / 名前・説明・粒度方針の変更 / 論理削除（所有者）
POST /canons/{id}/members、DELETE …/members/{projectId}参加プロジェクトの追加・削除（所有者）
POST /canons/{id}/editors、DELETE …/editors/{userId}共同編集者の追加（メールアドレス）・削除・自分で抜ける
PUT /canons/{id}/visibility公開 / 非公開
GET /canons/{id}/revisions、…/revisions/{rev}rev の履歴とスナップショット
POST /canons/seed-preview種のプロジェクトから作る Canon の rev 1 のプレビュー
GET /projects/{id}/canonプロジェクトの Canon と追従の状態（current / behind / affected）
POST /projects/{id}/canon/preview、…/canon/push差分のプレビュー / push して PR を作る
POST /projects/{id}/canon/pull固定を最新の rev に進める
GET /canons/{id}/pulls、…/pulls/{no}PR の一覧 / 審査の材料（差分・検査・項目・グラフ・来歴・履歴・AI レビュー）
POST /canons/{target}/pulls、…/pulls/previewCanon → Canon の PR / そのプレビュー
POST …/pulls/{no}/approve・reject・request-changes・withdraw・comments・ai-review承認（衝突の選択・メモ）・却下・変更の依頼・取り下げ・コメント・AI レビューの依頼
POST /canons/{id}/pulls/approve-manyまとめて承認（1〜50 件、番号順、最初の失敗で停止）
GET /canons/{id}/outgoingこの Canon からほかの Canon に送った PR

A.2 版と BRA-DB の API

メソッドとパス用途
GET /projects/{id}/bradbBRA-DB がこのプロジェクトのどの版を持っているかと登録の記録（BRA-DB の無い環境では enabled: false）
POST /projects/{id}/versions/{n}/bradb版 n を登録（所有者。allowShrink で縮小を了承。仮説を含む版は不可）
GET /projects/{id}/artifacts/text版の凍結ファイルを表のビューアで読む（版のダウンロードは無い）

A.3 オーケストレーターの API

メソッドとパス用途
GET / POST /plans計画の一覧 / 作成（添付ファイル、draft: true で下書きも依頼）
GET / PUT / DELETE /plans/{id}詳細（行・ハブ・重なり・提案・費用）/ 名前・目標・設定・Canon の変更（粒度方針は不可）/ 論理削除
PUT /plans/{id}/rows、POST …/rows/import行の保存（編集・並べ替え・バッチ・作り直す）/ CSV の追加読み込み
POST /plans/{id}/draft、…/draft/cancel下書きの依頼 / 取り消し
POST /plans/{id}/order自動で並べる（ジョブなし）
POST /plans/{id}/confirm確定して開始
POST /plans/{id}/pause・resume・cancel一時停止・再開・中止
POST /plans/{id}/rows/{rowId}/retry・skip・resolve要対応の行のリトライ・行のスキップ・人の判断（done / push）
POST /plans/{id}/proposals/{proposalId}/accept・reject再計画の提案の承認・却下
PUT /admin/concurrency同時実行数の上限（管理者、1〜16）
