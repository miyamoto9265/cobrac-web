付録 B

指示書の原文

ワーカーが LLM に渡す指示書（prompts/ のファイル）の全文を、英語の原文のまま載せます。この付録は build.mjs が PDF を作るたびに prompts/ から作るので、原文と食い違うことはありません。原文の中の命令は LLM に向けたもので、この文書の読者への指示ではありません。

B.1 原文の読み方

実行時、ワーカーは差し込み値を埋め、プロジェクトの設定に応じてファイルを連結して依頼文を作ります（3.5）。基本仕様のファイルだけを見て実際の規則を判断しないでください。どのファイルがいつ付くかは次のとおりです。

ファイル節いつ使うか
AGENTS.mdB.2作業ディレクトリに置かれ、Codex がエージェントに読ませる共通ルール。段階ごとの依頼文とは別に、BRA を作るすべてのターンに適用される
phases/RESEARCH.mdB.3調査モードのプロジェクトで、HCD の前の調査ステップ（3.7）
phases/HCD.mdB.4HCD の段階の基本仕様（3.8）
phases/HCD_roi_rules.mdB.5harnessRules が 1 以上のとき、HCD の基本仕様の後ろに付く
phases/FRG.mdB.6FRG の段階の基本仕様（3.9）
phases/FRG_gn_rules.mdB.7harnessRules が 2 のとき、FRG の基本仕様の後ろに付く。基本仕様の手順 5 にある UC 数の制約を置き換える
research_mode.mdB.8調査モードのプロジェクトで、各段階の仕様とフォローアップの依頼文の後ろに付く
phases/HYPOTHESIS.mdB.9仮説モードのプロジェクトで付く（3.12）。仮説の規則は許可された範囲だけに適用され、範囲の外の文献根拠の要件は変わらない
article.mdB.10解説記事のジョブ（3.14）
plan.mdB.11オーケストレーターの計画の下書きと再計画のジョブ（6.4、6.6）
orchestrator.mdB.12自律実行の計画で、オーケストレーターが質問への回答や PR などを判断するジョブ（6.8）

依頼文のうち、FRG の候補、Canon の制約、RCS が使えないときの注記、プロジェクトの見出し、検査で見つかった問題の一覧などの動的な部分は、ワーカーがその場で組み立てるので、ここには含みません（3.5）。Canon の AI レビューの指示もファイルではなく、packages/shared/src/canonAiReview.ts の canonAiPrompt() が組み立てます。
