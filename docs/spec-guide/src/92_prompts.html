付録 B

プロンプト原文

ワーカーが LLM に渡す指示ファイルの全文です。英語の原文をそのまま載せます。この付録は build.mjs がリポジトリの prompts/ から毎回作るので、原文と食い違うことはありません。原文の中の命令は LLM（CoBRAC エージェントなど）に向けたもので、この文書の読者への指示ではありません。

B.1 原文の読み方

実行時、ワーカーは差し込み値を埋め、プロジェクトの設定に応じてファイルを連結します（2.6）。基本仕様だけで実際の規則を判断しないでください。HCD の後ろには ROI 規則（harnessRules が 1 以上）、FRG の後ろには GN 規則（harnessRules が 2）が付き、GN 規則は FRG 基本仕様の手順 5 にある UC 数の制約を置き換えます。調査モードでは research_mode.md、仮説モードでは HYPOTHESIS.md がさらに付きます。仮説の規則は許可された範囲だけに適用され、範囲外の文献根拠の要件は変わりません。

AGENTS.md は作業場所に置かれ、Codex がエージェントに読ませる共通ルールで、段ごとの依頼文とは別に適用されます。FRG の候補、Canon の制約、RCS が使えないときの注記、プロジェクトの見出し、検査の問題一覧などの動的な部分は、ここには含みません（2.6）。Canon の AI レビューの指示はファイルではなく、packages/shared/src/canonAiReview.ts の canonAiPrompt() が組み立てます。
