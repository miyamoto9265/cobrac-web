E.2 本書の作り方

この PDF（docs/CoBRAC_仕様書.pdf）は、docs/spec-guide/src/ の HTML から npm run spec:build で作ります。付録 B は prompts/ の指示書から毎回作るので、原文と食い違うことはありません。挙動を変えたときは、同じ変更の中で該当する節を直して PDF を作り直します。作り直しの手順と書き方の約束は docs/spec-guide/README.md にあります。
